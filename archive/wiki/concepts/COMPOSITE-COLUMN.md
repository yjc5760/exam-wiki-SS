# 合成柱

**概念 ID：** COMPOSITE-COLUMN
**知識分類：** Part 2.2 材料科學（合成結構）
**規範來源：** 鋼結構極限設計法 第九章

## 定義

指由型鋼（或鋼管）與混凝土結合而成的壓力構件，常見型式有混凝土包覆型鋼（SRC）與鋼管混凝土（CFT）。此類構件能結合鋼材的韌性與混凝土的抗壓及勁度，有效提高承載能力與防火性能。

## 關鍵公式

**混凝土包覆型鋼柱（SRC）設計強度（LRFD）：**

$$\phi_c P_n = \phi_c A_s F_{cr},\qquad F_{cr} \text{ 以 } F_{my}、E_m \text{ 求 } \lambda_c = \frac{KL}{r_m\pi}\sqrt{\frac{F_{my}}{E_m}} \text{ 後套柱強度曲線}$$

（$F_{my}$ 已把鋼筋與混凝土折算進鋼骨，不可再另加 $A_{sr}F_y$、$A_cf'_c$，否則重複計算）

等效材料強度（簡化法）：

$$F_{my} = F_y + c_1 F_{yr}\frac{A_r}{A_s} + c_2 f'_c \frac{A_c}{A_s}$$

SRC（包覆型）：$c_1 = 0.7$、$c_2 = 0.6$、$c_3 = 0.2$；CFT（鋼管混凝土）：$c_1 = 1.0$、$c_2 = 0.85$、$c_3 = 0.4$（LRFD 1993 I2.2）

等效彈性模數：

$$E_m = E_s + c_3 E_c \frac{A_c}{A_s}$$

**鋼管混凝土柱（CFT）強度：**

$$\phi_c P_n = \phi_c \left(A_s F_y + C_2 f'_c \left(A_c + C_3 \frac{A_{sr} E_s}{E_c}\right)\right)$$

上式為 **AISC 360-10（非考卷版）** 寫法，其中 $C_2 = 0.85$（矩形）、$0.95$（圓形）。考卷所依 LRFD 1993 系仍以 $F_{my}$、$E_m$ 等效斷面法計算（$c_1 = 1.0$、$c_2 = 0.85$、$c_3 = 0.4$）。

## 常見陷阱

1. **SRC 柱的最小型鋼面積比**：型鋼斷面積須佔總斷面積的 4% 以上，才能作為合成柱設計（否則按 RC 設計）。
2. **等效細長比的計算**：合成柱需使用等效材料特性（$F_{my}$、$E_m$）計算 $\lambda_c$，再套用柱強度曲線。
3. **CFT 有圍束效應**：圓形 CFT 的混凝土受三向圍束，強度提升係數不同於矩形管。
