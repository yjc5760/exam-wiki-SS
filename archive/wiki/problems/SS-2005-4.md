# SS-2005-4 — 一端固接、一端簡支之 T 型鋼梁（全深 24 cm，L = 600 cm），以塑性設計法求因數化載重 wu

## 題幹摘要

有一靜不定鋼梁兩端分別為固接與簡支，鋼梁斷面為 T 型，$F_y = 2.5\ \text{tf/cm}^2$、$F_u = 4.1\ \text{tf/cm}^2$。假設鋼梁有足夠側向支撐且為結實斷面。試以塑性設計法，僅考慮撓曲強度，計算鋼梁所能承受之因數化載重 $w_u$（不考慮自重）。（25 分）

**T 型斷面（依考卷原圖）：** 翼板 $40 \times 2.6$ cm；腹板厚 2.4 cm；**全深 $d = 24$ cm**（腹板淨高 21.4 cm）。跨度 $L = 600$ cm，左端固接、右端簡支，全跨均布 $w_u$。

![SS-2005-4 題目附圖：左端固接、右端簡支 T 型梁，跨度 600 cm；T 型斷面翼板 40×2.6 cm、全深 24 cm、腹板厚 2.4 cm](../../raw/solutions/SS-2005-4/SS-2005-4-fig-1.png)

*圖說（依考卷原圖 600 dpi 目視判讀）：「24 cm」尺寸線上界線對齊翼板頂面、下界線對齊腹板底 → **24 cm 為全深**，不是腹板高。*

---

## 核心考點

1. 超靜定次數 1 → 2 個塑性鉸（固端負彎矩＋跨間正彎矩）
2. T 型斷面 PNA（在翼板內）、$Z$、$M_p$
3. 虛功法 $w_u(x) = 2M_p(2L-x)/[Lx(L-x)]$，對 $x$ 求極值 → $x = L(2-\sqrt{2})$、$w_u = (6+4\sqrt{2})M_p/L^2$

## 解題關鍵步驟

1. $h_w = 24 - 2.6 = 21.4$ cm；$A = 104 + 51.36 = 155.36$ cm²；$A/2 = 77.68 < 104$ → PNA 在翼板內，距頂 1.942 cm
2. $Z = 75.43 + 8.66 + 583.35 = 667.4$ cm³ → $M_p = 2.5 \times 667.4 = 1668.6$ tf·cm
3. 跨間鉸 $x = 351.5$ cm（距固端）
4. $w_u = 11.657 \times 1668.6 / 600^2 = 0.0540$ tf/cm = **5.40 tf/m**
5. 平衡法驗算：$R_A = 18.99$ tf，$M(351.5) = 1668.6 = M_p$ ✓

## 涉及陷阱

| 陷阱 | 說明 | 應對策略 |
|------|------|---------|
| ⚠️ 斷面尺寸讀錯 | 「24 cm」是全深；當成腹板高（全深 26.6）會得 $w_u = 6.58$，高估 22%（舊解錯誤，已更正） | 看尺寸線界線落點 |
| ⚠️ 誤以為鉸在中央 | 跨間鉸不在跨中 | 對 $x$ 微分 → $0.586L$ |
| ⚠️ PNA 誤算 | 先比較翼板面積與半面積 | PNA 在翼板內 |
| ⚠️ 負彎矩也需達 Mp | 固端負彎矩 | $Z^+ = Z^-$ |

## 結論

$M_p = 1668.6$ tf·cm，$w_u = 0.0540$ tf/cm $= 5.40$ tf/m（跨間鉸距固端 351.5 cm）。
