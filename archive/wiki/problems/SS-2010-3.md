## 題幹摘要

有一受壓桿件，斷面由四個不等肢角鋼（L150×100×15）以繫板和繫條穩固組合而成（如圖二），柱的有效長度為 25 m，若繫板和繫條之斷面積不計，鋼料降伏強度 $F_y = 2.52\ \text{tf/cm}^2$，$E = 2{,}040\ \text{tf/cm}^2$。

（一）以容許應力設計法（ASD），求組合斷面之挫屈載重（tf）。（15 分）
（二）以極限設計法（LSD），求組合斷面之設計強度（tf）。（15 分）

![組合斷面（40cm×40cm 方形配置，4 個 L150×100×15 不等肢角鋼置於四角，長肢垂直、短肢水平）及單角鋼斷面性質](../../raw/solutions/SS-2010-3/SS-2010-3-fig-1.png)

*圖說（依考卷原圖 500 dpi 目視判讀）：*
- *單角鋼圖：**長肢（15 cm）垂直、短肢（10 cm）水平**。$c_x = 5.0$ cm 的尺寸線是**垂直方向**，量自水平肢外緣到形心，也就是形心到水平 $X$ 軸方向外緣的距離；$c_y = 2.53$ cm 是**水平方向**，量自垂直肢外緣到形心。$I_x = 782$ cm⁴ 為繞水平 $X$ 軸、$I_y = 276$ cm⁴ 為繞垂直 $Y$ 軸。*
- *組合斷面：四支角鋼置於 40 cm × 40 cm 的四角，方向與單角鋼圖相同（長肢沿左右兩側垂直、短肢沿上下兩邊水平），形心在幾何中心；兩端鉸接，有效長度 25 m。*

---

## 核心考點

**核心觀念：組合柱斷面性質（平行軸定理）＋ ASD 與 LRFD 兩法柱強度**

**出題者測驗重點：**
- **平行軸距離要配對正確的軸**：角鋼繞水平軸的 $I_x$ 要配「形心到組合斷面水平軸的垂直距離」$20 - c_x$；繞垂直軸的 $I_y$ 要配水平距離 $20 - c_y$。
- 兩個方向都算，取較小的 $I$ 控制。
- ASD：$KL/r > C_c$ 用彈性 $F_a = 12\pi^2E/[23(KL/r)^2]$；LRFD：$\lambda_c > 1.5$ 用 $F_{cr} = 0.877F_y/\lambda_c^2$。

---

## 解題關鍵步驟

**作戰計畫：**
```
Step 1  讀單角鋼圖：c_x 是垂直距離（對應水平軸 X），c_y 是水平距離（對應垂直軸 Y）
Step 2  組合慣性矩（平行軸定理）：
        I_X = 4[I_x + A(20 − c_x)²] = 4[782 + 35.3×15.0²]  = 34,898 cm⁴（控制）
        I_Y = 4[I_y + A(20 − c_y)²] = 4[276 + 35.3×17.47²] = 44,198 cm⁴
Step 3  r = √(34,898/141.2) = 15.72 cm，KL/r = 2500/15.72 = 159.0
(一) ASD：C_c = 126.4 < 159.0 → 彈性 → F_a = 0.415 → P_a = 58.7 t
(二) LRFD：λ_c = 1.779 > 1.5 → F_cr = 0.698 → φcPn = 83.8 t
```

**陷阱分析：**

| 陷阱 | 說明 | 對策 |
|------|------|------|
| ❶ 平行軸距離配錯軸 | $I_x$（繞水平軸）必須配**垂直**距離 $20 - c_x$；把 $I_y = 276$ 配上 15 cm 就是把兩個方向混在一起 | 每一項都問「繞哪一軸？距離是不是垂直於這軸量的？」 |
| ❷ 看錯 $c_x$、$c_y$ 方向 | 圖上 $c_x$ 箭頭是上下向、$c_y$ 是左右向；下標指的是「對應哪一軸」，不是「沿哪個方向量」 | 回圖看箭頭 |
| ❸ 平行軸距離用 20 cm | 要扣掉形心偏距 | $20 - c$ |
| ❹ ASD 公式選錯 | $KL/r > C_c$ 用彈性式 | 先求 $C_c$ |
| ❺ LRFD 公式選錯 | $\lambda_c > 1.5$ 用 $0.877/\lambda_c^2$ | |

---

## 答案摘要

平行軸配對：$I_X = 4(782 + 35.3\times15.0^2) = 34{,}898$（控制）、$I_Y = 4(276 + 35.3\times17.47^2) = 44{,}198$ cm⁴ → $r = 15.72$ cm、$KL/r = 159.0 > C_c = 126.4$ → ASD **$P_a = 58.7$ t**；LRFD $\lambda_c = 1.779$ → **$\phi_cP_n = 83.8$ t**。
