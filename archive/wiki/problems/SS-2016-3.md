## 題幹摘要

**子問題：**
1. **(一)** 何謂殘留應力？（5 分）
2. **(二)** 殘留應力的來源有哪些？（5 分）
3. **(三)** 殘留應力對受壓桿件的影響為何？（5 分）
4. **(四)** 圖 1 所示為某一斷面殘留應力的分布圖（寬 $b$、厚 $t$ 的矩形板，兩側各 $b/3$ 為壓應力 $F_y/4$，中間 $b/3$ 為拉應力 $F_y/4$），請繪出該斷面受壓時強軸的 $F_{cr}$ vs $L/r$ 曲線（$F_{cr}$：由軸壓力所引致的挫屈應力；$y$ 軸為 $F_{cr}$，$x$ 軸為 $L/r$，假設 $K=1$）。已知材料降伏應力 $F_y = 2.5 \text{ tf/cm}^2$，完美彈塑性曲線如圖 2，$E = 2040 \text{ tf/cm}^2$。（15 分）

**殘留應力分佈（圖 1，依考卷原圖目視判讀）：**

```
   ┌──────────────────────────────┐ ↕ t
   └──────────────────────────────┘
   |← b/3 →|←  b/3  →|← b/3 →|
   [ Fy/4 壓 ]          [ Fy/4 壓 ]
            [ Fy/4 拉 ]
```

*圖說：圖 1 是**一塊寬 $b$、厚 $t$ 的矩形板**（不是 H 型鋼，沒有腹板）。殘留應力為三段塊狀：兩側各 $b/3$ 壓應力 $F_y/4$，中間 $b/3$ 拉應力 $F_y/4$。注意這組數字**不自相平衡**：壓力合力 $2 \times \tfrac{b}{3}t \times \tfrac{F_y}{4}$ 是拉力合力 $\tfrac{b}{3}t \times \tfrac{F_y}{4}$ 的兩倍（淨壓力 $F_ybt/12$）。這是題目的缺陷，答題時應指出，並說明採用的處理方式（見 §4(四)）。*
*強軸：板寬 $b$ 方向的彎曲（繞平行於 $t$ 的軸），$I = tb^3/12$，兩側的 $b/3$ 對勁度貢獻最大。*

## 核心考點

**核心觀念：殘留應力降低柱的挫屈強度——中間細長比最危險**

此題系統性地測驗考生對殘留應力的全面理解：從定義、來源、影響機制，到**定量繪製柱強度曲線**的能力。第四小題需要具體計算曲線上的關鍵轉折點。

**出題者測驗重點：**
- 殘留應力的「比例限（Proportional Limit）」概念
- 切線模數（Tangent Modulus）與有效彈性模數的關係
- 能否正確計算 $L/r$ 的轉折點（由彈性轉向非彈性的臨界細長比）
- Euler 曲線 vs 實際柱強度曲線的形狀差異

---

## 解題關鍵步驟

**步驟規劃（第四題）：**

1. 由殘留應力分佈求出**比例限**（Proportional Limit）$F_{PL}$
2. 計算彈性挫屈轉折點 $(L/r)_{\text{trans}}$：令 $F_e = F_{PL}$
3. 兩側同時降伏 → 強軸勁度剩 1/27 → 決定平台範圍與極短柱上升段；再接彈性 Euler（長柱）
4. 計算關鍵點的數值，繪製示意圖

**關鍵陷阱：**

> ⚠️ **陷阱1：比例限的計算方向**
> 殘留應力為**壓應力** $F_{rc} = F_y/4$ 時，疊加外部壓應力 $F_a$ 後，兩側 $b/3$ 殘留壓應力區最先（且同時）達到降伏：
> $F_a + F_{rc} = F_y$ → $F_a = F_y - F_{rc} = 3F_y/4$
> 比例限 $F_{PL} = 3F_y/4 = 1.875 \text{ tf/cm}^2$，**非** $F_y$ 本身。

> ⚠️ **陷阱2：塊狀殘留應力不會給平滑曲線**
> 兩側 $b/3$ 的殘留壓應力是**均勻**的，外力加到 $1.875$ 時兩側**同時**整塊降伏，強軸勁度一下子只剩中間 $b/3$ 的 $(1/3)^3 = 1/27$。所以非彈性段不是平滑下彎曲線，而是一段**水平平台** $F_{cr} = 1.875$（$19.9 \le L/r \le 103.6$），平台左端再接一小段 $\pi^2E/[27(L/r)^2]$ 上升到全斷面降伏。套用 $F_yF_e/(F_e + F_{rc})$ 之類的平滑式是錯的。

> ⚠️ **陷阱3：Euler 曲線的起始點計算錯誤**
> Euler 曲線的有效起始點是 $(L/r)_{\text{trans}}$，其數值由 $F_e = F_{PL}$ 求出，而非由 $F_e = F_y$ 求出。

---

## 答案摘要

(一)～(三) 殘留應力定義、來源（不均勻冷卻、銲接、冷作、火焰切割）、使比例限降為 $F_y - F_{rc}$、中等細長比影響最大。(四) 矩形板兩側 $b/3$ 同時在 $F = 1.875$ 降伏，強軸 $I_e/I = 1/27$ → **平台 $F_{cr} = 1.875$（$19.9 \le L/r \le 103.6$）**、$L/r \ge 103.6$ Euler、$18.0 \le L/r < 19.9$ 為 $\pi^2E/[27(L/r)^2]$、$L/r < 18.0$ 全斷面降伏 2.29；並指出題目殘留應力不自相平衡。
