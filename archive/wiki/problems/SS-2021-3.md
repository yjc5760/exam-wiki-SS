## 題幹摘要

耐震結構系統中有一如圖三所示承受均布載重（$w$）之鋼梁，該鋼梁採用 SM490 鋼材，$F_y = 3.5$ tf/cm²，$F_u = 4.9$ tf/cm²，$F_r = 1.16$ tf/cm²，$E = 2040$ tf/cm²。該梁在 A 點與鋼柱彎矩接合處及 B 點有充分側向支撐。自表一選擇一符合極限設計法規範耐震設計需求且可有效發揮斷面性質之最適當斷面，並詳細說明原因，未說明原因者不予計分。請計算所選擇斷面塑性彎矩強度及形狀因子後，再依極限設計法規範檢核該斷面是否足以發揮其塑性極限強度，若無法發揮其塑性強度請說明如何改善以使其可發揮塑性極限強度；若可發揮其塑性強度亦請說明理由，並計算其塑性極限強度。（45 分）

考卷參考公式（「請自行選擇適合的公式，並檢查其正確性」）：$\lambda_{pd} = 14/\sqrt{F_y}$、$17/\sqrt{F_y}$、$37/\sqrt{F_y - F_r}$（翼板）；$138/\sqrt{F_y}$、$170/\sqrt{F_y}$、$260/\sqrt{F_y}$（腹板）；$L_p = 80r_y/\sqrt{F_{yf}}$；$L_r = \dfrac{r_yX_1}{F_L}\sqrt{1 + \sqrt{1 + X_2F_L^2}}$；$M_r = F_LS_x$；$F_L = \min(F_{yf} - F_r,\ F_{yw})$；$M_{cr}$ 彈性式；$C_b = 1.75 + 1.05(M_1/M_2) + 0.3(M_1/M_2)^2 \le 2.3$；$\phi = 0.9$。

## 核心考點

**核心觀念：耐震梁的三道門檻——寬厚比（λpd）→ 側向支撐（$L_b \le L_p$ 且符合耐震側撐間距）→ 塑性極限強度**

出題者要考生：
1. 用耐震緊實斷面 $\lambda_{pd}$（不是一般 $\lambda_p$）篩選；
2. 說出「哪一個斷面最適合當梁」的理由——強軸受彎要靠**深度**，同樣的鋼料放在離中性軸愈遠愈有效；
3. 算 $Z_x$、$M_p$、形狀因子；
4. 認出 $L_b = 12$ m 太長、無法發揮 $M_p$，並提出加側撐的具體做法；
5. 加側撐後計算塑性極限強度（塑性鉸機構）。

---

## 解題關鍵步驟

**步驟規劃：**
1. 四斷面逐一檢核 $\lambda_{pd}$ → 淘汰 BH700×300×9×19
2. 比較剩餘三斷面的強軸受彎效率（$Z_x$／重量）→ 選 BH700×300×12×25
3. 算 $Z_x$、$M_p$、$f$
4. $L_p$、$L_r$ → $L_b = 1200 > L_r$ → 彈性 LTB，$M_n < M_p$
5. 改善：側撐間距 ≤ $L_p$ 且 ≤ 耐震限值 → 每 3 m 一處
6. 塑性極限強度：一端固接一端簡支受均布 → $w_u = 11.66M_p/L^2$

**關鍵陷阱：**

> ⚠️ **陷阱1：用一般 $\lambda_p$ 而非耐震 $\lambda_{pd}$。** 翼板 $14/\sqrt{F_y} = 7.48$、腹板 $138/\sqrt{F_y} = 73.8$。

> ⚠️ **陷阱2：$L_r$ 公式代 $r_T$。** 考卷印的 $L_r$ 式用的是 $r_y$（LRFD 的 $X_1$、$X_2$ 體系）；$r_T$ 是 ASD $F_b$ 公式用的。

> ⚠️ **陷阱3：「有效發揮斷面性質」誤解為「選 $r_y$ 最大」。** 寬翼 500×500 的 $r_y$ 大、$L_p$ 長，但它的鋼料多放在翼板寬度方向，強軸受彎的 $Z_x$／重量比明顯較低；作為耐震梁，側撐本來就必須加，$L_p$ 長短不是決定性因素。

> ⚠️ **陷阱4：中點圓點當成側撐。** 那是尺寸線標記；題文明言只有 A、B 有側撐。

---

## 答案摘要

$\lambda_{pd}$ 淘汰 BH700×300×9×19；以強軸受彎效率選 **BH700×300×12×25**：$Z_x = 6{,}330$ cm³、**$M_p = 221.6$ t·m、$f = 1.116$**；$L_b = 12$ m > $L_r = 8.98$ m → 無法發揮 $M_p$；改善為每 300 cm 側撐（≤ $L_p$ = 300.6 cm 且 ≤ 本國 13.6.7 之 $170r_y/\sqrt{F_y}$ = 639 cm）；塑性極限 **$w_u = 11.66M_p/L^2 = 17.9$ t/m**。
