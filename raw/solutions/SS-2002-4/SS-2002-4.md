## 2. 考題核心精神與出題者意圖 (Core Concepts & Examiner's Intent)

**核心觀念：** 偏心螺栓群的彈性向量法——直接剪力 $P/n$ 與扭矩剪力 $M r/I_p$ 的向量疊加。本題的載重是**斜向力**，扭矩必須用兩個分量分別對形心取矩（或以力線到形心的垂直距離乘 $P$），兩個分量的力矩**方向相反、部分抵銷**。

**出題者意圖：**
1. 能否從圖上讀出載重方向（3-4-5 三角形）與作用點位置，並把 25 cm 換算成到**形心**的距離；
2. 斜向力的直接剪力有水平、垂直兩個分量，最危險螺栓要逐顆向量疊加判斷；
3. 承壓應力依邊距與間距選用 (1a)，並取較薄的柱翼板控制。

## 3. 解題戰略地圖與陷阱分析 (Strategic Roadmap & Trap Analysis)

**解題順序：**
$$\text{讀圖（方向、作用點）} \to I_p = \Sigma r^2 \to M = x P_y - y P_x \to \text{各螺栓向量合力} \to R_v、R_p \to \text{檢核}$$

**關鍵陷阱：**

1. **載重方向**：圖上 P 旁有「4、3」斜率三角形，是斜向力。當成垂直力會把扭矩高估（$20 \times 25 = 500$ vs 實際 270 tf·cm），結論由 OK 變成 N.G.
2. **偏心距量到形心**：25 cm 是右行螺栓到作用點，到形心還要加 3.5 cm；作用點在鋼板上緣，比形心高 15.5 cm，水平分量也產生力矩。
3. **兩分量力矩反向**：$P_y$ 在形心右側 → 順時針；$P_x$（向左）在形心上方 → 逆時針。
4. **螺栓穿過翼板**：兩行螺栓在腹板兩側，穿過的是柱**翼板**（$t_f = 1.156$ cm），不是腹板。
5. **最危險螺栓**：斜向直接剪力 $(−1.5, −2.0)$ 與順時針扭矩剪力在**右下角**同向疊加。

## 4. 步驟化詳細計算過程 (Step-by-Step Detailed Calculation)

### 步驟 1：螺栓群幾何

形心取兩行中線與四列中點，各螺栓 $x = \pm 3.5$、$y = \pm 3.5, \pm 10.5$ cm：

$$\Sigma x^2 = 8 \times 3.5^2 = 98.0,\qquad \Sigma y^2 = 4 \times (3.5^2 + 10.5^2) = 490.0$$

$$\boxed{I_p = 98.0 + 490.0 = 588.0\ \text{cm}^2}$$

### 步驟 2：載重分量與作用點

$$P_x = 20 \times \tfrac35 = 12\ \text{tf}\ (\leftarrow),\qquad P_y = 20 \times \tfrac45 = 16\ \text{tf}\ (\downarrow)$$

作用點（鋼板右上角）相對形心：$x_P = 25 + 3.5 = 28.5$ cm，$y_P = 10.5 + 5 = 15.5$ cm。

### 步驟 3：扭矩（兩條路徑）

**路徑一（分量取矩）：**

$$M = x_P P_y - y_P P_x = 28.5(-16) - 15.5(-12) = -456 + 186 = \boxed{-270\ \text{tf}\cdot\text{cm}}\ \text{（順時針）}$$

**路徑二（力線垂直距離）：** 力線過 $(28.5, 15.5)$、方向 $(-0.6, -0.8)$，形心至力線距離

$$e = |28.5(-0.8) - 15.5(-0.6)| = |-22.8 + 9.3| = 13.5\ \text{cm} \Rightarrow M = 20 \times 13.5 = 270\ \text{tf}\cdot\text{cm}\ \checkmark$$

![SS-2002-4 兩格：左為 2×4 螺栓群、形心 O 與 3:4 斜向力線，形心到力線的垂直距離 e = 13.5 cm；右為分量取矩長條：16×28.5 = 456（順時針）、12×15.5 = 186（逆時針）、淨值 270，對照誤算 20×28.5 = 570](figs/SS-2002-4-fig-1-ecc.svg)

*圖 1　扭矩取形心到力線的垂直距離 $e = 13.5$ cm，$M = 270$ tf·cm；分量取矩是第二條路徑，兩者必須相同。這張圖攔的是拿作用點座標當力臂（$P \times 28.5 = 570$），或只算垂直分量的力矩。*

### 步驟 4：各螺栓合力

直接剪力：$(P_x/8,\ P_y/8) = (-1.5,\ -2.0)$ tf

扭矩剪力：$f_{Tx} = -M y/I_p$，$f_{Ty} = M x/I_p$（$M = -270$）

| 螺栓 $(x, y)$ | $f_x$ (tf) | $f_y$ (tf) | $R$ (tf) |
|:---:|---:|---:|---:|
| (+3.5, +10.5) | 3.321 | −3.607 | 4.90 |
| (+3.5, +3.5) | 0.107 | −3.607 | 3.61 |
| (+3.5, −3.5) | −3.107 | −3.607 | 4.76 |
| **(+3.5, −10.5)** | **−6.321** | **−3.607** | **7.28** |
| (−3.5, +10.5) | 3.321 | −0.393 | 3.34 |
| (−3.5, +3.5) | 0.107 | −0.393 | 0.41 |
| (−3.5, −3.5) | −3.107 | −0.393 | 3.13 |
| (−3.5, −10.5) | −6.321 | −0.393 | 6.33 |

**驗算（極座標）：** 右下角 $r = \sqrt{3.5^2 + 10.5^2} = 11.07$ cm，扭矩剪力 $270 \times 11.07/588 = 5.08$ tf，方向垂直於半徑 → $(-4.821, -1.607)$；與直接剪力相加 $(-6.321, -3.607)$，$R = 7.28$ tf ✓

$$\boxed{R_{max} = 7.28\ \text{tf}\ \text{（右下角螺栓）}}$$

### 步驟 5：容許螺栓力

**剪力（單剪，A325X 承壓式）：**

$$R_v = F_v A_b = 2.10 \times 3.88 = 8.148\ \text{tf}$$

**承壓：** 列距 7 cm $> 3d = 6.6$ cm、邊距 5 cm $> 1.5d = 3.3$ cm，柱翼板側邊距 $15.44/2 - 3.5 = 4.22$ cm $> 3.3$ cm → 採 (1a) $F_p = 1.2F_u = 4.92\ \text{t/cm}^2$

| 元件 | 厚度 | $R_p = F_p\,d\,t$ |
|------|------|------|
| 柱翼板 | 1.156 cm | 12.51 tf |
| 鋼板 | 1.5 cm | 16.24 tf |

$$R_{allow} = \min(8.148,\ 12.51) = \boxed{8.148\ \text{tf（剪力控制）}}$$

### 步驟 6：檢核

$$R_{max} = 7.28\ \text{tf} \le R_{allow} = 8.148\ \text{tf}\quad(\text{比值 } 0.89)$$

$$\boxed{\text{接合強度足夠（O.K.）}}$$

## 5. 關鍵爭議點與進階探討 (Critical Issues & Advanced Discussion)

### Q：若把 P 當成垂直力會怎樣？

$M = 20 \times 28.5 = 570$ tf·cm（量到形心），最大螺栓力 11.76 tf > 8.15 tf，判定 N.G.；若再把 25 cm 當成到形心的距離，得 10.47 tf，仍 N.G.。本題的斜向力讓兩個分量的力矩部分抵銷（$-456 + 186$），這是「O.K.」的關鍵，讀圖錯會直接翻轉結論。

### Q：作用點高度的敏感度

若作用點取在最上列螺栓高度（$y_P = 10.5$），$M = -456 + 126 = -330$ tf·cm，最大螺栓力 8.39 tf，略大於 8.15 tf（超 3%）。可見結論對作用點位置敏感，讀圖要確實。圖上「5cm」以外側箭頭標在鋼板上緣與最上列螺栓之間，作用點在鋼板角點，故取 $y_P = 15.5$ cm。

### Q：彈性法與即時中心法

彈性法假設接合板繞形心剛體旋轉、螺栓力與距離成正比，忽略螺栓非線性變形，結果偏保守。即時中心法（AISC 表格係數 $C$）考慮螺栓的荷重－變形曲線，容量通常高 20%–40%。本題指定彈性法。

### Q：鋼板本身

題目只問接合強度，鋼板之淨斷面、塊狀剪力與托架彎矩未要求，未列入。
