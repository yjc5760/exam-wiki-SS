## 4. 步驟化詳細計算過程 (Step-by-Step Detailed Calculation)

### （一）塊狀剪力撕裂（block shear rupture）

**定義：** 拉力構材或接合板在螺栓（或銲道）群的端部，沿「平行力方向的剪力面」與「垂直力方向的拉力面」同時破壞，**整塊被撕出來**的破壞模式。常發生於接合長度短、板較薄、或梁端切口（cope）處。

**機制：** 兩個面不會同時達到斷裂。斷裂應力較大的那一面先斷，另一面此時已降伏：

$$\phi R_n = 0.75\left[0.6F_yA_{gv} + F_uA_{nt}\right]\quad (F_uA_{nt} \ge 0.6F_uA_{nv}：拉力面斷裂＋剪力面降伏)$$
$$\phi R_n = 0.75\left[0.6F_uA_{nv} + F_yA_{gt}\right]\quad (F_uA_{nt} < 0.6F_uA_{nv}：剪力面斷裂＋拉力面降伏)$$

兩式均不得大於 $0.75\left[0.6F_uA_{nv} + F_uA_{nt}\right]$（兩面都斷裂的理論上限）。

*（作答時畫一張螺栓群端部的示意圖，標出剪力面 $A_{gv}/A_{nv}$ 與拉力面 $A_{gt}/A_{nt}$。）*

### （二）腹板局部降伏的改善措施

**成因：** 梁支承處（或集中載重處）的反力經翼板傳入腹板，在**腹板與翼板交界的趾部**（距翼板外緣 $k$）形成高應力；若支承長度 $N$ 太短、腹板太薄，該處會先降伏。

**檢核（佐證用）：** 擴散斜率 1:2.5
$$\text{端部反力：}R_n = (2.5k + N)F_{yw}t_w,\qquad \text{中間集中力：}R_n = (5k + N)F_{yw}t_w,\qquad \phi = 1.0$$
（ASD：$\dfrac{R}{t_w(N + 2.5k)} \le 0.66F_y$）

**改善措施（依效果與施工性）：**

| 措施 | 作用 |
|------|------|
| ① 加長支承長度 $N$（加大支承板或承座） | 直接增加分母，應力擴散範圍變大 |
| ② 設置**承壓加勁板**（bearing stiffener），兩側成對、緊貼受力翼板 | 反力改由加勁板直接傳遞，腹板不再單獨受壓（同時解決腹板皺曲 web crippling） |
| ③ 加厚腹板，或在腹板加銲補強板（doubler plate） | 增加 $t_w$ |
| ④ 改用腹板較厚、或 $k$ 較大的斷面 | 從斷面選擇上避免 |
| ⑤ 調整支承位置，使反力不落在梁端最邊緣 | 端部改為中間條件，擴散長度由 $2.5k$ 增為 $5k$ |

### （三）降伏的安全係數為何較低

受拉構材有兩個極限狀態：全斷面降伏（GSY）與淨斷面斷裂（NSF）。規範對前者給較小的安全係數：

$$\text{ASD：}F_t = 0.60F_y\ (FS = 1.67)\quad \text{vs}\quad F_t = 0.50F_u\ (FS = 2.00)$$
$$\text{LRFD：}\phi_t = 0.90\quad \text{vs}\quad \phi_t = 0.75$$

**理由：**
1. **破壞性質不同**：全斷面降伏屬**延性**行為，構材會大量伸長、有明顯預警，降伏後仍能承載（應變硬化），不會立即倒塌；淨斷面斷裂屬**脆性**行為，一斷即失去承載力，後果嚴重。
2. **發生範圍不同**：降伏發生在全長的毛斷面，應力分布均勻、預測準確；斷裂發生在螺栓孔所在的局部淨斷面，有應力集中、剪力遲滯、孔緣損傷等不確定因素。
3. **材料變異**：$F_u$ 的變異與 $F_u/F_y$ 比值隨鋼種而異，對斷裂需保留較大餘裕。
4. **設計理念**：希望構材「先降伏、後斷裂」，以延性破壞控制，因此斷裂側要更保守。

### （四）依局部挫屈特性的四種斷面

以受壓肢材的寬厚比 $\lambda = b/t$（或 $h/t_w$）與規範限值比較：

| 分類 | 寬厚比 | 行為 |
|:---|:---|:---|
| ① **塑性設計斷面** | $\lambda \le \lambda_{pd}$ | 可達塑性彎矩 $M_p$，並有足夠轉動能力形成塑性鉸、產生彎矩重分配；用於塑性設計與耐震韌性構材 |
| ② **結實斷面**（compact） | $\lambda_{pd} < \lambda \le \lambda_p$ | 局部挫屈前可達 $M_p$，但轉動能力有限 |
| ③ **半結實斷面**（noncompact） | $\lambda_p < \lambda \le \lambda_r$ | 局部挫屈前可達初始降伏 $M_y$（含殘留應力影響），但達不到 $M_p$ |
| ④ **細長肢斷面**（slender element） | $\lambda > \lambda_r$ | 在**彈性範圍**即發生局部挫屈，強度須折減（$Q$ 係數或有效寬度） |

（例：國內規範熱軋 I 型梁翼板 $\lambda_{pd} = 14/\sqrt{F_y}$、$\lambda_p = 17/\sqrt{F_y}$、$\lambda_r = 25/\sqrt{F_y}$，$F_y$ 以 t/cm² 計。）

### （五）臨界長細比 $C_c$

**定義：** ASD 柱公式中，**彈性挫屈與非彈性挫屈的分界細長比**，為尤拉臨界應力等於 $F_y/2$ 時的 $KL/r$：

$$F_e = \frac{\pi^2E}{(KL/r)^2} = \frac{F_y}{2}\quad\Rightarrow\quad C_c = \sqrt{\frac{2\pi^2E}{F_y}}$$

**理論背景：**
1. **殘留應力**：熱軋型鋼冷卻不均，翼板尖端殘留壓應力最大約 $0.3$～$0.5F_y$。柱受壓時，外加應力加上殘留壓應力達 $F_y$ 的部位先降伏，勁度下降。CRC（Column Research Council）取殘留應力 $0.5F_y$ 作為代表值 → 平均應力超過 $F_y/2$ 後柱即進入非彈性。
2. **兩段公式**：
   - $KL/r \ge C_c$：全斷面仍彈性 → 尤拉公式，$F_a = \dfrac{12\pi^2E}{23(KL/r)^2}$（$FS = 23/12$）
   - $KL/r < C_c$：部分降伏 → 以切線模數理論為基礎的 CRC 拋物線，$F_a = \dfrac{\left[1 - \dfrac{(KL/r)^2}{2C_c^2}\right]F_y}{FS}$，$FS = \dfrac{5}{3} + \dfrac{3(KL/r)}{8C_c} - \dfrac{(KL/r)^3}{8C_c^3}$
3. 兩段在 $KL/r = C_c$ 處連續（拋物線在該點應力為 $F_y/2$）。

**數值例：** $F_y = 2.5$ t/cm²、$E = 2040$ t/cm² → $C_c = 126.9$；$F_y = 3.5$ t/cm² → $C_c = 107.3$（高強度鋼的 $C_c$ 較小）。

**易混淆：** $C_c$ 不是細長比上限；受壓構材的細長比限制是 $KL/r \le 200$。
