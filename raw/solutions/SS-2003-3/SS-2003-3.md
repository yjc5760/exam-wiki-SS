## 1. 原始題目重述 (Problem Restatement)

如圖示長肢背對背雙角鋼受拉構材與柱之接合，接合全部採用標稱直徑 19 mm 之 A325X 承壓型螺栓（標準孔），螺栓孔附近之變形非為設計之考量因素。計算時必須扣除之螺栓孔徑為 22 mm。已知柱和 WT 型鋼強度足夠。（25 分）

（一）試依極限設計法決定**雙角鋼與 WT 型鋼腹板**接合所需螺栓數量。假設螺栓至構材邊距大於 1.5 倍之螺栓直徑，且螺栓心距大於 3 倍之螺栓直徑，並將螺栓排成一列。**不必考慮塊狀剪力。**

（二）已知**柱和 WT 型鋼以 8 顆螺栓接合**，試依極限設計法此接合強度是否足夠？

**參考資料：** 構材之 $F_y = 2.5$ t/cm²、$F_u = 4.1$ t/cm²；雙角鋼：厚度 $t = 9.5$ mm、雙角鋼總面積 $A_g = 34.45$ cm²；螺栓：斷面積 $A_b = 2.85$ cm²，$F_v = 4.2$ t/cm²，$F_t = 6.3$ t/cm²；$P_n = F_yA_g$，$\phi_t = 0.9$；$P_n = F_uA_e$，$\phi_t = 0.75$。

## 2. 考題核心精神與出題者意圖 (Core Concepts & Examiner's Intent)

本題是一個**兩段式傳力**的斜撐接頭：

```
雙角鋼（拉力構材） ──(一) 一列螺栓、雙剪──▶ WT 腹板 ──WT 本身（題目說強度足夠）──▶ WT 翼板 ──(二) 8 顆螺栓、拉＋剪──▶ 柱翼板
```

**出題意圖：**
1. **（一）設計題**：題目沒給外力，接合要能發揮構材本身的設計強度 → 先算構材 $\phi_tP_n$（降伏、斷裂取小），再以「單栓強度」反推顆數。關鍵是看出**雙角鋼夾 WT 腹板＝雙剪**。
2. **（二）檢核題**：力是斜的（3:4），到了柱面，水平分量把螺栓**拉離柱面**、垂直分量讓螺栓**受剪** → 承壓型螺栓的**拉剪互制**。
3. 題目刻意交代「變形非設計考量」、「邊距 > 1.5d、心距 > 3d」（對應背面承壓表第 1 款）、「不必考慮塊狀剪力」、「扣除孔徑 22 mm」；背面還印了拉剪互制式 $F_t = 8.2 - 1.9f_v$——這些都是作答要照用的條件。

## 4. 步驟化詳細計算過程 (Step-by-Step Detailed Calculation)

### 4.1 構材設計強度（兩小題共用的設計力）

**全斷面降伏：**
$$\phi_tP_n = 0.9\times2.5\times34.45 = 77.51\ \text{t}$$

**淨斷面斷裂：** 兩支角鋼各扣一個孔（單列螺栓），扣除孔徑依題目取 2.2 cm：
$$A_n = 34.45 - 2\times2.2\times0.95 = 30.27\ \text{cm}^2$$

只有長肢連接、短肢未連接 → 有剪力遲滯。角鋼尺寸未給，無法算 $1 - \bar x/L$；依舊版 LRFD（B3）表列，非 W 形斷面、每列螺栓 ≥ 3 顆時 $U = 0.85$（（一）的結果為 5 顆，符合）：
$$A_e = 0.85\times30.27 = 25.73\ \text{cm}^2,\qquad \phi_tP_n = 0.75\times4.1\times25.73 = 79.12\ \text{t}$$

$$\boxed{\phi_tP_n = \min(77.51,\ 79.12) = 77.51\ \text{t}\ \ \text{（降伏控制）}}$$

### 4.2（一）雙角鋼與 WT 腹板所需螺栓數

**單栓剪力（雙剪）：** 螺栓穿過「角鋼—WT 腹板—角鋼」，兩個剪力面；A325X 螺紋不在剪力面上，$F_v = 4.2$ t/cm²：
$$\phi R_v = 0.75\times4.2\times2.85\times2 = 17.96\ \text{t/顆}$$

**單栓承壓：** 邊距 ≥ 1.5d、心距 ≥ 3d、一列多顆 → 背面承壓表第 1 款；題目說孔附近變形非設計考量 → 照考卷表 $R_n = 2.4dtF_u$。WT 強度足夠，只檢核兩支角鋼（總厚 $2\times0.95 = 1.9$ cm）：
$$\phi R_p = 0.75\times2.4\times1.9\times1.9\times4.1 = 26.64\ \text{t/顆} > 17.96$$

→ 單栓由剪力控制，17.96 t。

$$n = \frac{77.51}{17.96} = 4.32 \quad\Rightarrow\quad \boxed{n = 5\ \text{顆（排成一列）}}$$

檢核：$5\times17.96 = 89.8\ \text{t} \ge 77.51\ \text{t}$ ✓；每列 5 顆 ≥ 3 顆，$U = 0.85$ 的前提成立 ✓。（塊狀剪力依題意不檢核。）

### 4.3（二）WT 翼板與柱的 8 顆螺栓

**設計力：** 取構材設計強度 $P = 77.51$ t，沿 3:4 方向：
$$T = \tfrac{4}{5}P = 62.01\ \text{t（垂直柱面，使螺栓受拉）},\qquad V = \tfrac{3}{5}P = 46.51\ \text{t（平行柱面，使螺栓受剪）}$$

作用線通過螺栓群中心（圖示），8 顆均分：
$$t_u = \frac{62.01}{8} = 7.75\ \text{t},\qquad v_u = \frac{46.51}{8} = 5.81\ \text{t}$$

**剪力檢核（單剪）：**
$$f_v = \frac{5.81}{2.85} = 2.04\ \text{t/cm}^2 \le \phi F_v = 0.75\times4.2 = 3.15\ \text{t/cm}^2\ \ \checkmark$$

**拉剪互制（承壓型 A325）：** 依考卷背面表，$F_t = 8.2 - 1.9f_v \le 6.3$ t/cm²，$\phi = 0.75$：
$$F_t' = 8.2 - 1.9\times2.04 = 4.32\ \text{t/cm}^2 \le 6.3\ \text{t/cm}^2$$
$$\phi R_t' = 0.75\times4.32\times2.85 = 9.24\ \text{t/顆} \ \ge\ t_u = 7.75\ \text{t}\ \ \checkmark$$

（若依 AISC LRFD 原表對螺紋不在剪力面的 A325-X：$F_t' = 117 - 1.5f_v$ ksi $= 8.23 - 1.5\times2.04 = 5.17$ t/cm²，$\phi R_t' = 11.04$ t，結論相同。）

**雙路徑驗算（以題給 $F_t = 6.3$ 做圓形互制）：**
$$\left(\frac{7.75}{0.75\times6.3\times2.85}\right)^2 + \left(\frac{5.81}{0.75\times4.2\times2.85}\right)^2 = 0.576^2 + 0.648^2 = 0.75 \le 1.0\ \ \checkmark$$

**柱面承壓：** 柱與 WT 強度足夠（題目）。

$$\boxed{\text{8 顆螺栓接合強度足夠（拉力使用率 0.84、剪力 0.65）}}$$

> 設計力的取法：接合要能傳遞構材的設計強度，故取 $P = \phi_tP_n = 77.51$ t。若誤取（一）螺栓群的強度 $5\times17.96 = 89.8$ t：$f_v = 2.36$、$F_t' = 3.71$、$\phi R_t' = 7.93$ t < $t_u = 8.98$ t，會判為不足——設計力的定義會改變結論，作答時要寫清楚。

## 5. 關鍵爭議點與進階探討 (Critical Issues & Advanced Discussion)

### 5.1 為什麼是「雙剪」？

「長肢背對背」的雙角鋼中間留有間隙，正好夾住 WT 的腹板。螺栓穿過三層鋼板，構材的力由兩支角鋼分別傳給中間的 WT 腹板，每顆螺栓有**兩個剪力面**。誤用單剪會讓顆數算成 $77.51/8.98 = 8.6 \to 9$ 顆，多出將近一倍。

### 5.2 考卷承壓表與 AISC 的對應相反

考卷背面寫「變形**非**為設計考量 → $R_n = 2.4dtF_u$；變形**為**設計考量 → $R_n = L_etF_u \le 3.0dtF_u$」。AISC LRFD J3.10 的原意相反：變形是設計考量時用較保守的 $2.4dtF_u$，不是考量時才放寬到 $L_etF_u \le 3.0dtF_u$。

本題照考卷表取 $2.4dtF_u$（26.64 t/顆），不控制。若依 AISC 原意取 $L_etF_u$、且 $L_e$ 只知「大於 1.5d」而取 1.5d：最靠端部那顆 $\phi R_n = 0.75\times1.5\times1.9\times1.9\times4.1 = 16.65$ t，略小於雙剪 17.96 t；5 顆的群組強度 $16.65 + 4\times17.96 = 88.5$ t ≥ 77.51 t，**仍為 5 顆**。兩種讀法答案一致。

### 5.3 撬力（prying action）

WT 翼板受拉時若翼板不夠厚，翼板外緣會壓在柱面上產生撬力，使螺栓實際拉力大於 $t_u$。題目未給螺栓列距與翼板寬度，且說「柱和 WT 強度足夠」，故不計；實務設計須檢核（$t_f = 18.9$ mm 相對 19 mm 螺栓屬厚翼板，撬力通常不大）。

### 5.4 舊解錯在哪裡

| 項目 | 舊解 | 更正 |
|:---|:---|:---|
| 構材 | 「WT13.5×470 拉力構材」 | 構材是**雙角鋼**，WT 是接頭板 |
| （一） | 已知 3 顆，求各破壞模式強度 | **決定顆數** → 5 顆 |
| 剪力面 | 單剪 | **雙剪** |
| 扣除孔徑 | 2.2 + 0.2 = 2.4 cm | 題目明定 **2.2 cm** |
| 淨面積 | $34.45 - 2.4\times1.24$（扣 WT 腹板厚） | $34.45 - 2\times2.2\times0.95$（兩支角鋼各扣一孔） |
| （二） | 8 顆的塊狀剪力 | WT 與柱之間 8 顆的**拉剪互制** → 足夠 |
