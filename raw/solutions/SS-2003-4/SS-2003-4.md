⚠️ **原卷為單一問句**（只問「是否滿足 ASD 之要求」），並未分成 (一)(二)(三) 小題。

**⚠️ 兩項關鍵判讀（決定 $C_m$，也是本題最易失分處）：**

| 項目 | 正確判讀 | 依據 |
|------|---------|------|
| 構架型式 | **有側撐（含斜撐）構架，無側移** | 柱頂有水平滾支承、柱底為鉸支承，兩端水平位移均受束制；且題目給 $K_x = K_y = 1.0$（無側移之鉸-鉸值） |
| 端彎矩曲率 | **雙曲率（反向曲率）**，$M_1/M_2 = +1$ | 兩端外加力偶**同轉向**（皆逆時針）→ 內力彎矩圖反對稱、中點變號 |

> **曲率判定的通用規則（可自行驗證，不必背）**：長度 $L$ 之構材兩端各施加外力偶 $C_A$、$C_B$（逆時針為正），則內力彎矩 $M(x) = (C_A+C_B)x/L - C_A$。
> - 兩端**反轉向**（$C_B = -C_A$）→ $M(x) = -C_A$ 為**定值** → **單曲率**（$M_1/M_2 = -1$，$C_m = 1.0$）
> - 兩端**同轉向**（$C_B = C_A = M$）→ $M(x) = 2Mx/L - M$，於 $x=0$ 為 $-M$、$x=L/2$ 為 $0$、$x=L$ 為 $+M$ → **反對稱、雙曲率**（$M_1/M_2 = +1$，$C_m = 0.2$）
>
> 本題兩端力偶同為逆時針 ⇒ **雙曲率** ⇒ $M_1/M_2 = +1$。

**W12×170 斷面性質（A36）：**

| 性質 | 數值 |
|------|------|
| 斷面積 $A$ | 322.58 cm² |
| 強軸斷面模數 $S_x$ | 3850.96 cm³ |
| 強軸迴轉半徑 $r_x$ | 14.58 cm |
| 弱軸斷面模數 $S_y$ | 1348.66 cm³ |
| 弱軸迴轉半徑 $r_y$ | 8.18 cm |
| 緊密撓度極限距 $L_c$ | 4.05 m |
| 非緊密撓度極限距 $L_u$ | 19.6 m |

**材料性質：**

$$F_y = 2.50\ \text{tf/cm}^2,\quad F_u = 4.10\ \text{tf/cm}^2,\quad E = 2100\ \text{tf/cm}^2$$

**ASD 設計公式（題目提供）：**

$$C_c = \sqrt{\frac{2\pi^2 E}{F_y}}$$

$$\frac{KL}{r} \leq C_c:\quad F_a = \frac{\left[1-\dfrac{(KL/r)^2}{2C_c^2}\right]F_y}{\dfrac{5}{3}+\dfrac{3(KL/r)}{8C_c}-\dfrac{(KL/r)^3}{8C_c^3}}$$

$$\frac{KL}{r} > C_c:\quad F_a = \frac{12\pi^2 E}{23(KL/r)^2}$$

$$F'_{ex} = \frac{12\pi^2 E}{23(KL_b/r_x)^2},\quad F'_{ey} = \frac{12\pi^2 E}{23(KL_b/r_y)^2}$$

**互制方程式（$f_a/F_a > 0.15$）：**

$$\frac{f_a}{F_a} + \frac{C_{mx}f_{bx}}{\left(1-\dfrac{f_a}{F'_{ex}}\right)F_{bx}} + \frac{C_{my}f_{by}}{\left(1-\dfrac{f_a}{F'_{ey}}\right)F_{by}} \leq 1.0 \tag{穩定式}$$

$$\frac{f_a}{0.6F_y} + \frac{f_{bx}}{F_{bx}} + \frac{f_{by}}{F_{by}} \leq 1.0 \tag{強度式}$$

**互制方程式（$f_a/F_a \leq 0.15$）：**

$$\frac{f_a}{F_a} + \frac{f_{bx}}{F_{bx}} + \frac{f_{by}}{F_{by}} \leq 1.0$$

**$C_m$ 之取值規定（原卷逐字列出三款）：**

| 款 | 條件 | $C_m$ |
|:--:|------|:---:|
| (一) | 可側向位移構架之受壓構材 | $0.85$ |
| (二) | 含斜撐構架中之受束制壓力構材，**且在構材彎曲平面兩端點間無橫向載重時** | $0.6 - 0.4(M_1/M_2)$ |
| (三) 1. | 含斜撐構架之受壓構材，兩端點間受橫向載重、構材端點**受束制** | $0.85$ |
| (三) 2. | 含斜撐構架之受壓構材，兩端點間受橫向載重、構材端點**未束制** | $1.00$ |

> **本題適用第 (二) 款**：柱頂水平滾支承＋柱底鉸支承 ⇒ 側移受束制（含斜撐構架）；兩端點間**無橫向載重**（只有端彎矩）。
> ⚠️ 原卷所印之 $C_m = 0.6 - 0.4(M_1/M_2)$ **未加任何下限**。經查台灣「鋼構造建築物鋼結構設計技術規範」**容許應力設計法第 8.2 節式 (8.2-5)** 亦無下限，其解說更明言舊式的「$\geq 0.4$」限制「在 1986 年版的 AISC-LRFD 規範及本規範中**均已不再採用**」；AISC ASD 9th Ed.（1989）§H1 同樣無下限。故本題**不設 $C_m \geq 0.4$ 的地板值**。

**求：** 檢核該構材是否滿足容許應力法（ASD）之要求。（單一問句，25 分）

**核心觀念：** ASD 梁柱桿件設計的兩個關鍵——$C_m$（彎矩放大係數，描述二階效應的影響）和互制方程式（穩定式 + 強度式同時檢核）。

**出題意圖：**

2. 測驗 $F'_e$（歐拉放大應力）的計算——與 $F_a$ 不同，$F'_e$ 無安全係數
3. 測驗 $C_m$ 在不同約束條件與載重型式下的三種取值邏輯
4. 雙軸彎矩（$M_x$ + $M_y$ 同時存在）的互制疊加方式

## 3. 解題戰略地圖與陷阱分析 (Strategic Roadmap & Trap Analysis)

**解題順序：**

$$f_a,f_{bx},f_{by} \to F_a \to f_a/F_a比較0.15 \to F_{bx},F_{by} \to F'_{ex},F'_{ey} \to C_m \to \text{互制檢核}$$

**關鍵陷阱：**

1. **$F_a$ vs $F'_e$ 的差異**：$F_a$ 有安全係數（1.67–1.92），用於 $f_a/F_a$ 的軸壓部分；$F'_e = 12\pi^2E/[23(KL/r)^2]$ **沒有安全係數但乘了 12/23**，用於分母中的放大係數，兩者不可互換。

2. **兩個互制方程式都必須滿足**：$f_a/F_a > 0.15$ 時，「穩定式」和「強度式」**兩式都要通過**，取最不利者。

3. **$C_m$ 的款別與曲率符號（本題唯一的觀念關卡）**：本題柱頂水平滾支承＋柱底鉸接 ⇒ **有側撐（無側移）**、且兩端點間無橫向載重 ⇒ 適用 $C_m = 0.6 - 0.4(M_1/M_2)$，**不是** 0.85。兩端力偶同轉向 ⇒ **雙曲率** ⇒ $M_1/M_2 = \mathbf{+1}$（正值）⇒ $C_m = 0.6 - 0.4 = \mathbf{0.2}$。**符號記錯（誤取 $-1$）會得 $C_m = 1.0$，穩定式由 0.595 暴增到 1.250，結論翻轉。**

4. **$L_b < L_c$ → $F_{bx} = 0.66F_y$**：側撐間距 $L_b = 3.7\ \text{m} < L_c = 4.05\ \text{m}$ 在緊密範圍，可取最大值。

## 4. 步驟化詳細計算過程 (Step-by-Step Detailed Calculation)

### 步驟 1：計算實際應力

$$f_a = \frac{P}{A} = \frac{182}{322.58} = 0.5643\ \text{tf/cm}^2$$

$$f_{bx} = \frac{M_x}{S_x} = \frac{27.68 \times 100}{3850.96} = \frac{2768}{3850.96} = 0.7188\ \text{tf/cm}^2$$

$$f_{by} = \frac{M_y}{S_y} = \frac{8.30 \times 100}{1348.66} = \frac{830}{1348.66} = 0.6155\ \text{tf/cm}^2$$

---

### 步驟 2：計算容許軸壓應力 $F_a$

**臨界細長比 $C_c$：**

$$C_c = \sqrt{\frac{2\pi^2 E}{F_y}} = \sqrt{\frac{2 \times 9.870 \times 2100}{2.5}} = \sqrt{16{,}581} = 128.8$$

**計算 $KL/r$（控制軸）：**

$$\frac{K_x L}{r_x} = \frac{1.0 \times 370}{14.58} = 25.38 \quad \text{（強軸）}$$

$$\frac{K_y L}{r_y} = \frac{1.0 \times 370}{8.18} = 45.23 \quad \text{（弱軸，控制）}$$

$$\frac{KL}{r} = 45.23 < C_c = 128.8 \Rightarrow \text{非彈性挫屈，用拋物線公式}$$

**分子：**

$$\left[1-\frac{(45.23)^2}{2\times(128.8)^2}\right]F_y = \left[1-\frac{2046}{33{,}163}\right]\times 2.5 = 0.9383\times 2.5 = 2.346\ \text{tf/cm}^2$$

**分母（令 $\alpha = KL/r/C_c = 45.23/128.8 = 0.3512$）：**

$$\frac{5}{3} + \frac{3\alpha}{8} - \frac{\alpha^3}{8} = 1.6667 + \frac{3\times0.3512}{8} - \frac{(0.3512)^3}{8}$$

$$= 1.6667 + 0.1317 - \frac{0.04334}{8} = 1.6667 + 0.1317 - 0.00542 = 1.793$$

$$\boxed{F_a = \frac{2.346}{1.793} = 1.308\ \text{tf/cm}^2}$$

---

### 步驟 3：判斷互制方程式類型

$$\frac{f_a}{F_a} = \frac{0.5643}{1.308} = 0.431 > 0.15$$

→ 使用**完整互制方程式**（穩定式 + 強度式均需檢核）

---

### 步驟 4：容許彎曲應力 $F_{bx}$、$F_{by}$

**強軸彎曲（確認 $L_b$ vs $L_c$）：**

$$L_b = 3.7\ \text{m} < L_c = 4.05\ \text{m} \Rightarrow F_{bx} = 0.66F_y = 0.66\times2.5 = 1.65\ \text{tf/cm}^2$$

**弱軸彎曲（I 型斷面）：**

$$F_{by} = 0.75F_y = 0.75\times2.5 = 1.875\ \text{tf/cm}^2$$

### 步驟 5：計算歐拉放大應力 $F'_{ex}$、$F'_{ey}$

$$F'_{ex} = \frac{12\pi^2 E}{23(KL/r_x)^2} = \frac{12\times9.870\times2100}{23\times(25.38)^2}$$

$$= \frac{248{,}724}{23\times644.1} = \frac{248{,}724}{14{,}814} = \boxed{16.79\ \text{tf/cm}^2}$$

$$F'_{ey} = \frac{12\pi^2 E}{23(KL/r_y)^2} = \frac{248{,}724}{23\times(45.23)^2}$$

$$= \frac{248{,}724}{23\times2046} = \frac{248{,}724}{47{,}058} = \boxed{5.286\ \text{tf/cm}^2}$$

### 步驟 6：判定構架型式與曲率，求 $C_m$

#### 6.1 構架型式：有側撐（無側移）

由附圖：**柱頂為靠牆之水平滾支承**（束制水平位移、可自由轉動與豎向滑動），**柱底為鉸支承**。兩端水平位移均受束制 ⇒ 本柱**不可側移**，屬「含斜撐構架中之受束制壓力構材」。

**旁證：** 題目給定 $K_x = K_y = 1.0$。$K = 1.0$ 正是「**無側移**、鉸接-鉸接」的值（見 102 年考卷 K 值表）；若為可側移構架，$K$ 至少為 1.2～2.0。若構架真能側移而仍取 $K = 1.0$，$F_a$ 會被嚴重高估，題目不會如此設定。

⇒ **適用第 (二) 款**：$C_m = 0.6 - 0.4(M_1/M_2)$（**不是** 0.85）

#### 6.2 曲率：雙曲率，$M_1/M_2 = +1$

兩端外加力偶大小相等（強軸皆 27.68 t-m、弱軸皆 8.30 t-m），且**轉向相同**（皆逆時針，見 §1 圖說之目視判讀）。

代入通用式 $M(x) = (C_A + C_B)x/L - C_A$，以 $C_A = C_B = M$：

$$M(0) = -M,\qquad M(L/2) = 0,\qquad M(L) = +M$$

彎矩圖**反對稱、於中點變號** ⇒ **雙曲率（反向曲率）**。依規範「雙曲率時 $M_1/M_2$ 為正值」：

$$\frac{M_1}{M_2} = +1 \quad(\text{兩軸皆同})$$

![SS-2003-4 兩格對照：左為兩端力偶同轉向，彎矩圖反對稱、中點變號、雙曲率、M1/M2 = +1、Cm = 0.2；右為兩端反轉向，彎矩沿全長定值、單曲率、M1/M2 = −1、Cm = 1.0](figs/SS-2003-4-fig-2-curvature.svg)

#### 6.3 $C_m$

$$\boxed{C_{mx} = C_{my} = 0.6 - 0.4(+1) = 0.2}$$

**無下限**（見 §1 之規範查證）。

> ⚠️ **雙曲率是最有利的端彎矩型態**：最大彎矩在端點、而 P-δ 二階撓曲的最大值在中點附近，兩者不疊加，故放大係數極小。反之單曲率（定值彎矩）最不利，$C_m = 1.0$。

**$C_m$ 取值敏感度（同一題四種可能）：**

| $C_m$ | 來源 | 穩定式 | 判定 |
|:---:|------|:---:|:---:|
| **0.2** | **正解**（雙曲率，無下限） | **0.595** | **OK** |
| 0.4 | 若誤用已廢止的 $\geq 0.4$ 下限 | 0.759 | OK |
| 0.85 | 若誤判為可側移構架 | 1.127 | N.G. |
| 1.0 | 若曲率符號記反（誤為單曲率） | 1.250 | N.G. |

**四者的強度式恆為 1.140（不含 $C_m$），故「不滿足 ASD」的結論不因 $C_m$ 而改變；但「哪一式控制」完全取決於 $C_m$。**

### 步驟 7：互制方程式驗算

**放大分母計算：**

$$1 - \frac{f_a}{F'_{ex}} = 1 - \frac{0.5643}{16.79} = 1 - 0.0336 = 0.9664$$

$$1 - \frac{f_a}{F'_{ey}} = 1 - \frac{0.5643}{5.286} = 1 - 0.1068 = 0.8932$$

**穩定式（$f_a/F_a > 0.15$ → 需滿足）：**

$$\frac{f_a}{F_a} + \frac{C_{mx}f_{bx}}{\left(1-\dfrac{f_a}{F'_{ex}}\right)F_{bx}} + \frac{C_{my}f_{by}}{\left(1-\dfrac{f_a}{F'_{ey}}\right)F_{by}} \leq 1.0$$

$$= 0.4312 + \frac{0.2\times0.7188}{0.9664\times1.65} + \frac{0.2\times0.6155}{0.8933\times1.875}$$

$$= 0.4312 + \frac{0.14376}{1.5946} + \frac{0.12310}{1.6749}$$

$$= 0.4312 + 0.0902 + 0.0735 = \boxed{0.595 \leq 1.0 \quad \textbf{OK}}$$

**強度式（同樣需滿足）：**

$$\frac{f_a}{0.6F_y} + \frac{f_{bx}}{F_{bx}} + \frac{f_{by}}{F_{by}} \leq 1.0$$

$$= \frac{0.5643}{1.50} + \frac{0.7188}{1.65} + \frac{0.6155}{1.875}$$

$$= 0.3762 + 0.4356 + 0.3282 = \boxed{1.140 > 1.0 \quad \textbf{N.G. ← 控制}}$$

> **結論**：**穩定式通過（59.5%）、強度式不通過（114.0%）** ⇒ 該構材**不滿足** ASD 之要求，且**由斷面強度（全斷面降伏）控制**，而非由二階穩定控制。
> 這與「$C_m = 0.85$ 兩式皆 N.G.」的舊結論在**判定**上相同、在**成因**上完全不同：本柱的細長比很小（$KL/r_y = 45.2$，僅為 $C_c$ 的 35%），二階放大本就微弱（$1-f_a/F'_{ey} = 0.893$），再加上雙曲率的 $C_m = 0.2$，穩定式自然不會控制。真正的問題是**斷面應力總和已超出容許值 14%**。
> **改善方向**：強度式三項中 $f_{bx}/F_{bx} = 0.436$ 最大，$f_{by}/F_{by} = 0.328$ 次之 —— 應加大斷面（尤其弱軸 $S_y$），或減小端彎矩。

## 5. 關鍵爭議點與進階探討 (Critical Issues & Advanced Discussion)

### Q：兩個方程式各自捕捉什麼失效模式？

| 方程式 | 名稱 | 主要考量 | 不足時代表 |
|--------|------|---------|-----------|
| 穩定式 | Stability interaction | 二階 P-δ 放大（$C_m$/$F'_e$）+ 軸壓 | 柱可能在彎矩放大後挫屈 |
| 強度式 | Strength interaction | 截面全截面降伏 | 柱在無挫屈條件下截面先達到降伏 |

本題**穩定式 0.595 通過、強度式 1.140 不通過** —— 代表桿件的二階穩定有充裕餘裕（細長比小＋雙曲率），真正的瓶頸是**斷面應力總和已達降伏**。這正是「兩式必須分別檢核、取最不利者」的價值：只算穩定式會誤判為安全。

### Q：$F'_e$ 為何與 $F_a$ 的公式相似卻不同？

$$F'_e = \frac{12\pi^2 E}{23(KL/r)^2}$$

- 分子：$12\pi^2$ 而非 $1\pi^2$
- 分母：$23(KL/r)^2$ 而非 $1(KL/r)^2$

**本質**：$F'_e = (12/23) \times F_{e,Euler}$，其中 12/23 ≈ 0.522 是 Euler 彈性挫屈的折減係數（安全係數 23/12 ≈ 1.92）。$F'_e$ 用在分母放大係數中，目的是通過「$1-f_a/F'_e$」計入 P-δ 效應，並非用於計算容許應力。

### Q：若改用 LRFD 法，如何對應？

| ASD 元素 | LRFD 對應 |
|---------|-----------|
| $f_a/F_a + C_m f_b/(1-f_a/F'_e)F_b$ | $P_u/\phi_c P_n + \tfrac{8}{9}\big(B_1M_{ntx}/\phi_b M_{nx} + \cdots\big)$（H1-1a） |
| $C_m$ 係數 | $B_1$ 放大係數（$B_1 = C_m/(1-P_u/P_{e1})$） |
| $F'_e$ | $P_{e1}$（彈性挫屈載重，$F'_e = \tfrac{12}{23}P_e/A$） |
| $F_{bx} = 0.66F_y$（對 $S_x$） | $\phi_bM_p = 0.9F_yZ_x$（對 $Z_x$）→ 新規範可用塑性儲備 |
| $F_{by} = 0.75F_y$（對 $S_y$） | $\phi_b\min(F_yZ_y,\,1.6F_yS_y)$ |
| 兩式（穩定式＋強度式） | **單一式** H1-1a／H1-1b |

LRFD 的 $B_1$ 放大係數本質上就是 ASD 穩定式中 $C_m/(1-f_a/F'_e)$ 的變形，兩者邏輯完全相同；但 **LRFD／AISC 360 已把 ASD 的「兩式」合併為一式**（二階彎矩已含放大，故不需另設穩定式）。

### 為何 ASD 的強度式用 $0.6F_y$ 而不是 $F_a$？

強度式 $f_a/(0.6F_y) + f_{bx}/F_{bx} + f_{by}/F_{by} \leq 1.0$ 檢核的是**斷面的降伏**，與桿件細長無關，故軸壓項的分母取「短柱」的容許應力 $0.6F_y$（即 $F_y/1.67$），而非含細長比折減的 $F_a$。本題 $F_a = 1.308 < 0.6F_y = 1.50$，所以**穩定式的軸壓項（0.431）反而大於強度式的軸壓項（0.376）**；但強度式的兩個彎矩項未經 $C_m$ 縮減，總和仍較大。

### 6.3 依 AISC 360-16 重算（ASD，$\Omega = 1.67$）

**軸壓：**
$$F_e = \frac{\pi^2E}{(KL/r_y)^2} = \frac{9.8696 \times 2100}{45.23^2} = 10.130\ \text{tf/cm}^2, \qquad \frac{F_y}{F_e} = 0.2468 \leq 2.25$$
$$F_{cr} = 0.658^{0.2468}\,F_y = 0.9019 \times 2.50 = 2.255\ \text{tf/cm}^2$$
$$P_n = 2.255 \times 322.58 = 727.3\ \text{tf}, \qquad P_c = \frac{P_n}{1.67} = 435.5\ \text{tf}$$
$$\frac{P_r}{P_c} = \frac{182}{435.5} = 0.418 \geq 0.2 \Rightarrow \textbf{H1-1a}$$

（對照台灣 ASD 之 $f_a/F_a = 0.431$，僅差 3%——兩者的軸壓折減幾乎等價。）

**撓曲：** $L_b = 370$ cm，$L_p = 1.76r_y\sqrt{E/F_y} = 1.76(8.18)(28.98) = 417$ cm $> L_b$ ⇒ 塑性區，$M_{nx} = M_{px}$
$$M_{cx} = \frac{F_yZ_x}{1.67} = \frac{2.50 \times 4506}{1.67} = 6746\ \text{tf·cm} = 67.46\ \text{tf·m}$$
$$M_{ny} = \min(F_yZ_y,\ 1.6F_yS_y) = \min(5162,\ 5395) = 5162\ \text{tf·cm} \Rightarrow M_{cy} = \frac{5162}{1.67} = 30.91\ \text{tf·m}$$

> 註：台灣 ASD 的 $L_c = 4.05$ m $> L_b = 3.7$ m 與 AISC 的 $L_p = 4.17$ m $> L_b$ 判定一致 ✓。

**二階放大（附錄 8，ASD 之 $\alpha = 1.6$）：**
$$P_{e1x} = \frac{\pi^2EI_x}{L^2} = \frac{9.8696(2100)(68{,}573)}{370^2} = 10{,}382\ \text{tf}, \qquad \frac{\alpha P_r}{P_{e1x}} = \frac{1.6(182)}{10{,}382} = 0.028$$
$$P_{e1y} = \frac{9.8696(2100)(21{,}585)}{370^2} = 3{,}268\ \text{tf}, \qquad \frac{\alpha P_r}{P_{e1y}} = 0.089$$
$$B_{1x} = \frac{0.2}{1-0.028} = 0.206 \to \mathbf{1.0}, \qquad B_{1y} = \frac{0.2}{1-0.089} = 0.220 \to \mathbf{1.0}$$

（$C_m = 0.2$ 太小，$B_1$ 均受 $\geq 1.0$ 下限控制 ⇒ **無放大**。）

**H1-1a：**
$$\frac{P_r}{P_c} + \frac{8}{9}\!\left(\frac{M_{rx}}{M_{cx}} + \frac{M_{ry}}{M_{cy}}\right) = 0.418 + \frac{8}{9}\!\left(\frac{27.68}{67.46} + \frac{8.30}{30.91}\right)$$
$$= 0.418 + \frac{8}{9}(0.410 + 0.269) = 0.418 + 0.365 + 0.239 = \mathbf{1.021 > 1.0} \quad \textbf{N.G.}$$
