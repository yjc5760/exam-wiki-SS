## 1. 原始題目重述

鋼結構極限強度設計法規範對於混凝土包覆梁之設計撓曲強度訂為 $\phi_bM_n$，$\phi_b = 0.9$，$M_n$ 依塑性應力分析而得。試依塑性應力分析，計算圖示混凝土包覆合成梁之標稱撓曲強度 $M_n$。假設鋼梁與鋼筋全斷面達降伏應力，並考慮鋼梁、主筋與混凝土之貢獻。鋼梁為 H488×300×11×18（$d \times b_f \times t_w \times t_f$，mm）之型鋼，置於梁斷面中心位置，鋼材 $F_y = 2.5$ tf/cm²，$F_u = 4.1$ tf/cm²。四支主筋為 D32 鋼筋（每支截面積 8.19 cm²），$F_y = 4200$ kgf/cm²。混凝土 $f'_c = 210$ kgf/cm²。（25 分）

*圖說（依考卷原圖 450 dpi 目視判讀）：斷面寬 50 cm、高 70 cm；H 型鋼置中，上下翼板外緣距斷面上下緣各 $(70 - 48.8)/2 = 10.6$ cm；四支 D32 位於四角，上下各 2 支，鋼筋中心距上、下緣各 8 cm（尺寸線量至鋼筋中心）。*

**單位換算（注意）：**

$$f'_c = 210\ \text{kgf/cm}^2 = 0.21\ \text{tf/cm}^2,\qquad 0.85f'_c = 0.1785\ \text{tf/cm}^2$$

$$F_{yr} = 4200\ \text{kgf/cm}^2 = 4.2\ \text{tf/cm}^2$$

## 2. 考題核心精神與出題者意圖

本題測驗**包覆型合成梁（SRC 梁）的塑性應力分布法**：混凝土受壓區取 $0.85f'_c$ 均勻應力，鋼骨與鋼筋各自全斷面降伏（受壓或受拉），由力平衡找塑性中性軸（PNA），再取力矩得 $M_n$。

關鍵在判斷 PNA 落在哪裡。混凝土強度只有鋼材的 1/12～1/20，靠混凝土單獨平衡全部鋼骨＋鋼筋拉力需要很深的壓力區；實際上 PNA 會往下進到型鋼上翼板以下，**上排鋼筋與上翼板都在受壓區**。

## 3. 解題戰略地圖與陷阱分析

**作戰計畫：**
1. 建立座標（頂面為 0、向下為正），列出各材料位置與降伏力
2. 先試 PNA 在上翼板以上：所需壓力區深度遠超過上翼板位置 → 不成立
3. 設 PNA 在腹板內（深度 $y$），以 $C = T$ 解 $y$
4. 對 PNA 取力矩求 $M_n$；$\phi_bM_n = 0.9M_n$

**陷阱分析：**

| 陷阱 | 說明 | 應對策略 |
|------|------|---------|
| ⚠️ $0.85f'_c$ 單位 | 210 kgf/cm² = **0.21** tf/cm²，$0.85f'_c = 0.1785$ tf/cm²；寫成 1.785 會讓混凝土強度放大 10 倍 | 換算後對照「混凝土約為鋼材 1/12」做合理性檢查 |
| ⚠️ PNA 位置 | 不能先假設 PNA 在混凝土頂部；要用力平衡試算 | 依序試「上翼板以上」→「腹板內」 |
| ⚠️ 上排鋼筋受壓 | PNA 在 13.3 cm，上排筋（8 cm）與上翼板受壓 | 受壓鋼材也以 $F_y$ 計 |

## 3.5 變數層次分析（Variable Hierarchy Analysis）

> 複習提示：解題後，在每個卡住的知識點「卡關?」欄標記 `⚠`；第二次複習時只看有 `⚠` 的項目。

**最終目標：** SRC 梁塑性應力分佈法 → 確定 PNA 位置 → 對 PNA 取矩求 $M_n$

### 主要公式（$\boxed{\phantom{x}}$ = 未知，待推導）

$$0.85f'_c\,b\,\boxed{y} + \sum F_{\text{鋼，壓}} = \sum F_{\text{鋼，拉}}\quad(\text{力平衡求 PNA 深度 } y)$$

$$\boxed{M_n} = \sum F_i\,|y_i - y|,\qquad \phi_bM_n = 0.9M_n$$

| 斷面 | 50 × 70 cm | 混凝土外廓 |
| 鋼梁 | H488×300×11×18 | 置中，頂緣距斷面頂 10.6 cm |
| $F_y$ | 2.5 tf/cm² | 鋼梁 |
| 主筋 | 4-D32（8.19 cm²/支），上下各 2 支 | 中心距上下緣 8 cm |
| $F_{yr}$ | 4.2 tf/cm² | 鋼筋 |
| $f'_c$ | 0.21 tf/cm² | 混凝土 |
| $\phi_b$ | 0.9 | 題目給定 |

### L2：需知識點推導

### 4.3 塑性中性軸（PNA）位置

**試 1：PNA 在上翼板以上（鋼骨全受拉）**

$$8.925y + 68.8 = 394.3 + 68.8\ \Rightarrow\ y = 44.2\ \text{cm} > 10.6\ \text{cm}\quad\text{✗（矛盾）}$$

**試 2：PNA 在上翼板內（$10.6 \le y \le 12.4$）**

$y = 12.4$ 時壓力 $= 8.925 \times 12.4 + 68.8 + 135.0 = 314.5$ t < 拉力 $124.3 + 135.0 + 68.8 = 328.1$ t → PNA 還要再往下 ✗

**試 3：PNA 在腹板內（$12.4 \le y \le 57.6$）**

$$\underbrace{8.925y + 68.8 + 135.0 + 2.75(y - 12.4)}_{C} = \underbrace{2.75(57.6 - y) + 135.0 + 68.8}_{T}$$

$$14.425y = 158.4 + 34.1\ \Rightarrow\ \boxed{y = 13.34\ \text{cm}}\quad(\text{落在腹板頂端下方 0.94 cm})\ \checkmark$$

|------|:---:|:---:|:---:|:---:|:---:|
| 混凝土 | 壓 | 119.10 | 6.67 | 6.67 | 794.7 |
| 上排鋼筋 | 壓 | 68.80 | 8.00 | 5.34 | 367.7 |
| 上翼板 | 壓 | 135.00 | 11.50 | 1.84 | 249.1 |
| 腹板受壓段 | 壓 | 2.60 | 12.87 | 0.47 | 1.2 |
| 腹板受拉段 | 拉 | 121.70 | 35.47 | 22.13 | 2,693.0 |
| 下翼板 | 拉 | 135.00 | 58.50 | 45.16 | 6,095.9 |
| 下排鋼筋 | 拉 | 68.80 | 62.00 | 48.66 | 3,347.3 |
| **合計** | | $C = T = 325.5$ | | | **13,548.9** |

$$\boxed{M_n = 13{,}549\ \text{tf}\cdot\text{cm} \approx 135.5\ \text{tf}\cdot\text{m}}$$

$$\phi_bM_n = 0.9 \times 135.5 = \boxed{121.9\ \text{tf}\cdot\text{m}}$$

**雙路徑驗算：** 以頂面為力矩中心，$M_n = \sum T_iy_i - \sum C_iy_i = 13{,}549$ tf·cm ✔。若扣除型鋼在受壓區排開的混凝土（上翼板與 0.94 cm 腹板處不計混凝土），PNA 移至 14.04 cm，$M_n = 135.3$ tf·m，差 0.2%。

## 5. 關鍵爭議點與進階探討

### 5.1 舊版解析的單位錯誤

舊版把 $0.85f'_c$ 寫成 $1.785$ tf/cm²（應為 0.1785），混凝土強度被放大 10 倍，於是只需 5.96 cm 的壓力區就能平衡全部鋼材拉力，得到「所有鋼骨與鋼筋都受拉」、$M_n = 170.3$ tf·m 的錯誤結果。

**合理性檢查：** 鋼材 $F_y = 2.5$ tf/cm²，混凝土 $0.85f'_c$ 只有 0.18 tf/cm²，約為鋼材的 1/14。一個 50 cm 寬、6 cm 深的混凝土塊（300 cm²）只能提供 54 t，遠小於型鋼 394 t 的拉力——看到 PNA 只有幾公分深就該警覺。

### 5.2 PNA 為何停在上翼板下方

壓力區混凝土貢獻有限，主要靠上翼板（135 t）與上排鋼筋（69 t）受壓來平衡。這兩項加上 12.4 cm 深的混凝土（111 t）已達 314 t，只差一點點，所以 PNA 只往腹板內走了 0.94 cm。

### 5.3 與純鋼梁的比較

$$M_{p,鋼} = F_yZ_x = 2.5 \times 3{,}099.8 = 7{,}750\ \text{tf}\cdot\text{cm} = 77.5\ \text{tf}\cdot\text{m}$$

包覆後 $M_n = 135.5$ tf·m，約為純鋼梁的 **1.75 倍**。增量主要來自上下鋼筋形成的力偶（約 $68.8 \times 54 = 3{,}715$ tf·cm）以及混凝土讓 PNA 上移後鋼骨拉力臂加長。
