## 2. 考題核心精神與出題者意圖 (Core Concepts & Examiner's Intent)

**核心考點：** LRFD 梁桿件設計三段式 LTB 流程：
1. 確認結實斷面（排除局部挫屈）
2. 計算 $L_p$、$L_r$，判斷控制極限狀態
3. 對各無束制段計算 $C_b$，求 $\phi_b M_n$
4. 以最大彎矩對應設計強度求解 $w_{n,cr}$

**出題者意圖：** 載重只放在兩側，讓中間 BC 段成為**均勻彎矩段**（$C_b = 1.0$，最不利），且 $L_b = 6$ m 恰好略大於 $L_r$ → 彈性 LTB 控制。測的是讀圖、彎矩圖與 $C_b$ 的判斷。

## 3. 解題戰略地圖與陷阱分析 (Strategic Roadmap & Trap Analysis)

**解題順序：**
```
① 局部挫屈（翼板、腹板）→ 確認結實斷面
② 計算 Mp、X1、X2、Lp、Lr
③ 比較 Lb = 600 cm 與 Lp、Lr
④ 各段計算 Cb → 求 φbMn（注意 Mn ≤ Mp 上限）
⑤ 各段對應彎矩需求 → 求解 wn,cr
```

**關鍵陷阱：**

| 陷阱 | 錯誤 | 正確 |
|------|------|------|
| ① Cb 的段落定義 | 用全梁計算一個 Cb | 每個無束制段（AB、BC、CD）各算各的 Cb |
| ② Mn 的上限 | 忘記 $M_n \leq M_p$ | 即使 $C_b \times M_{cr} > M_p$，仍要以 $M_p$ 為上限 |
| ③ 載重範圍 | 把 $w$ 當成全跨 | 圖上 $w$ 只在 AB、CD 兩段；BC 段無載重 → BC 段彎矩為常數 $18w$ |
| ④ 均勻彎矩的 $C_b$ | 把 $M_1/M_2 = +1$ 代入 1.75 式得 3.10 | 均勻彎矩是**單曲率**，$M_1/M_2 = -1$ → $C_b = 1.75 - 1.05 + 0.3 = 1.0$（四分點式同為 1.0） |
| ⑤ Lr 的計算 | 跳過 X1、X2 直接查表 | 題目給了斷面參數，需完整計算 X1、X2 後求 Lr；題目未給 $F_r$，熱軋取 0.69 t/cm²（10 ksi） |

$$\boxed{M_p} = F_y Z_x, \quad \phi_b M_p = 0.9 M_p$$

## 4. 步驟化詳細計算過程 (Step-by-Step Detailed Calculation)

### Step 1：局部挫屈檢核（結實斷面確認）

**翼板寬厚比：**

$$\lambda_f = \frac{b_f}{2t_f} = \frac{21.22}{2 \times 2.12} = 5.00$$

$$\lambda_{p,f} = \frac{17}{\sqrt{F_y}} = \frac{17}{\sqrt{3.5}} = \frac{17}{1.871} = 9.09$$

$\lambda_f = 5.00 < \lambda_{p,f} = 9.09$ ✅ 結實翼板

**腹板寬厚比（純彎曲，$f_a = 0$）：**

$$h = d - 2t_f = 54.43 - 2(2.12) = 50.19 \text{ cm}$$

$$\lambda_w = \frac{h}{t_w} = \frac{50.19}{1.31} = 38.31$$

$$\lambda_{p,w} = \frac{170}{\sqrt{F_y}} = \frac{170}{\sqrt{3.5}} = \frac{170}{1.871} = 90.87$$

$\lambda_w = 38.31 < \lambda_{p,w} = 90.87$ ✅ 結實腹板

> **結論：結實斷面（Compact Section）**，塑性彎矩 $M_p$ 為斷面最大撓曲強度。

---

### Step 2：計算基本強度參數

**塑性彎矩：**

$$M_p = F_y Z_x = 3.5 \times 3212 = 11{,}242 \text{ t}\cdot\text{cm} = 112.42 \text{ t}\cdot\text{m}$$

**設計強度上限：**

$$\phi_b M_p = 0.9 \times 11{,}242 = 10{,}118 \text{ t}\cdot\text{cm} = 101.18 \text{ t}\cdot\text{m}$$

**殘留應力（熱軋斷面）：**

$$F_r = 0.69 \text{ t/cm}^2 \quad \Rightarrow \quad F_y - F_r = 3.5 - 0.69 = 2.81 \text{ t/cm}^2$$

**彈性極限彎矩：**

$$M_r = (F_y - F_r) S_x = 2.81 \times 2802 = 7{,}874 \text{ t}\cdot\text{cm}$$

---

### Step 3：計算 $L_p$

$$L_p = \frac{80 r_y}{\sqrt{F_y}} = \frac{80 \times 4.65}{\sqrt{3.5}} = \frac{372}{1.871} = \mathbf{198.8 \text{ cm} \approx 199 \text{ cm}}$$

---

### Step 4：計算 $X_1$、$X_2$ → 求 $L_r$

**$X_1$（扭轉常數一）：**

$$X_1 = \frac{\pi}{S_x}\sqrt{\frac{EGJA}{2}}$$

$$EGJA = 2100 \times 840 \times 181 \times 156.77 = 5.007 \times 10^{10} \text{ t}^2\cdot\text{cm}^2$$

$$\sqrt{EGJA/2} = \sqrt{2.504 \times 10^{10}} = 158{,}227 \text{ t}\cdot\text{cm}$$

$$X_1 = \frac{\pi}{2802} \times 158{,}227 = \frac{3.14159}{2802} \times 158{,}227 = \mathbf{177.4 \text{ t/cm}^2}$$

**$X_2$（扭轉常數二）：**

$$X_2 = \frac{4C_w}{I_y}\left[\frac{S_x}{GJ}\right]^2$$

$$\frac{4C_w}{I_y} = \frac{4 \times 2{,}317{,}464}{3388} = 2{,}735.9 \text{ cm}^2$$

$$\frac{S_x}{GJ} = \frac{2802}{840 \times 181} = \frac{2802}{152{,}040} = 0.018429 \text{ cm/t}$$

$$\left[\frac{S_x}{GJ}\right]^2 = (0.018429)^2 = 3.396 \times 10^{-4} \text{ cm}^2/\text{t}^2$$

$$X_2 = 2{,}735.9 \times 3.396 \times 10^{-4} = \mathbf{0.9291 \text{ cm}^4/\text{t}^2}$$

**$L_r$：**

$$L_r = \frac{r_y X_1}{F_y - F_r}\sqrt{1 + \sqrt{1 + X_2(F_y-F_r)^2}}$$

$$X_2(F_y-F_r)^2 = 0.9291 \times (2.81)^2 = 0.9291 \times 7.896 = 7.335$$

$$\sqrt{1 + X_2(F_y-F_r)^2} = \sqrt{1 + 7.335} = \sqrt{8.335} = 2.887$$

$$\sqrt{1 + 2.887} = \sqrt{3.887} = 1.972$$

$$L_r = \frac{4.65 \times 177.4}{2.81} \times 1.972 = \frac{824.9}{2.81} \times 1.972 = 293.6 \times 1.972 = \mathbf{578.9 \text{ cm} \approx 579 \text{ cm}}$$

---

### Step 5：判斷 LTB 區段

各無束制段之 $L_b$（A-B、B-C、C-D）均為：

$$L_b = L/3 = 18/3 = 6 \text{ m} = 600 \text{ cm}$$

**比較：**

$$L_p = 199 \text{ cm} < L_r = 579 \text{ cm} < L_b = 600 \text{ cm}$$

> **$L_b > L_r$ → 彈性 LTB 控制！**

使用彈性 LTB 公式（LRFD）：

$$M_n = \frac{C_b S_x X_1 \sqrt{2}}{L_b/r_y}\sqrt{1 + \frac{X_1^2 X_2}{2(L_b/r_y)^2}} \leq M_p$$

**計算 $M_{cr}$（$C_b = 1$ 時之基準彈性挫屈彎矩）：**

$$\frac{L_b}{r_y} = \frac{600}{4.65} = 129.03$$

$$\frac{X_1^2 X_2}{2(L_b/r_y)^2} = \frac{(177.4)^2 \times 0.9291}{2 \times (129.03)^2} = \frac{31{,}471 \times 0.9291}{2 \times 16{,}649} = \frac{29{,}241}{33{,}298} = 0.8782$$

$$\sqrt{1 + 0.8782} = \sqrt{1.8782} = 1.3704$$

$$S_x X_1 \sqrt{2} = 2802 \times 177.4 \times 1.4142 = 703{,}022 \text{ t}\cdot\text{cm}$$

$$M_{cr}(C_b=1) = \frac{703{,}022}{129.03} \times 1.3704 = 5{,}449 \times 1.3704 = \mathbf{7{,}469 \text{ t}\cdot\text{cm}}$$

---

### Step 6：彎矩圖與各段 $C_b$、$M_n$

**載重與反力（依原圖：$w$ 只作用於 AB、CD）：**

$$R_A = R_D = \frac{w \times 6 + w \times 6}{2} = 6w$$

$$M(x) = 6w\,x - \frac{w x^2}{2}\quad(0 \le x \le 6),\qquad M = 18w\quad(6 \le x \le 12)$$

| 位置 | $x$ (m) | $M$ (t·m) |
|------|:---:|:---:|
| A | 0 | 0 |
| AB 四分點 | 1.5 / 3.0 / 4.5 | $7.875w$ / $13.5w$ / $16.875w$ |
| B | 6 | $18w$（AB 段在 B 點斜率 $6w - 6w = 0$） |
| B–C | 6～12 | **$18w$（常數）** |
| C | 12 | $18w$ |
| D | 18 | 0 |

---

**段 B-C（均勻彎矩，控制段）：**

均勻彎矩使受壓翼板全段受同樣大的壓力，是 LTB 最不利的情形。以 1.75 式計算時，兩端彎矩同向使梁**單曲率**彎曲，$M_1/M_2 = -1$：

$$C_b = 1.75 + 1.05(-1) + 0.3(-1)^2 = 1.0$$

（四分點式：$12.5 \times 18w/(2.5 \times 18w + 3 \times 18w + 4 \times 18w + 3 \times 18w) = 1.0$，相同。）

$$M_n = 1.0 \times 7{,}465 = 7{,}465\ \text{t}\cdot\text{cm} < M_p = 11{,}242\ \text{t}\cdot\text{cm}$$

$$\phi_bM_n = 0.9 \times 74.65 = 67.18\ \text{t}\cdot\text{m}$$

---

**段 A-B（C-D 對稱）：**

四分點式 $C_b = \dfrac{12.5 \times 18}{2.5 \times 18 + 3 \times 7.875 + 4 \times 13.5 + 3 \times 16.875} = 1.30$（若用 1.75 式，$M_A = 0$ → 1.75）

$$M_n = \min(1.30 \times 74.65,\ M_p) = 96.9\ \text{t}\cdot\text{m}\ \ (\text{1.75 式則達 } M_p = 112.4)$$

![SS-2008-3 圖解：18 m 梁三等分，w 只在 AB、CD；彎矩圖 AB 段拋物線上升（四分點 7.875w、13.5w、16.875w），BC 段常數 18w，CD 對稱；各段 Cb：AB 1.30、BC 1.00、CD 1.30](figs/SS-2008-3-fig-1-cb.svg)

---

### Step 7：求解 $w_{n,cr}$

| 無束制段 | 最大彎矩需求 | $\phi_b M_n$ (t·m) | 對應 $w$ (t/m) |
|---------|:---:|:---:|:---:|
| A-B | $18w$ | 87.3 | 4.85 |
| **B-C** | **$18w$** | **67.18** | **3.73 ← 控制** |
| C-D | $18w$ | 87.3 | 4.85 |

$$18\,w_{n,cr} = 67.18\ \Rightarrow\ \boxed{w_{n,cr} = 3.73\ \text{t/m}}$$

（不乘 $\phi_b$ 的標稱值：$w = 74.65/18 = 4.15$ t/m。）

**雙路徑驗算：** 直接以 AISC 彈性 LTB 式 $M_{cr} = \dfrac{\pi}{L_b}\sqrt{EI_yGJ + \left(\dfrac{\pi E}{L_b}\right)^2I_yC_w}$ 計算：$\dfrac{\pi}{600}\sqrt{2100 \times 3388 \times 840 \times 181 + (\pi \times 2100/600)^2 \times 3388 \times 2{,}317{,}464} = 7{,}462$ t·cm ✔，與 $X_1$、$X_2$ 式（7,465）相同。

![SS-2008-3 圖解：φbMn 對 Lb 曲線，Cb = 1.0 與 1.30，Lp = 199、Lr = 579 cm，Lb = 600 cm 在彈性區；BC 段 67.18、AB 與 CD 段 87.3 t·m；右側列 Mcr = 7,465（直接公式驗算 7,462）與 w = 67.18 / 18 = 3.73 t/m](figs/SS-2008-3-fig-2-curve.svg)

## 5. 關鍵爭議點與進階探討 (Critical Issues & Advanced Discussion)

### 舊版解析的兩處錯誤

| 項目 | 舊解 | 正確 |
|---|---|---|
| 載重範圍 | 全跨均佈，跨中 $40.5w$ | 只在 AB、CD；BC 段常數 $18w$ |
| BC 段 $C_b$ | $M_1/M_2 = +1$ → 3.10 → 取 2.3 → $M_n = M_p$ | 單曲率 $M_1/M_2 = -1$ → **1.0** → 彈性 $M_{cr}$ |
| $w_{n,cr}$ | 2.50 t/m | **3.73 t/m** |

第二個錯誤即使載重判讀正確也會出現：「兩端彎矩相等」在 1.75 式中代 $+1$ 會得到最大 $C_b$，但兩端彎矩相等且同號正是**均勻彎矩、單曲率**，應代 $-1$。記法：單曲率（中段沒有反曲點）$M_1/M_2 < 0$，$C_b$ 偏小；雙曲率（中段有反曲點）$M_1/M_2 > 0$，$C_b$ 偏大。

### 題目未給 $F_r$

本解取熱軋型鋼 $F_r = 0.69$ t/cm²（10 ksi），$L_r = 579$ cm，$L_b = 600$ cm 剛好落在彈性段。若取 1.16 t/cm²（銲接組合），$L_r = 656$ cm，BC 段改為非彈性 $M_n = 71.4$ t·m，$w_{n,cr} = 3.57$ t/m，差約 4%。

### $X_1$、$X_2$ 的物理意義

- $X_1$：代表截面抵抗 **St. Venant 扭轉**與彎矩慣性矩的綜合指標，$X_1$ 越大，翹曲行為越顯著
- $X_2$：代表截面**翹曲剛度**（$C_w$）相對於扭轉剛度（$GJ$）的比值，$X_2$ 越大，翹曲扭轉在 LTB 中的貢獻越大

$L_r$ 正是利用 $X_1$、$X_2$ 求得的彈性 LTB 開始點（$C_b = 1$，$F_b = F_y - F_r$）。
