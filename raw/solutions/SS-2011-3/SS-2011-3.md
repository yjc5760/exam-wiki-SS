## 1. 原始題目重述 (Problem Restatement)

圖示一鋼梁，已知鋼梁在 A 端有一彎矩 M 作用，鋼梁長度 L 為 812.8 cm，梁鋼材特性及斷面尺寸如下所示。試用 LRFD 規範求解此鋼梁所能承受之標稱彎矩 $M_n$，並確認此梁挫屈時是否在彈性範圍內。（25 分）

**材料特性：**
- $E = 2100 \text{ tf/cm}^2$，$G = 840 \text{ tf/cm}^2$
- $F_y = 2.52 \text{ tf/cm}^2$，$F_r = 1.05 \text{ tf/cm}^2$

**斷面尺寸（H 型鋼，單位 cm）：**
- 腹板淨高（上下翼板內側面之間）：$h_w = 40.62 \text{ cm}$ → 全深 $d = 40.62 + 2(1.27) = 43.16 \text{ cm}$
- 翼板寬：$b_f = 20.32 \text{ cm}$
- 翼板厚：$t_f = 1.27 \text{ cm}$
- 腹板厚：$t_w = 1.27 \text{ cm}$

> ⚠️ **40.62 是腹板淨高，不是全深**：原卷（100 年第 2 頁第三題）斷面圖左側 40.62 之尺寸線，上下延伸線與箭頭分別止於**上翼板下緣**與**下翼板上緣**（500 dpi 目視；PDF 向量座標尺寸線 405.2–445.8 pt 與翼板內側面一致，斷面外框 395.8–454.4 pt），翼板厚 $t_f = 1.27$ 另標於翼板外側。

**支撐條件：**
- A 端：施加彎矩 M，**滾支承**（三角形下兩圓輪；平面圖中可防止側移及扭轉）
- B 端：**鉸支承**（三角形＋地面斜線；平面圖中可防止側移及扭轉）
- 無側向中間支撐，無側撐長度 $L_b = L = 812.8 \text{ cm}$

## 2. 考題核心精神與出題者意圖 (Core Concepts & Examiner's Intent)

**核心觀念：** 非對稱彎矩分布（端彎矩型）下，利用 $C_b = 1.75$、$X_1$–$X_2$ 參數法計算 LRFD 側扭挫屈標稱彎矩，並判斷 LTB 類型（彈性 vs. 非彈性）。

**出題者意圖：**
- 測試完整的 LTB 三段判斷流程（Lp / Lr 計算）
- 端彎矩型 $C_b = 1.75$ 的正確識別（而非預設 1.0）
- $X_1$、$X_2$ 複雜公式的計算能力（含 J、$C_W$ 之推導）
- LTB 類型判斷（此題 $L_b > L_r$ → 彈性，僅超出 1.2%，與非彈性差之毫釐）

**關鍵陷阱：**
1. $C_b$ 易誤設為 1.0（未考慮端彎矩加成效果 $C_b = 1.75$）
2. **讀圖**：40.62 是**腹板淨高** $h_w$（尺寸線止於翼板內緣），全深 $d = h_w + 2t_f = 43.16$ cm；誤當全深會使 $L_r$ 變成 833.2 cm 而把分區判錯成非彈性
3. $M_n$ 上限需與 $M_p$ 比較（$C_b$ 放大後仍不能超過 $M_p$）
4. 題目問「是否在彈性範圍內」——需比較 $L_b$ 與 $L_r$

## 4. 步驟化詳細計算過程 (Step-by-Step Detailed Calculation)

### Step 1：斷面幾何計算

**基本幾何量：**

| 符號 | 計算 | 值 |
|------|------|-----|
| $h_w$（腹板淨高，題給） | 圖上 40.62 | $40.62 \text{ cm}$ |
| $d$（全深） | $h_w + 2t_f = 40.62 + 2(1.27)$ | $43.16 \text{ cm}$ |
| $A$（斷面積） | $2 b_f t_f + h_w t_w$ | $2(20.32)(1.27) + (40.62)(1.27) = 51.61 + 51.59 = 103.20 \text{ cm}^2$ |

**強軸慣性矩 $I_x$：**

$$I_x = \frac{1}{12}\left[b_f d^3 - (b_f - t_w)h_w^3\right]$$

$$= \frac{1}{12}\left[20.32 \times 43.16^3 - 19.05 \times 40.62^3\right]$$

$$= \frac{1}{12}\left[20.32 \times 80{,}398 - 19.05 \times 67{,}023\right]$$

$$= \frac{1}{12}\left[1{,}633{,}684 - 1{,}276{,}776\right] = \frac{356{,}908}{12}$$

$$\boxed{I_x = 29{,}742 \text{ cm}^4}$$

> 雙路徑檢核：平行軸法 $2\left[\frac{b_ft_f^3}{12} + b_ft_f\left(\frac{d-t_f}{2}\right)^2\right] + \frac{t_wh_w^3}{12} = 29{,}742$ cm⁴ ✓

**強軸斷面模數 $S_x$：**

$$S_x = \frac{I_x}{d/2} = \frac{29{,}742}{21.58} = 1378.2 \text{ cm}^3$$

**強軸塑性斷面模數 $Z_x$（PNA 在形心）：**

$$Z_x = 2\left[b_f t_f \cdot \frac{d-t_f}{2}\right] + 2\left[t_w \cdot \frac{h_w}{2} \cdot \frac{h_w}{4}\right]$$

$$= b_f t_f (d - t_f) + \frac{t_w h_w^2}{4} = 25.806 \times 41.89 + \frac{1.27 \times 40.62^2}{4}$$

$$= 1081.0 + 523.9$$

$$\boxed{Z_x = 1604.9 \text{ cm}^3}$$

**弱軸慣性矩 $I_y$：**

$$I_y = \frac{2t_f b_f^3}{12} + \frac{h_w t_w^3}{12}$$

$$= \frac{2(1.27)(20.32)^3}{12} + \frac{(40.62)(1.27)^3}{12}$$

$$= \frac{2(1.27)(8390)}{12} + \frac{(40.62)(2.048)}{12} = 1775.9 + 6.9$$

$$\boxed{I_y = 1782.9 \text{ cm}^4}$$

**弱軸迴轉半徑 $r_y$：**

$$r_y = \sqrt{\frac{I_y}{A}} = \sqrt{\frac{1782.9}{103.20}} = 4.156 \text{ cm}$$

**扭轉常數 $J$（St. Venant 扭矩）：**

$$J = \frac{1}{3}\left[2b_f t_f^3 + h_w t_w^3\right] = \frac{t_f^3}{3}(2b_f + h_w)$$

$$= \frac{(1.27)^3}{3}(2 \times 20.32 + 40.62) = \frac{2.048}{3}(81.26)$$

$$\boxed{J = 55.48 \text{ cm}^4}$$

**翹曲常數 $C_W$（依本卷第三頁公式表：$C_W = I_f h^2 / 2$）：**

其中 $I_f$ 為**單一翼板**對弱軸之慣性矩，$h = d - t_f$ 為兩翼板形心距：

$$I_f = \frac{t_f b_f^3}{12} = \frac{1.27 \times 20.32^3}{12} = \frac{1.27 \times 8390.2}{12} = 887.96 \text{ cm}^4$$

$$h = d - t_f = 43.16 - 1.27 = 41.89 \text{ cm}$$

$$C_W = \frac{I_f h^2}{2} = \frac{887.96 \times 41.89^2}{2} = \frac{887.96 \times 1754.77}{2}$$

$$\boxed{C_W = 779{,}084 \text{ cm}^6}$$

> ⚠️ **易錯點**：常見近似式 $C_W \approx I_y(d-t_f)^2/4$ 得 782,126 cm⁶，比正解**高 0.39%**。
> 原因：$C_W$ 只計**翼板**的翹曲貢獻（$I_f$），而 $I_y = 2I_f + t_w^3h_w/12$ 還含腹板項，
> 故 $I_y/2 = 891.43 \neq I_f = 887.96$。本卷公式表既已明列 $I_f h^2/2$，即應照用。

---

### Step 2：結實斷面確認

**翼板寬厚比：**
$$\lambda_f = \frac{b_f}{2t_f} = \frac{20.32}{2(1.27)} = 8.0 < \frac{17}{\sqrt{F_y}} = \frac{17}{\sqrt{2.52}} = 10.71 \quad \checkmark \text{（結實翼板）}$$

**腹板寬厚比（純彎曲，$f_a = 0$）：**
$$\lambda_w = \frac{h_w}{t_w} = \frac{40.62}{1.27} = 31.98 < \frac{170}{\sqrt{F_y}} = \frac{170}{\sqrt{2.52}} = 107.1 \quad \checkmark \text{（結實腹板）}$$

→ 斷面為**結實斷面（Compact Section）**，$\phi_b M_p$ 為上限，可使用完整 LTB 公式。

---

### Step 3：Cb 計算（端彎矩型）

加載型式：A 端彎矩 M，B 端彎矩 0，彎矩圖為線性遞減（單向曲率）。

$$C_b = 1.75 + 1.05\left(\frac{M_1}{M_2}\right) + 0.3\left(\frac{M_1}{M_2}\right)^2 \leq 2.3$$

其中 $M_1 = 0$（較小端），$M_2 = M$（較大端）：

$$\boxed{C_b = 1.75 + 1.05(0) + 0.3(0)^2 = 1.75}$$

---

### Step 4：計算 $X_1$、$X_2$，求 $L_p$、$L_r$

**$X_1$（截面固有挫屈參數）：**

$$X_1 = \frac{\pi}{S_x}\sqrt{\frac{EGJA}{2}}$$

$$EGJA = 2100 \times 840 \times 55.48 \times 103.20 = 1.0101 \times 10^{10}$$

$$\sqrt{\frac{EGJA}{2}} = \sqrt{5.0503 \times 10^9} = 71{,}065$$

$$X_1 = \frac{\pi}{1378.2} \times 71{,}065 = \boxed{162.0 \text{ tf/cm}^2}$$

**$X_2$（截面固有挫屈參數）：**

$$X_2 = 4\frac{C_W}{I_y}\left[\frac{S_x}{GJ}\right]^2$$

$$\frac{C_W}{I_y} = \frac{779{,}084}{1782.9} = 436.99 \text{ cm}^2$$

$$\frac{S_x}{GJ} = \frac{1378.2}{840 \times 55.48} = \frac{1378.2}{46{,}607} = 0.029572 \text{ cm/tf}$$

$$X_2 = 4 \times 436.99 \times (0.029572)^2 = 4 \times 436.99 \times 8.745 \times 10^{-4} = \boxed{1.529 \text{ cm}^4/\text{tf}^2}$$

> 量綱檢查：$X_2(F_y-F_r)^2$ 須無因次 —— $(\text{cm}^4/\text{tf}^2)(\text{tf}/\text{cm}^2)^2 = 1$ ✓

**$L_p$（塑性彎矩對應之側撐長度上限）：**

$$L_p = \frac{80 r_y}{\sqrt{F_y}} = \frac{80 \times 4.156}{\sqrt{2.52}} = \frac{332.5}{1.5875}$$

$$\boxed{L_p = 209.5 \text{ cm}}$$

**$L_r$（彈性 LTB 對應之側撐長度下限）：**

$$L_r = \frac{r_y X_1}{F_y - F_r}\sqrt{1 + \sqrt{1 + X_2(F_y - F_r)^2}}$$

$$F_y - F_r = 2.52 - 1.05 = 1.47 \text{ tf/cm}^2$$

$$X_2(F_y - F_r)^2 = 1.529 \times 1.47^2 = 1.529 \times 2.1609 = 3.3031$$

$$\sqrt{1 + 3.3031} = \sqrt{4.3031} = 2.0744$$

$$\sqrt{1 + 2.0744} = \sqrt{3.0744} = 1.7534$$

$$L_r = \frac{4.156 \times 162.0}{1.47} \times 1.7534 = 458.0 \times 1.7534$$

$$\boxed{L_r = 803.1 \text{ cm}}$$

---

### Step 5：LTB 類型判斷

$$L_p = 209.5 \text{ cm} < L_r = 803.1 \text{ cm} < L_b = 812.8 \text{ cm}$$

$$\boxed{\text{彈性側扭挫屈（Elastic LTB）範圍}}$$

**結論：此梁挫屈時「在彈性範圍內」**（$L_b > L_r$ 故為彈性 LTB；僅超出 9.7 cm，1.2%）

### Step 6：計算標稱彎矩 $M_n$

**基準彎矩：**

$$M_p = F_y Z_x = 2.52 \times 1604.9 = 4044.3 \text{ tf}\cdot\text{cm}$$

$$M_r = (F_y - F_r)S_x = 1.47 \times 1378.2 = 2026.0 \text{ tf}\cdot\text{cm}$$

**彈性 LTB 公式（本卷第三頁）：**

$$M_n = \frac{C_bS_xX_1\sqrt{2}}{L_b/r_y}\sqrt{1 + \frac{X_1^2X_2}{2(L_b/r_y)^2}} \leq M_p$$

$$\frac{L_b}{r_y} = \frac{812.8}{4.156} = 195.55$$

$$\frac{C_bS_xX_1\sqrt2}{L_b/r_y} = \frac{1.75 \times 1378.2 \times 162.0 \times 1.4142}{195.55} = 2825.5 \text{ tf}\cdot\text{cm}$$

$$\sqrt{1 + \frac{162.0^2 \times 1.529}{2 \times 195.55^2}} = \sqrt{1 + 0.5245} = 1.2347$$

$$M_n = 2825.5 \times 1.2347 = 3488.6 \text{ tf}\cdot\text{cm}$$

**上限檢核：** $3488.6 \leq M_p = 4044.3$ tf·cm ✓

$$\boxed{M_n = 3489 \text{ tf}\cdot\text{cm} \approx 34.89 \text{ tf}\cdot\text{m}}$$

**設計強度：** $\phi_b M_n = 0.9 \times 3489 = 3140$ tf·cm

> ✅ **雙路徑交叉驗算**：以本卷第三頁「Simply supported I-section under pure bending」之 $M_{o,cr} = \frac{\pi}{L}\sqrt{EI_yGJ}\sqrt{1+\left(\frac{\pi}{L}\right)^2\frac{EC_W}{GJ}}$ 計算，得 $M_{o,cr} = 1993.5$ tf·cm，$C_bM_{o,cr} = 1.75 \times 1993.5 = 3488.6$ tf·cm，與 $X_1$–$X_2$ 式**完全相同**（兩式為同一彈性解之不同寫法）。
> ✅ **連續性驗算**：於 $L_b = L_r = 803.1$ cm，非彈性式 $C_bM_r = 3545.5$ 與彈性式 3545.5 tf·cm 相接，證明 $X_1$、$X_2$、$L_r$ 計算彼此一致。

## 5. 關鍵爭議點與進階探討 (Critical Issues & Advanced Discussion)

### $L_b$ 與 $L_r$ 非常接近的意義（本題最關鍵之處）

本題 $L_b = 812.8$ cm 與 $L_r = 803.1$ cm 相差僅 **9.7 cm（1.2%）**，此梁處於彈性 LTB 的**最前端**，幾乎貼著非彈性 LTB 的邊界。

這使得題目那句「並確認此梁挫屈時是否在彈性範圍內」變成一個**高風險判斷**：

- **讀圖**：若誤把 40.62 當作全深 $d$（腹板淨高變成 38.08），斷面性質全部變小（$I_x$ 25,831、$S_x$ 1271.8、$Z_x$ 1475.9、$J$ 53.75、$C_W$ 687,469），$L_r$ 變成 833.2 cm > $L_b$，**分區翻轉為非彈性**，$M_n = 3378$ tf·cm（舊版解析即犯此誤，見頁尾修正註記）。
- $C_W$ 若用近似式 $I_y(d-t_f)^2/4$（高估 0.39%）→ $L_r = 803.5$ cm，答案仍是彈性 ✓
- 但若 $C_W$、$X_2$ 或 $J$ 稍有誤差使 $L_r$ 增加 1.2% 以上，**答案會翻轉成「非彈性」**
- 因此本題必須先把尺寸讀對，再把 $J$、$C_W$、$X_1$、$X_2$ 逐項算準，並用「$L_b \approx L_r$ 時兩式應相接」做連續性驗算（見 Step 6）

> 由於 $L_b$ 與 $L_r$ 極近，彈性式與非彈性式在此處給出幾乎相同的值（非彈性式外插至 $L_b$ 得 3487.7 tf·cm），**$M_n$ 數值對分區不敏感，但「是否彈性」的文字結論完全取決於 $L_r$ 落在 $L_b$ 哪一側**。

### $C_b$ 放大後 $M_n/S_x = 2.53 > F_y - F_r$ 的意涵

$$\frac{M_n}{S_x} = \frac{3488.6}{1378.2} = 2.531 \text{ tf/cm}^2 \ > \ F_y - F_r = 1.47 \ （且略大於 F_y = 2.52）$$

- 分區界線 $L_r$ 是以**均勻彎矩（$C_b = 1$）**定義的：$C_b = 1$ 時 $M_{o,cr} = 1993.5 < M_r = 2026.0$ tf·cm，挫屈時全斷面最大應力 $1.446 < F_y - F_r$，確為彈性。依規範分區，本題答「彈性 LTB」。
- $C_b = 1.75$ 只是把強度放大，**不移動分區界線**。挫屈時 A 端最大彎矩 $3489 > M_y = F_yS_x = 3473$ tf·cm（超出 0.44%），表示**彎矩最大的 A 端斷面在挫屈前外緣已達降伏**；但彎矩向 B 端線性遞減，跨內大部分斷面仍在彈性，且 $M_n \le M_p$ 仍成立，規範容許此結果。
- 作答建議：答「依規範 $L_b > L_r$，屬彈性 LTB」，並附一句「$C_b$ 放大後 $M_n/S_x = 2.53$ tf/cm²，A 端局部已達降伏，『彈性』指的是挫屈分區（以 $C_b = 1$ 定義），不代表全梁應力都在比例限內」。

### $C_b = 1.75$ 的加成效果

若誤設 $C_b = 1.0$：

$$M_n^{(C_b=1)} = M_{o,cr} = 1993.5 \text{ tf}\cdot\text{cm}$$

正確 $C_b = 1.75$：

$$M_n = 3489 \text{ tf}\cdot\text{cm}$$

兩者相差 **75%**（即 $C_b$ 本身）！端彎矩型 $C_b$ 的影響極為顯著，考場上務必計算而非直接使用 1.0。

### 為什麼「端彎矩＋另一端為零」是最有利的 $C_b$？

舊式 $C_b = 1.75 + 1.05(M_1/M_2) + 0.3(M_1/M_2)^2$ 中，$M_1/M_2$ 取**負值代表單曲率**（同向彎曲）。本題 $M_1 = 0$ 為單曲率與雙曲率的分界，$C_b = 1.75$。若兩端等值反向（$M_1/M_2 = +1$，雙曲率）則 $C_b = 1.75+1.05+0.3 = 3.10 > 2.3$ 取 2.3；若兩端等值同向（純均勻彎矩，$M_1/M_2 = -1$）則 $C_b = 1.75-1.05+0.3 = 1.0$。**均勻彎矩是最不利情形（$C_b = 1.0$）**，因為整段側撐長度內壓力翼板都承受最大壓應力。

## 6. 依最新規範（AISC 360-16／-22）對照

> **主答依據**：內政部「鋼構造建築物鋼結構設計技術規範」**民國 99 年（2010）修正版**（＝AISC LRFD 1993 體系，本卷第三頁公式表即為該體系）。以 AISC 360-16 為基礎之修訂版**尚未發布**，故僅列為對照。

### 6.1 規範改版對本題的影響

AISC 360-05 起把 LTB 條文（§F2）全面改寫：廢除 $X_1$／$X_2$ 參數，改以 $r_{ts}$ 與 $J c/(S_x h_o)$ 表示；$M_r$ 由 $(F_y - F_r)S_x$ 改為固定的 $0.7F_yS_x$；$C_b$ 由三項式改為四點求積式。逐項對照：

| 項目 | 台灣 2010／AISC LRFD 1993 | AISC 360-16 §F2 | 本題數值 |
|------|------|------|:---:|
| $C_b$ | $1.75 + 1.05\frac{M_1}{M_2} + 0.3(\frac{M_1}{M_2})^2 \leq 2.3$ | $\dfrac{12.5M_{max}}{2.5M_{max}+3M_A+4M_B+3M_C} \leq 3.0$ | **1.75 → 1.667**（−4.8%） |
| $L_p$ | $80r_y/\sqrt{F_y}$ | $1.76r_y\sqrt{E/F_y}$ | 209.5 → **211.2** cm |
| 中間量 | $X_1 = \frac{\pi}{S_x}\sqrt{\frac{EGJA}{2}}$、$X_2 = \frac{4C_W}{I_y}(\frac{S_x}{GJ})^2$ | $r_{ts} = \sqrt{\frac{\sqrt{I_yC_W}}{S_x}}$、$\frac{Jc}{S_xh_o}$ | $X_1=162.0$、$X_2=1.529$ → $r_{ts}=5.200$ cm、$\frac{Jc}{S_xh_o}=0.000961$ |
| $M_r$（轉折彎矩） | $(F_y-F_r)S_x = 1.47S_x$ | $0.7F_yS_x = 1.764S_x$ | 2,026.0 → **2,431.2** tf·cm |
| $L_r$ | 見 Step 4 | $1.95r_{ts}\frac{E}{0.7F_y}\sqrt{\frac{Jc}{S_xh_o}+\sqrt{(\frac{Jc}{S_xh_o})^2+6.76(\frac{0.7F_y}{E})^2}}$ | 803.1 → **698.4** cm |

$C_b$ 的四點求積式：本題彎矩由 A 端的 $M$ 線性遞減至 B 端的 0，四分點彎矩為 $M_A = 0.75M$、$M_B = 0.5M$、$M_C = 0.25M$：

$$C_b = \frac{12.5M}{2.5M + 3(0.75M) + 4(0.5M) + 3(0.25M)} = \frac{12.5}{7.5} = 1.667$$

### 6.2 分區：兩規範皆為「彈性」LTB

$$L_r^{AISC} = 698.4 \text{ cm} \ < \ L_b = 812.8 \text{ cm} \quad \Rightarrow \quad \textbf{彈性 LTB}$$

$$L_r^{TW} = 803.1 \text{ cm} \ < \ L_b = 812.8 \text{ cm} \quad \Rightarrow \quad \textbf{彈性 LTB}$$

兩規範分區相同；差別在於台灣 2010 規範下 $L_b$ 只超出 $L_r$ 1.2%（邊界敏感），AISC 360-16 下則明確落在彈性區（超出 16%）。

### 6.3 AISC 360-16 的 $M_n$

$$\frac{L_b}{r_{ts}} = \frac{812.8}{5.200} = 156.3$$

$$F_{cr} = \frac{C_b\pi^2E}{(L_b/r_{ts})^2}\sqrt{1 + 0.078\frac{Jc}{S_xh_o}\left(\frac{L_b}{r_{ts}}\right)^2} = \frac{1.667\pi^2(2100)}{156.3^2}\sqrt{1+0.078(0.000961)(156.3^2)}$$

$$= 2.3792 \text{ tf/cm}^2 < F_y = 2.52 \ \checkmark$$

$$M_n = F_{cr}S_x = 2.3792 \times 1378.2 = \mathbf{3279 \text{ tf}\cdot\text{cm}} \ (\leq M_p = 4044.3 \ \checkmark)$$

$$\phi_b M_n = 0.9 \times 3279 = 2951 \text{ tf}\cdot\text{cm}$$
