## 2. 考題核心精神與出題者意圖 (Core Concepts & Examiner's Intent)

**核心觀念：** 韌性抗彎矩構架（SMF）靠梁端塑鉸消散地震能量，因此：
1. 梁柱接頭必須具備足夠的**塑性轉角能力**，且以反復載重試驗驗證；
2. 梁在塑鉸區大幅轉動時不能發生側向扭轉挫屈，須以**側向支撐**維持穩定。

**出題者意圖：** 題目指明「依據鋼結構極限設計法規範」，要求寫出**本國規範第十三章（耐震設計）**的條文數值——塑性轉角 0.03 弧度與三種決定方式、強度以試驗彎矩 90% 為準；側撐間距 $170r_y/\sqrt{F_y}$、強度為翼板強度 2%——而不是美國 AISC 341 的 0.04 弧度層間變位角。

---

## 3. 解題戰略地圖與陷阱分析 (Strategic Roadmap & Trap Analysis)

**作答架構：**
- ㈠ 條文（13.6.1）：θp 三種決定方式 → 驗證方式（反復載重試驗、彎矩 90% 對應之轉角）
- ㈡ 目的 → 原則（13.6.7：上下翼板、間距、強度、塑鉸處）→ 繪圖（平面配置＋斷面斜撐）

**關鍵陷阱：**

1. **0.03 vs 0.04**：本國極限設計法規範規定**塑性轉角 0.03 弧度**；0.04 弧度是 AISC 341-05 以後的「層間變位角」（總轉角，含彈性部分）。兩者概念不同，題目問本國規範。
2. **強度保持**：以反復載重試驗中**彎矩為試驗強度 90%** 所對應的最大轉角作為接頭可提供之塑性轉角（AISC 341 為 0.8Mp）。
3. **側撐間距單位**：$170r_y/\sqrt{F_y}$，$r_y$ 以 cm、$F_y$ 以 tf/cm² 計。
4. **上下翼板都要撐**：地震反復作用，上、下翼板輪流受壓。

## 4. 步驟化詳細計算過程 (Step-by-Step Detailed Calculation)

### 問（一）：塑性轉角需求規定（7 分）

依《鋼結構極限設計法》13.6.1，韌性抗彎矩構架梁柱接頭應能提供之塑性轉角 $\theta_p$，依下列三者之一決定：

1. $\theta_p = 0.03$ 弧度；
2. 以非線性動力分析求得之最大塑性轉角再加 0.005 弧度；
3. $\theta_p = 1.1(R - 1.0)\,\theta_E$（$R$ 為結構系統韌性容量、$\theta_E$ 為設計地震力下之彈性層間變位角）。

接頭所能提供之塑性轉角，須以**反復載重試驗**（或經驗證之接頭資料）證明，並以試驗中**彎矩為試驗強度 90%** 所對應之最大轉角為準。

$$\boxed{\theta_p \ge 0.03\ \text{rad（或分析值＋0.005、或 }1.1(R-1)\theta_E\text{）；以彎矩 90\% 試驗強度對應之轉角驗證}}$$

### 問（二）：梁塑鉸區側向支撐之目的、設計原則與施作（18 分）

#### (A) 目的

1. **防止非彈性側向扭轉挫屈**：梁端形成塑鉸後受壓翼板仍須保持穩定，否則彎矩強度驟降；
2. **確保塑性轉角能力**：讓接頭能發揮 (一) 所要求的塑性轉角，維持穩定、飽滿的遲滯迴圈；
3. **使塑鉸發生在預期位置**：避免平面外失穩造成非預期破壞模式。

#### (B) 設計原則（13.6.7）

1. **上、下翼板均須設置側向支撐**（地震反復作用，上、下翼板輪流受壓）；
2. **間距**：須符合 7.2.4 節（梁之側撐規定），且不得超過

$$L_b \le \frac{170\,r_y}{\sqrt{F_y}}\quad(r_y：\text{cm},\ F_y：\text{tf/cm}^2)$$

   例：$F_y = 3.3$ tf/cm²（SN490B）→ $L_b \le 93.6\,r_y$；$F_y = 2.5$ → $107.5\,r_y$；

3. **強度**：每處側撐須能抵抗梁翼板強度之 2%：

$$P_{br} \ge 0.02\,F_y\,b_f\,t_f$$

4. **塑鉸處**：梁承受集中載重且可能產生塑性鉸處，亦須設置側向支撐；採減弱斷面（RBS）時，側撐設在減弱段以外，避免干擾塑鉸。

#### (C) 施作方式繪圖說明

```
平面圖（梁長向）：

  柱面
   │← 塑鉸區 →│
   ├──────────┼─────────┼─────────┼────── 梁
   │   ⓪      ①         ②         ③
   │  塑鉸     └── 間距 ≤ 170ry/√Fy ──┘
   ⓪ = 預期塑鉸（柱面外約 d/2～d）
   ①②③ = 側撐（上、下翼板均需）
```

```
斷面圖（側撐做法）：

   ═══════════════ 樓版
   ┬─────上翼板─────┬      ← 上翼板：樓版＋剪力釘提供側撐
   │               │
   │    梁腹板      │       小梁（或繫梁）
   │               │      ／
   ┴─────下翼板─────┴ ─── 斜撐角鋼（kicker）連至小梁上翼板或樓版
```

| 做法 | 說明 |
|------|------|
| 上翼板 | 混凝土樓版與剪力釘連接，提供上翼板側向束制 |
| 下翼板 | 以斜撐角鋼（kicker）連接相鄰小梁或樓版，或在側撐點設置垂直於梁的小梁＋加勁板 |
| 小梁直接連接 | 小梁接於大梁時，可在接點設全深加勁板，同時撐住上、下翼板 |

## 5. 關鍵爭議點與進階探討 (Critical Issues & Advanced Discussion)

### 5.1 本國規範與 AISC 341 之差異

| 項目 | 本國極限設計法 13 章 | AISC 341-05 以後 |
|------|------|------|
| 接頭變形需求 | 塑性轉角 0.03 rad（三擇一） | 層間變位角 0.04 rad（總轉角） |
| 強度保持 | 彎矩 90% 試驗強度所對應之轉角 | 0.04 rad 時柱面彎矩 ≥ 0.8Mp |
| 側撐間距 | $170r_y/\sqrt{F_y}$（cm、tf/cm²） | $0.086r_yE/F_y$（341-10；341-16 改依延展性分級） |
| 側撐強度 | $0.02F_yb_ft_f$ | $0.06R_yF_yZ/h_o$ |

以 $F_y = 3.5$ tf/cm²、$E = 2040$ tf/cm² 比較：本國 $90.9r_y$，AISC 341-10 $50.1r_y$，美國規定較嚴。

### 5.2 為何梁端需要側撐而柱端不強調？

強柱弱梁設計使塑鉸發生在梁端，柱應保持彈性；梁塑鉸區在大轉角下受壓翼板最易失穩，故側撐規定集中在梁。

### 5.3 RBS 減弱斷面

塑鉸移至減弱段，側撐應設於減弱段外側，避免側撐連接干擾塑鉸發展。
