## 1. 原始題目重述 (Problem Restatement)

> **原卷逐字**：「如圖 4 所示一**無側撐剛架**，承受垂直軸壓力 P 及水平力 H。試使用 LRFD 求解**柱 BC** 之二階設計彎矩（Second-order design moment）$M_u$ 及 $B_1$、$B_2$、$M_{nt}$、$M_{lt}$。（求解柱 BC 之有效長度係數時，請參考題二之 Alignment Chart。）（25 分）（柱邊界為固接（Fixed end）時 G 使用 1、為鉸接（hinged end）時 G 使用 10。）」

![SS-2013-4 題目附圖：水平梁 A—B—D 位於上方，A、D 為滾支承，B 點下方連一根長度 L 的柱 BC，C 為鉸支承；水平力 H 作用於 A，垂直力 P 作用於 B；AB = BD = 1.5L](SS-2013-4-fig-1.png)

*圖說（依原卷圖 4 目視判讀）：**上方**為連續水平梁 **A—B—D**，$AB = BD = 1.5L$（全長 $3L$），各段 $EI$ 相同。**A 端與 D 端均為滾支承**（三角形＋滾輪＋斜線地面符號）——只提供**垂直**支承，水平方向**可自由平移**。**B 點**為梁與柱之剛性交會點。自 B 往**下**接一根長度 $L$、剛度 $EI$ 之柱 **BC**，柱底 **C 為鉸支承**（三角形＋斜線地面，無滾輪）——同時束制水平與垂直。**水平力 $H$ 作用於 A 點**（向右），**垂直軸壓力 $P$ 作用於 B 點**（向下，即柱頂）。*

**⚠️ 幾何判讀重點（本題最易誤讀之處）：**

| 項目 | 正確判讀 | 常見誤讀 |
|------|---------|---------|
| 柱數 | **僅 1 根**（柱 BC） | 誤為「單層兩跨、三根柱」 |
| A、D 之角色 | 梁兩端之**滾支承**（在地面／支座上） | 誤為兩根外柱的柱頂節點 |
| 水平束制來源 | **只有 C 點的鉸支承**（故可側移＝無側撐剛架） | — |
| $P$ 之作用位置 | **B 點**（柱頂，與柱同軸） | 誤為作用於 D 點 |
| $H$ 之作用位置 | A 點（經梁傳至 B，再下傳至 C） | — |

**為何是「無側撐剛架」：** A、D 為滾支承，水平方向不提供束制；整個梁可水平平移，唯一抵抗側移者為柱 BC 之撓曲。故側移**未受束制**（sidesway uninhibited），符合原卷「無側撐剛架」之描述，$K > 1$。

**題目提供之公式（原卷圖 4 下方）：**
$$B_1 = \frac{C_m}{1 - P_u/P_{eK}} \geq 1.0, \quad C_m = 0.6 - 0.4\frac{M_A}{M_B}$$
$$P_{eK} = \frac{\pi^2 EI}{(KL)^2} = \frac{P_e}{K^2}, \quad B_2 = \frac{1}{1 - \sum P_u/\sum P_{eK}}$$
$$M_u = B_1 M_{nt} + B_2 M_{lt}$$

**題目提供之 K 值表（原卷題三下方，本題可參照）：**

| 條件 | 邊界無側位移 | | | 邊界有側位移* | | |
|------|:---:|:---:|:---:|:---:|:---:|:---:|

## 2. 考題核心精神與出題者意圖 (Core Concepts & Examiner's Intent)

**核心觀念：$B_1$-$B_2$ 放大法 —— 二階彎矩的兩個來源分別放大後再相加**

| 量 | 物理意義 | 求法 | 本題結果 |
|---|---------|------|---------|
| $M_{nt}$ | **no translation**：側移被束制後的一階彎矩 | 加虛擬水平支撐，只施加重力載重，作一階分析 | **0** |
| $M_{lt}$ | **lateral translation**：僅側移（水平力）造成的一階彎矩 | 只施加水平力，作一階分析 | **$HL$** |
| $B_1$ | 構材撓曲 P-δ 放大係數（作用於 $M_{nt}$） | $C_m/(1-P_u/P_{eK})$，$P_{eK}$ 用**無側移 K** | 1.0（$M_{nt}=0$，不影響結果） |
| $B_2$ | 層間側移 P-Δ 放大係數（作用於 $M_{lt}$） | $1/(1-\sum P_u/\sum P_{eK})$，$P_{eK}$ 用**有側移 K** | $\dfrac{1}{1 - PL^2/(2.88EI)}$ |
| $M_u$ | 二階設計彎矩 | $B_1M_{nt} + B_2M_{lt}$ | $B_2 \cdot HL$ |

**出題者測驗重點：**
1. 能正確判讀支承型式（滾支承 vs 鉸支承）並判定「可側移」
2. 能分離 $M_{nt}$ 與 $M_{lt}$（本題 $M_{nt}=0$ 是關鍵發現）
3. 能用有側移對位圖查 $K$（$G$ 值分母含**兩側**梁）
4. 知道 $\sum P_{eK}$ 只計「抵抗側移之柱」，本題僅 1 根

## 3. 解題戰略地圖與陷阱分析 (Strategic Roadmap & Trap Analysis)

**作戰計畫：**
```
Step 1  判讀支承：A、D 滾支承（水平自由）、C 鉸支承（水平束制）→ 可側移，僅 1 根柱
Step 2  G 值：柱頂 B 之分母含左右兩段梁；柱底 C 為鉸接 → G = 10
Step 3  有側移對位圖 → K_BC
Step 4  Mnt：束制側移後，P 沿柱軸直下 + 幾何對稱 → Mnt = 0
Step 5  Mlt：對 C 取矩，H 作用於 L 高處 → Mlt = H·L
Step 6  ΣPeK = π²EI/(K L)²（只有 BC 一根）；ΣPu = P
Step 7  B2 = 1/(1 − ΣPu/ΣPeK)；Mu = B1·0 + B2·HL = B2·HL
```

**關鍵陷阱：**

> ⚠️ **陷阱1：把 A、D 誤認為柱頂節點（本題最致命）**
> A、D 是**梁端的滾支承**，不是柱。全結構**只有一根柱（BC）**。若誤為三根柱，$\sum P_{eK}$ 會膨脹成約 2.7 倍、$M_{lt}$ 會被錯誤地分成 $H/3 \times L$，兩處錯誤同時發生。

> ⚠️ **陷阱2：$M_{lt}$ 不是 $HL/3$，而是 $HL$**
> 只有柱 BC 抵抗側移（A、D 為滾支承，水平反力為零），故層剪力**全部**由 BC 承擔：$V_{BC} = H$，$M_{lt} = H \times L$。

> ⚠️ **陷阱3：$M_{nt} = 0$，但仍須說明理由**
> $P$ 直接作用於柱頂 B、與柱同軸，且梁兩側跨度相同（$1.5L = 1.5L$）。束制側移後，梁在 B 點的變形對稱 → $\theta_B = 0$ → 左右梁端彎矩等值反向、於節點相消 → 不傳遞彎矩給柱 → $M_{nt} = 0$。

> ⚠️ **陷阱4：$P_{e1}$（$B_1$ 用）與 $P_{eK}$（$B_2$ 用）的 K 不同**
> $B_1$ 之 $P_{e1}$ 用**無側移** K（規範明定 $K \leq 1.0$）；$B_2$ 之 $P_{eK}$ 用**有側移** K（規範 4.8 節，$K \geq 1.0$）。混用會嚴重高估或低估。

> ⚠️ **陷阱5：$C_m$ 在 $M_{nt} = 0$ 時是 $0/0$**
> $M_A/M_B = 0/0$ 無定義。但 $B_1 M_{nt} = B_1 \times 0 = 0$，$B_1$ 之數值不影響 $M_u$；依規範下限取 $B_1 = 1.0$ 即可，**不可編造「規範規定 $C_m = 1.0$」**。

## 4. 步驟化詳細計算過程 (Step-by-Step Detailed Calculation)

### 一、支承判讀與結構行為

由圖 4 目視判讀：

- **A、D**：三角形＋**滾輪**＋斜線地面 → **滾支承**，$R_x = 0$、$R_y \neq 0$、$M = 0$
- **C**：三角形＋斜線地面（無滾輪）→ **鉸支承**，$R_x \neq 0$、$R_y \neq 0$、$M = 0$
- **B**：梁與柱之剛性交會（剛架節點）

**水平力平衡（整體）：**
$$\sum F_x = 0:\quad H + R_{x,A} + R_{x,D} + R_{x,C} = 0 \ \xrightarrow{\ R_{x,A}=R_{x,D}=0\ }\ R_{x,C} = -H$$

→ 水平力**全部**經梁傳至 B、再沿柱 BC 下傳至 C。柱 BC 是**唯一**的抗側力構材，故本剛架**側移未受束制**（無側撐剛架），$K > 1$。

---

### 二、$G$ 值計算

各構材 $EI$ 相同，取 $I_c = I_g = I$：

$$\text{柱勁度} = \frac{I_c}{L_c} = \frac{I}{L}, \qquad \text{梁勁度（兩段之和）} = \frac{I}{1.5L} + \frac{I}{1.5L} = \frac{2I}{1.5L} = \frac{4I}{3L}$$

**柱頂 B：**
$$G_B = \frac{\sum(I_c/L_c)}{\sum(I_g/L_g)} = \frac{I/L}{4I/(3L)} = \frac{3}{4} = \boxed{0.75}$$

**柱底 C（鉸接）：** 依原卷約定
$$G_C = \boxed{10}$$

---

### 三、有側移有效長度係數 $K_{BC}$

**方法一：Jackson–Moreland 近似式（AISC 解說所列，適用有側移）**

$$K = \sqrt{\frac{1.6\,G_BG_C + 4(G_B+G_C) + 7.5}{G_B + G_C + 7.5}}$$

$$= \sqrt{\frac{1.6(0.75)(10) + 4(0.75+10) + 7.5}{0.75+10+7.5}} = \sqrt{\frac{12 + 43 + 7.5}{18.25}} = \sqrt{\frac{62.5}{18.25}} = \sqrt{3.4247} = 1.851$$

**方法二：對位圖之精確超越方程式（交叉驗算）**

$$\frac{G_BG_C(\pi/K)^2 - 36}{6(G_B+G_C)} = \frac{\pi/K}{\tan(\pi/K)}$$

數值解得 $\pi/K = 1.7005$ → $K = 1.8474$。

$$\boxed{K_{BC} \approx 1.85}\qquad(\text{近似式 } 1.851 \text{ vs 精解 } 1.847，\text{差 } 0.17\% \ \checkmark)$$

> ✅ **方程式自我驗證**：以 $G_B = G_C = 0$（兩端完全固接、可側移）代入精確式，得 $K = 1.00$ —— 與 K 值表「固接*-固接：理論 K = 1.0」吻合，證明所用方程式正確。

---

### 四、各柱之 $P_{eK}$ 與全層 $\sum P_{eK}$

$$P_{eK,BC} = \frac{\pi^2 EI}{(K_{BC}L)^2} = \frac{\pi^2 EI}{(1.851L)^2} = \frac{9.8696\,EI}{3.4247\,L^2} = \frac{2.882\,EI}{L^2}$$

**全層總和 —— 本結構只有一根柱：**

$$\boxed{\sum P_{eK} = P_{eK,BC} = \frac{2.88\,EI}{L^2}}$$

> ⚠️ A、D 是**支承**而非柱，不提供側向勁度，也沒有 $P_{eK}$ 可加。

**全層垂直載重：**
$$\sum P_u = P$$

---

### 五、一階分析（求 $M_{nt}$ 與 $M_{lt}$）

#### 5.1 無側移分析 → $M_{nt}$

在 B 點加一虛擬水平支撐（阻止側移），只施加重力載重 $P$：

- $P$ 直接作用於節點 B，**與柱 BC 同軸**，本身不對柱產生偏心彎矩。
- 梁 A—B—D 在 B 點兩側跨度**相同**（$1.5L = 1.5L$）、$EI$ 相同 → 對 B 點幾何**對稱**。
- 垂直力作用於對稱點時，變形形狀對稱於 B，故 $\theta_B = 0$；左右兩段梁在 B 端的彎矩**等值反向**，於節點處相互抵銷。

$$\Rightarrow \text{節點 B 不傳遞彎矩給柱} \quad \Rightarrow \quad \boxed{M_{nt} = 0}$$

（柱底 C 為鉸接本已無彎矩；柱身無橫向載重。）

#### 5.2 側移分析 → $M_{lt}$

移除虛擬支撐，只施加水平力 $H$。取**柱 BC 之自由體**，對 C 點取矩：

$$\sum M_C = 0:\quad M_{B} = H \times L$$

（作用於 B 點的水平力等於 $H$，力臂為柱高 $L$；柱底 C 為鉸接，彎矩為 0。）

$$\boxed{M_{lt} = H\,L \quad (\text{柱頂 B}),\qquad M_{lt,C} = 0}$$

> **對照**：若誤判為三根柱平均分擔，會得 $M_{lt} = HL/3$，**低估 3 倍**。

---

### 六、$B_2$（側移放大係數）

$$B_2 = \frac{1}{1 - \dfrac{\sum P_u}{\sum P_{eK}}} = \frac{1}{1 - \dfrac{P}{2.88\,EI/L^2}} = \frac{1}{1 - \dfrac{P L^2}{2.88\,EI}}$$

$$\boxed{B_2 = \frac{2.88\,EI}{2.88\,EI - P L^2}}$$

**適用範圍檢核：** 須 $\sum P_u < \sum P_{eK}$，即 $P < 2.88\,EI/L^2$；否則該層已達側移挫屈（$B_2 \to \infty$）。實務並要求 $B_2 \leq 1.5\sim2.5$。

---

### 七、$B_1$（構材撓曲放大係數）

**$P_{e1}$（用無側移 $K$）：** 規範明定 $B_1$ 之 $P_{e1}$ 取彎曲平面上 $K \leq 1.0$：

$$P_{e1} = \frac{\pi^2 EI}{(1.0\,L)^2} = \frac{9.87\,EI}{L^2}$$

**$C_m$：** $M_{nt} = 0$（兩端皆為 0），故 $M_A/M_B = 0/0$ **無定義**，$C_m$ 不可計算。

但因

$$B_1 M_{nt} = B_1 \times 0 = 0 \quad(\text{對任意 } B_1)$$

$B_1$ 的數值**不影響** $M_u$。依規範下限：

$$\boxed{B_1 = 1.0}$$

> ⚠️ 不要寫「$M_{nt}=0$ 時規範規定 $C_m = 1.0$」——規範並無此條文。正確說法是「$M_{nt}=0$ 使 $B_1M_{nt}=0$，$B_1$ 取下限 1.0」。

---

### 八、二階設計彎矩 $M_u$

$$M_u = B_1 M_{nt} + B_2 M_{lt} = 1.0 \times 0 + B_2 \times HL$$

$$\boxed{M_u = B_2\,HL = \frac{2.88\,EI}{2.88\,EI - PL^2}\,HL = \frac{HL}{1 - \dfrac{PL^2}{2.88\,EI}}}$$

**極限行為檢查（量綱與趨勢）：**

| 情況 | $M_u$ | 是否合理 |
|------|------|:---:|
| $P \to 0$ | $\to HL$（純一階） | ✓ |
| $P \to 2.88EI/L^2$ | $\to \infty$（層間側移挫屈） | ✓ |
| $P = 0.5 \times 2.88EI/L^2$ | $B_2 = 2.0$，$M_u = 2HL$ | ✓ |

量綱：$EI$ 為 $[\text{力}\cdot\text{長}^2]$，$PL^2$ 為 $[\text{力}\cdot\text{長}^2]$ → $B_2$ 無因次 ✓；$M_u \sim HL$ 為 $[\text{力}\cdot\text{長}]$ ✓。

## 5. 關鍵爭議點與進階探討 (Critical Issues & Advanced Discussion)

### 爭議一：對位圖是否應對「梁遠端鉸接」作 0.5 折減？

有側移對位圖的推導**內設**梁兩端作反對稱轉動，對應梁的轉動勁度 $6EI/L_g$。本題梁的遠端（A、D）是**滾支承**（轉動自由），實際勁度只有 $3EI/L_g$，僅為對位圖假設的一半。AISC 解說對此提供修正：**有側移時，遠端鉸接之梁其 $I_g/L_g$ 應乘 0.5**。

| | 未修正（原卷應期望之解法） | 乘 0.5 修正（理論較嚴謹） |
|---|:---:|:---:|
| $\sum I_g/L_g$ | $2I/(1.5L) = 1.333\,I/L$ | $0.5 \times 1.333 = 0.667\,I/L$ |
| $G_B$ | **0.75** | 1.50 |
| $K$（近似／精解） | **1.851 / 1.847** | 2.020 / 2.008 |
| $\sum P_{eK}$ | **$2.88\,EI/L^2$** | $2.42\,EI/L^2$ |
| $B_2$ | $\dfrac{2.88EI}{2.88EI-PL^2}$ | $\dfrac{2.42EI}{2.42EI-PL^2}$ |

**取捨：** 原卷只給了「固接 $G=1$、鉸接 $G=10$」這一項約定，未提及梁端折減，且要求「參考題二之 Alignment Chart」，故**主答採未修正之 $G_B = 0.75$、$K = 1.85$**。若答題時間充裕，可加註「梁遠端為滾支承，嚴格應乘 0.5 折減，得 $K = 2.02$、$\sum P_{eK} = 2.42EI/L^2$，$B_2$ 更大、設計更保守」——屬加分，不是替代。

### 爭議二：本結構的「層」只有一根柱，$B_2$ 還適用嗎？

$B_2$ 的推導基礎是「該層的側移勁度」與「該層的重力載重」之比，與柱數無關。單柱情況下 $B_2$ 退化為單一構材的側移放大係數，仍然成立。事實上本題可直接驗證：

$$B_2 = \frac{1}{1 - P/P_{cr,sway}}, \qquad P_{cr,sway} = \frac{\pi^2 EI}{(K L)^2} = \frac{2.88EI}{L^2}$$

—— 即「側移挫屈載重」的定義，物理意義完全一致。

### 爭議三：$P$ 究竟全部落在柱 BC 上嗎？

$P$ 作用於節點 B。B 點的支撐路徑有兩條：柱 BC 的**軸向**勁度 $EA/L$，與梁兩側的**撓曲**勁度（$\sim 3EI/(1.5L)^3$ 每側）。對常見鋼構斷面，$EA/L \gg EI/L^3$（相差約 $(L/r)^2$ 倍，通常 $10^3$ 以上），故 $P$ 幾乎全數由柱承擔：

$$P_{u,BC} \approx P, \qquad \sum P_u = P$$

即使少量由梁分擔，$\sum P_u$（該層全部垂直載重）仍為 $P$，$B_2$ 不受影響。

### $B_1$ 與 $B_2$ 的物理意義對照

| | $B_1$（P-δ） | $B_2$（P-Δ） |
|---|---|---|
| 變形量 | 構材自身撓曲 $\delta$（相對於兩端連線） | 層間相對側移 $\Delta$ |
| 放大對象 | $M_{nt}$ | $M_{lt}$ |
| $K$ | 無側移，$K \leq 1.0$ | 有側移，$K \geq 1.0$ |
| 分母 | $1 - P_u/P_{e1}$（單一構材） | $1 - \sum P_u/\sum P_{eK}$（整層） |
| 本題 | 不起作用（$M_{nt}=0$） | **控制全部答案** |

**本題是「純 P-Δ 題」**：所有二階效應都來自層間側移，構材內的 P-δ 完全不參與。這正是出題者要考的分工。

### 無側撐剛架 vs 有側撐剛架

| 特性 | 有側撐（braced） | 無側撐（unbraced，本題） |
|------|--------------|----------------|
| 側向束制來源 | 斜撐／剪力牆／核心 | 剛架本身的撓曲 |
| $K$ | $\leq 1.0$ | $> 1.0$ |
| $M_{lt}$ | 通常 = 0 | $> 0$（本題 $= HL$） |
| 二階效應主體 | $B_1$（P-δ） | $B_2$（P-Δ） |

## 6. 依最新規範（AISC 360-16／-22）對照

> **主答依據**：內政部「鋼構造建築物鋼結構設計技術規範」**極限設計法（民國 99 年／2010 修正版）** 第 8.2 節（$M_u = B_1M_{nt} + B_2M_{lt}$，式 8.2-2～8.2-5），與原卷提供之公式一致。以 AISC 360-16 為基礎之修訂版**尚未發布**，故僅列為對照。

### 6.1 $B_1$-$B_2$ 放大法在 AISC 360 中被「降級」

這是本題在新舊規範間最大的差異：

| 規範 | 穩定設計的主方法 | $B_1$-$B_2$ 的地位 |
|------|------|------|
| 台灣 2010／AISC LRFD 1993／AISC 360-05 | **有效長度法（ELM）**＋$B_1$-$B_2$ 放大 | 規範本體（第 8.2 節 / Ch. C） |
| **AISC 360-10／-16／-22** | **直接分析法（DAM，Chapter C）** | 移入 **Appendix 8「二階分析之近似解」**，僅作為 ELM／一階分析法的配套工具 |

AISC 360-16 的預設流程是：以**二階分析**（或 App. 8 的 $B_1$-$B_2$ 近似）求 $M_r$，同時計入初始不完美（$N_i = 0.002\alpha Y_i$）與勁度折減（$0.8\tau_b EI$、$0.8EA$），並取 **$K = 1.0$**——**完全不需要查對位圖**。

### 6.2 若本題改依 AISC 360-16 Appendix 8

Appendix 8 的公式與台灣 2010 幾乎相同，但有三處差異：

| 項目 | 台灣 2010（第 8.2 節） | AISC 360-16 App. 8 |
|------|------|------|
| 二階彎矩 | $M_u = B_1M_{nt} + B_2M_{lt}$ | $M_r = B_1M_{nt} + B_2M_{lt}$（式 A-8-1，形式相同） |
| $B_1$ 之 $C_m$ | 規範 (8.2-3) 之 Taiwan 專用式（含 0.64／0.32） | $C_m = 0.6 - 0.4(M_1/M_2)$（式 A-8-4） |
| $P_{e1}$ | $A_gF_y/\lambda_c^2$，$K \leq 1.0$ | $\pi^2EI^*/(L_{c1})^2$，$L_{c1}$ 取無側移長度（通常 $= L$） |
| $B_2$ 分母 | $1 - \sum P_u/\sum P_{e2}$ | $1 - \alpha\sum P_r/\sum P_{e\,story}$（**多了 $\alpha$**：LRFD 1.0、ASD 1.6） |
| $\sum P_{e,story}$ | $\sum \pi^2EI/(K_2L)^2$（需查對位圖） | $R_M \dfrac{\sum H L}{\Delta_H}$（**用一階側移直接算，不需 K**）；$R_M = 1 - 0.15(P_{mf}/P_{story})$ |
| 勁度 | 彈性 $EI$ | 折減 $EI^* = 0.8\tau_b EI$ |

**用 AISC 360-16 的側移法重算本題（示範差異）：**

一階側移分析（只有柱 BC，柱底鉸接，柱頂由梁提供轉動束制）。由 §5 爭議一的勁度模型（梁遠端鉸接，$k_\theta = 4EI/L$）作斜率-偏移法：

$$\theta_B = \frac{3}{7}\psi,\qquad M_{BC} = \frac{3EI}{L}(\theta_B - \psi) = -\frac{12EI}{7L}\psi,\qquad H = \frac{|M_{BC}|}{L} = \frac{12EI}{7L^2}\psi$$

$$\Rightarrow \Delta_H = \psi L = \frac{7HL^3}{12EI}$$

$$\sum P_{e,story} = R_M\frac{\sum H \cdot L}{\Delta_H} = R_M \cdot \frac{HL}{7HL^3/(12EI)} = R_M\cdot\frac{12EI}{7L^2} = 1.714\,R_M\frac{EI}{L^2}$$

本題全部垂直載重都在抗彎構架的柱上（$P_{mf} = P_{story}$）→ $R_M = 1 - 0.15 = 0.85$：

$$\sum P_{e,story} = 0.85 \times 1.714\frac{EI}{L^2} = 1.457\frac{EI}{L^2}$$

$$B_2^{AISC} = \frac{1}{1 - \dfrac{1.0 \times P}{1.457EI/L^2}} = \frac{1}{1 - \dfrac{PL^2}{1.457EI}}\quad(\text{LRFD, }\alpha=1.0)$$

對照台灣 2010 之 $B_2 = 1/(1 - PL^2/2.88EI)$：AISC 的分母門檻由 $2.88EI/L^2$ 降到 $1.457EI/L^2$，**放大量明顯較大（較保守）**。差異來源：① $R_M$ 折減 0.85；② 側移法用的是「梁遠端鉸接」之真實勁度（相當於 §5 爭議一的修正情形，且不受對位圖 $6EI/L_g$ 假設拖累）；③ 若再計入 $0.8\tau_b$ 勁度折減，$\sum P_{e,story}$ 還會再降 20%。

> 這也**印證了 §5 爭議一**：對位圖未修正的 $K = 1.85$ 確實偏樂觀；AISC 的側移法（不查 K）自然地反映了滾支承梁端的真實柔度。
