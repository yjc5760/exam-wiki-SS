# 考題編號：SS-2018-2

**主分類：** `SS-U1-1` 拉力及壓力桿件
**副分類：** 無
**設計法：** LRFD
**標籤：** `壓力桿件` `箱型斷面` `整體彎曲挫屈` `有效長度係數` `λc` `Fcr` `φcPn` `非彈性挫屈` `局部挫屈` `φc新舊規範`

## 1. 原始題目重述 (Problem Restatement)

**題目：** 鋼構架中有一柱長 400 cm，採用板厚 3.2 cm、寬度 80 cm 之箱型斷面。分析後得知柱需承受壓力 1,119 tf，且 2 方向有效長度係數分別為 2.284 與 2.397。鋼材降伏強度 3.3 tf/cm²，而揚氏係數 2,040 tf/cm²。試依極限設計法（LRFD）檢核上述柱構件之強度設計。（25 分）

**已知條件整理：**

| 參數 | 數值 |
|------|------|
| 柱長 $L$ | 400 cm |
| 斷面型式 | 正方形箱型（hollow square）|
| 外側寬度 $b_o$ | 80 cm |
| 板厚 $t$ | 3.2 cm |
| 設計壓力 $P_u$ | 1,119 tf |
| 有效長度係數 $K_1$ | 2.284（第一方向）|
| 有效長度係數 $K_2$ | 2.397（第二方向，控制）|
| 降伏強度 $F_y$ | 3.3 tf/cm² |
| 揚氏係數 $E$ | 2,040 tf/cm² |

**考卷給定參考公式：**

$$\lambda_c = \frac{KL}{\pi r}\sqrt{\frac{F_y}{E}}$$

$$\lambda_c > 1.5 \Rightarrow F_{cr} = \frac{0.877}{\lambda_c^2}F_y \quad (\text{彈性挫屈})$$

$$\lambda_c \leq 1.5 \Rightarrow F_{cr} = e^{-0.419\lambda_c^2}F_y \quad (\text{非彈性挫屈})$$

*（說明：$e^{-0.419\lambda_c^2} = 0.658^{\lambda_c^2}$，兩式等價）*

## 2. 考題核心精神與出題者意圖 (Core Concepts & Examiner's Intent)

**核心觀念：** 箱型斷面屬高效率斷面，對稱軸兩方向慣性矩相同，計算迴轉半徑時可利用代數化簡公式 $r^2 = (b_o^2 + b_i^2)/12$（僅適用正方形箱）。有效長度係數不同時，需分別計算兩方向之 $\lambda_c$ 取最大者控制。

**出題者意圖：**
1. 考核正方形箱型斷面斷面性質的計算（$A$、$I$、$r$）
2. 考核 LRFD 壓力桿件設計流程（$\lambda_c \to F_{cr} \to \phi_c P_n$）
3. 考核考生在兩個方向中能否正確選取控制方向

---

## 3. 解題戰略地圖與陷阱分析 (Strategic Roadmap & Trap Analysis)

**作戰計畫：**
1. 計算箱型斷面面積 $A$ 與迴轉半徑 $r$
2. **局部挫屈檢核** $b/t$（箱型壁板為有側支撐板元）→ 決定是否需折減
3. 計算兩方向之 $KL/r$，取最大者，並檢核 $KL/r \le 200$
4. 計算 $\lambda_c$，判斷挫屈類型
5. 計算 $F_{cr}$，再求 $\phi_c P_n = \phi_c F_{cr} A$
6. 比較 $P_u$ 與 $\phi_c P_n$，判定 OK / NG

**關鍵陷阱：**

| 陷阱 | 說明 | 應對 |
|------|------|------|
| ❌ 箱型斷面 $I$ 計算錯誤 | 容易忘記空心部分，或計算外形 $b^4/12$ 不扣內孔 | 用公式 $I = (b_o^4 - b_i^4)/12$，或利用化簡 $r^2 = (b_o^2+b_i^2)/12$ |
| ❌ 只計算一個方向 | 題目明給兩組 $K$ 值，需取控制方向（較大 $\lambda_c$）| 兩方向都算，取最大 $KL/r$ |
| ❌ 公式 $0.658^{\lambda_c^2}$ vs $e^{-0.419\lambda_c^2}$ 混淆 | 考卷給的是指數形式，計算時用計算機直接代入即可 | 兩式等價，擇一使用即可 |
| ❌ **漏做局部挫屈檢核** | 題目要求「檢核柱構件之強度設計」，箱型斷面必須先確認壁板 $b/t$ 未達細長界限，否則 $F_{cr}$ 要折減 | $b/t = b_i/t = 23.0 < 1.40\sqrt{E/F_y} = 34.8$ → 非細長（詳 Step 2） |
| ⚠️ **$\phi_c$：0.85 還是 0.90？** | **台灣現行規範（民國 99 年版）與本題考卷年代皆為 $\phi_c = 0.85$**；AISC 360-05 起已改為 **0.90**。兩者相差 6% | 考場依台灣規範用 **0.85**；實務採 AISC 360-22 用 0.90（詳 §5.1） |

## 3.5 變數層次分析（Variable Hierarchy Analysis）

**最終目標：** 計算箱型斷面 $r$ → 兩方向 $KL/r$ 取最大 → $\lambda_c$ → $F_{cr}$ → $\phi_c P_n \geq P_u$（LRFD 壓力桿件完整流程）

### 主要公式（$\boxed{\phantom{x}}$ = 未知，待推導）

$$\boxed{r} = \sqrt{\frac{b_o^2 + b_i^2}{12}} \quad (\text{正方形箱型化簡})$$

$$\left(\frac{KL}{r}\right)_{\max} = \frac{K_2 L}{\boxed{r}} \quad \text{（取兩方向最大）}$$

## 4. 步驟化詳細計算過程 (Step-by-Step Detailed Calculation)

### Step 1：斷面幾何

**外側寬度：** $b_o = 80 \text{ cm}$

**內側寬度：** $b_i = b_o - 2t = 80 - 2(3.2) = 73.6 \text{ cm}$

**斷面積：**
$$A = b_o^2 - b_i^2 = 80^2 - 73.6^2 = 6400 - 5416.96 = \mathbf{983.04 \text{ cm}^2}$$

**斷面慣性矩（主軸，正方形對稱）：**
$$I = \frac{b_o^4 - b_i^4}{12}$$

**迴轉半徑（利用代數化簡）：**
$$r^2 = \frac{I}{A} = \frac{(b_o^4 - b_i^4)/12}{(b_o^2 - b_i^2)} = \frac{(b_o^2 + b_i^2)(b_o^2 - b_i^2)}{12(b_o^2 - b_i^2)} = \frac{b_o^2 + b_i^2}{12}$$

$$r^2 = \frac{80^2 + 73.6^2}{12} = \frac{6400 + 5416.96}{12} = \frac{11816.96}{12} = 984.75 \text{ cm}^2$$

$$\boxed{r = \sqrt{984.75} = 31.38 \text{ cm}}$$

---

### Step 2：局部挫屈檢核（$b/t$）— 「檢核強度設計」不可略的第一關

箱型斷面的四片壁板**四邊均有支撐**，屬「**有側支撐板元**」（stiffened element），受均勻壓應力：

$$\frac{b}{t} = \frac{b_i}{t} = \frac{73.6}{3.2} = 23.0$$

$$\lambda_r = 1.40\sqrt{\frac{E}{F_y}} = 1.40\sqrt{\frac{2040}{3.3}} = 1.40 \times 24.87 = 34.8$$

$$23.0 < 34.8 \;\Rightarrow\; \textbf{非細長斷面（non-slender）}$$

$\Rightarrow$ 無局部挫屈折減（$Q = 1.0$），可直接以整體彎曲挫屈決定 $F_{cr}$、且全斷面積 $A$ 皆有效。

> **策略註解：** 題目要求「**檢核**上述柱構件之強度設計」，箱型斷面的第一件事就是壁板 $b/t$——
> 若 $b/t$ 超過 $\lambda_r$，$F_{cr}$ 須改用有效寬度（或 $Q$ 係數）折減，後面所有數字都要重算。
> 台灣現行規範的等價寫法為 $b/t \le 50/\sqrt{F_y}$（$F_y$ 以 tf/cm² 計）$= 50/\sqrt{3.3} = 27.5$，
> 23.0 < 27.5 同樣通過（該式較 AISC 的 34.8 保守）。

---

### Step 3：計算兩方向之 $KL/r$

$$\frac{K_1 L}{r} = \frac{2.284 \times 400}{31.38} = \frac{913.6}{31.38} = 29.11$$

$$\frac{K_2 L}{r} = \frac{2.397 \times 400}{31.38} = \frac{958.8}{31.38} = \mathbf{30.55}$$

**控制方向：** 第二方向（$K_2 = 2.397$ 較大），$KL/r = 30.55$

**細長比上限檢核：** $KL/r = 30.55 < 200$ ✓（規範對壓力桿件之建議上限）

---

### Step 4：計算細長比參數 $\lambda_c$

$$\lambda_c = \frac{KL}{\pi r}\sqrt{\frac{F_y}{E}} = \frac{30.55}{\pi}\sqrt{\frac{3.3}{2040}}$$

$$= \frac{30.55}{3.1416} \times \sqrt{0.001618} = 9.724 \times 0.04022$$

$$\boxed{\lambda_c = 0.391}$$

由於 $\lambda_c = 0.391 \leq 1.5$，為**非彈性挫屈**。

---

### Step 5：計算臨界應力 $F_{cr}$

$$F_{cr} = e^{-0.419\lambda_c^2} \times F_y = e^{-0.419 \times 0.391^2} \times 3.3$$

$$= e^{-0.419 \times 0.153} \times 3.3 = e^{-0.0641} \times 3.3$$

$$= 0.9379 \times 3.3$$

$$\boxed{F_{cr} = 3.095 \text{ tf/cm}^2}$$

---

### Step 6：計算設計強度 $\phi_c P_n$ 並與 $P_u$ 比較

**標稱強度：**

$$P_n = F_{cr} \times A = 3.095 \times 983.04 = 3{,}042 \text{ tf}$$

**（a）依台灣現行規範（民國 99 年版，$\phi_c = 0.85$）——考場作答用：**

$$\phi_c P_n = 0.85 \times 3{,}042 = \mathbf{2{,}586 \text{ tf}}$$

$$\frac{P_u}{\phi_c P_n} = \frac{1119}{2586} = 0.433 < 1.0 \quad \Rightarrow \text{ OK} \checkmark$$

**（b）依最新規範（AISC 360-16／-22，$\phi_c = 0.90$）：**

$$\phi_c P_n = 0.90 \times 3{,}042 = \mathbf{2{,}738 \text{ tf}}$$

$$\frac{P_u}{\phi_c P_n} = \frac{1119}{2738} = 0.409 < 1.0 \quad \Rightarrow \text{ OK} \checkmark$$

$$\boxed{P_u = 1119 \text{ tf} \ll \phi_c P_n = 2{,}586 \text{ tf}\ (\phi_c=0.85) \ \Rightarrow\ \text{強度設計 OK}}$$

**結論：** 三項檢核（局部挫屈 $b/t$、細長比上限、整體彎曲挫屈強度）全部通過。
利用率僅 43.3%（新規範 40.9%），斷面對此柱非常充裕。

## 5. 關鍵爭議點與進階探討 (Critical Issues & Advanced Discussion)

### 5.1 依最新規範計算：$\phi_c$ 由 0.85 提高為 0.90

| 項目 | 台灣現行規範（民國 99 年版，考場依據） | AISC 360-16／-22（最新規範） | 本題影響 |
|:---|:---|:---|:---|
| **$\phi_c$** | **0.85** | **0.90** | $\phi_cP_n$：2,586 → **2,738 tf**（+5.9%）；DCR 0.433 → 0.409 |
| 界限判準 | $\lambda_c \le 1.5$ | $KL/r \le 4.71\sqrt{E/F_y} = 117.1$ | 等價（$1.5\pi = 4.712$）；本題 30.55 < 117.1，同屬非彈性 |
| $F_{cr}$ 公式 | $e^{-0.419\lambda_c^2}F_y = 0.658^{\lambda_c^2}F_y$ | $\left[0.658^{F_y/F_e}\right]F_y$ | **完全相同**（$F_y/F_e \equiv \lambda_c^2$）——見下方驗算 |
| 局部挫屈界限（箱型壁板） | $b/t \le 50/\sqrt{F_y}$（tf/cm²）$= 27.5$ | $b/t \le 1.40\sqrt{E/F_y} = 34.8$ | 兩者皆通過（23.0） |
| 細長比上限 | 建議 $KL/r \le 200$ | 同（E2 條文說明） | 30.55 ✓ |

**$F_{cr}$ 兩式等價的數值驗算（AISC 360-22 形式）：**

$$F_e = \frac{\pi^2 E}{(KL/r)^2} = \frac{9.8696 \times 2040}{30.55^2} = \frac{20{,}134}{933.3} = 21.57 \text{ tf/cm}^2$$

$$\frac{F_y}{F_e} = \frac{3.3}{21.57} = 0.1530 \;(= \lambda_c^2 = 0.391^2 \ \checkmark)$$

$$F_{cr} = \left[0.658^{0.1530}\right] \times 3.3 = 0.9379 \times 3.3 = 3.095 \text{ tf/cm}^2 \ \checkmark$$

**結論：** 最新規範對本題的**唯一實質差異就是 $\phi_c$**。台灣現行有效版本仍為民國 99 年（2010）修正版
（$\phi_c = 0.85$），參照 AISC 360-16 的修正草案已完成研究但尚未發布施行。
**考場請用 0.85**（$\phi_cP_n = 2{,}586$ tf）；實務若依 AISC 360-22 則為 2,738 tf。

### 5.2 為何利用率偏低（43%）？

本題有效長度係數 $K_1 = 2.284$、$K_2 = 2.397$，遠超過一般框架（$K \approx 1.0 \sim 1.5$），意味著柱的端部約束趨近於自由端（類似懸臂柱），使有效長度 $KL$ 接近 9.6 m。

然而箱型斷面 $80 \times 80$ cm、板厚 3.2 cm，迴轉半徑 $r = 31.38$ cm 極大，導致 $KL/r = 30.55$ 仍屬**短柱範疇**（短柱一般定義為 $KL/r < 50$），應力主要由降伏控制（$F_{cr}/F_y = 0.938$，接近 1），故設計強度高。這在大斷面、短柱情形完全合理。

### 5.3 等價公式說明

$$e^{-0.419\lambda_c^2} = 0.658^{\lambda_c^2}$$

**推導：**
$$0.658^{\lambda_c^2} = e^{\lambda_c^2 \ln(0.658)} = e^{-0.419\lambda_c^2} \quad (\because \ln 0.658 = -0.419)$$

考場使用計算機時，兩種形式均可。

### 5.4 箱型斷面迴轉半徑化簡公式的適用條件

$$r^2 = \frac{b_o^2 + b_i^2}{12}$$

此公式僅適用於**正方形箱型斷面**（兩方向相同尺寸）。若為矩形箱，需分別計算 $I_x$、$I_y$ 與對應 $r_x$、$r_y$，不可混用。


### 5.5 為什麼「檢核」題一定要寫局部挫屈？

本題只給 $b_o$、$t$、$F_y$、$E$、$K$、$L$、$P_u$，看似只要算 $\phi_cP_n$ 比一比。但題目用的動詞是
「**檢核**上述柱構件之強度設計」——強度設計的完整檢核鏈是：

```
① 板元局部挫屈  b/t ≤ λr ？   → 決定 A 與 Fcr 是否需折減
② 桿件細長比    KL/r ≤ 200 ？ → 決定設計是否合理
③ 整體彎曲挫屈  φcPn ≥ Pu ？  → 主檢核
```

三項全寫才是完整答案。本題 $b/t = 23.0$ 距界限 34.8 還有餘裕，但這正是「板厚 3.2 cm」這個
看似多餘的條件之所以會出現在題目裡的原因——不寫 $b/t$，等於沒看見這個提示。
