# 塊狀剪力（Block Shear Rupture）計算

**方法 ID：** block-shear
**知識分類：** 解題工具 / 接合設計
**適用題型：** SS-U1-1 拉力桿件、SS-U1-4 接合設計
**出現題數：** 8 題

---

## 核心原理

塊狀剪力（Block Shear）是拉力構材接合端部的破壞模式：一個由剪力面（平行拉力）和拉力面（垂直拉力）所圍成的「塊體」，沿剪力面剪斷、沿拉力面拉斷，同時發生。

**考卷版（本國 LRFD，AISC LRFD 1993／1999 J4.3；2015、2021 年考卷所附即此）——依大小擇一式：**

$$F_uA_{nt} \ge 0.6F_uA_{nv}:\quad \phi R_n = \phi\left[0.6F_yA_{gv} + F_uA_{nt}\right] \le \phi\left[0.6F_uA_{nv} + F_uA_{nt}\right]$$

$$0.6F_uA_{nv} > F_uA_{nt}:\quad \phi R_n = \phi\left[0.6F_uA_{nv} + F_yA_{gt}\right] \le \phi\left[0.6F_uA_{nv} + F_uA_{nt}\right]$$

觀念：斷裂發生在**較大**的那個面，另一個面降伏。

**AISC 360-05 以後（非考卷版）：** $\phi R_n = \phi\left[0.6F_uA_{nv} + U_{bs}F_uA_{nt}\right] \le \phi\left[0.6F_yA_{gv} + U_{bs}F_uA_{nt}\right]$（單一式取小）

其中：
- $\phi = 0.75$
- $A_{nv}$：剪力面淨面積（扣孔洞）
- $A_{nt}$：拉力面淨面積（扣孔洞）
- $A_{gv}$：剪力面毛面積
- $U_{bs}$（僅 360 版）：拉力面應力均勻 = 1.0（含角鋼單行螺栓）；拉力面應力不均（如梁端切缺多行螺栓）= 0.5

**考卷版是「依大小擇一式」，不是兩式取小**；360 版才是單一式取小。

## 解題步驟

```
Step 1  畫出破壞塊體
        識別：剪力面（從螺栓群側邊延伸至端部，平行拉力方向）
              拉力面（螺栓群端部，垂直拉力方向）

Step 2  計算 Agv 和 Anv（剪力面）
        Agv = 剪力面長度 × t（板厚）
        Anv = (剪力面長度 - n½ × 孔徑) × t
        n½ = 剪力面上的孔洞數（端孔算半個時用孔徑整數）

Step 3  計算 Agt 和 Ant（拉力面）
        Agt = 拉力面長度 × t
        Ant = (拉力面長度 - n × 孔徑) × t
        n = 拉力面上的孔洞數

Step 4  比較 FuAnt 與 0.6FuAnv（考卷版）
        FuAnt ≥ 0.6FuAnv → 拉力面斷裂、剪力面降伏：0.6FyAgv + FuAnt
        0.6FuAnv > FuAnt → 剪力面斷裂、拉力面降伏：0.6FuAnv + FyAgt

Step 5  上限檢查
        φRn ≤ φ(0.6FuAnv + FuAnt)

Step 6  φ = 0.75，得 φRn
        （若題目指定 AISC 360：改用單一式並判斷 Ubs）

Step 7  與拉力需求 Tu 比較
        Tu ≤ φRn → OK
```

## 孔徑計算規則

| 螺栓標稱直徑 $d_b$ | 標準孔孔徑 | 計算用孔徑（$+3$ mm） |
|-------------------|-----------|----------------------|
| M22（7/8"） | 24 mm | 24 + 3 = 27 mm = 2.7 cm |
| M24（1"） | 26 mm | 26 + 3 = 29 mm ≈ 2.9 cm |
| M20 | 22 mm | 22 + 3 = 25 mm = 2.5 cm |

> 台灣規範：計算淨面積時，孔徑 = 螺栓直徑 + 3 mm（標準孔為螺栓直徑 + 2 mm，再加 1 mm 衝孔損傷）

## 常見破壞塊體類型

**類型 A：單排螺栓（一個剪力面）**
```
────●────●────●────→ 拉力方向
    ↑剪力面            ↑拉力面
```

**類型 B：雙排螺栓（兩個剪力面）**
```
────●────●────●────→
────●────●────●────→
↑左剪力面   ↑右剪力面  ↑拉力面（最外排間）
```
→ $A_{nv}$ = 兩側剪力面淨面積之和

**類型 C：角鋼單肢接合（單行螺栓）**
→ 拉力面短、應力近似均勻；360 版 $U_{bs} = 1.0$（0.5 用於拉力面應力不均，如梁端切缺多行螺栓）

## 常見陷阱

| # | 陷阱 | 對策 |
|---|------|------|
| 1 | **考卷版是擇一式** | 依 $F_uA_{nt}$ 與 $0.6F_uA_{nv}$ 大小選一式（再檢查上限），不是兩式取小；360 版才是取小 |
| 2 | **計算用孔徑比實際孔大 3 mm** | 淨面積計算用 $d_b + 3$ mm，非 $d_b + 2$ mm |
| 3 | **剪力面孔數計算** | 剪力面沿長度方向的孔數，端點孔可能算 1/2 或完整 |
| 4 | **$\phi = 0.75$，不是 0.9** | Block Shear 的 $\phi = 0.75$（斷裂型破壞） |
| 5 | **多塊體可能存在** | 斜線排列螺栓時可能有多個破壞路徑，需各自計算取最小 |
| 6 | **Ubs 判斷（僅 360 版）** | 拉力面應力均勻（含角鋼單行）= 1.0；不均勻（梁端切缺多行）= 0.5 |
