## 跨科通用

| 圖型 | recipe / 作法 | 攔下的錯誤 |
|---|---|---|
| 題目重繪 | primitives 組（構材＋支承＋載重＋尺寸） | 截圖看不清支承型式；節點命名與解題不一致 |
| 自由體圖 FBD | primitives（隔離體邊界用虛線，切斷面標內力） | 漏算某個反力；內力方向假設前後不一致 |
| 量級比較 | `bar_compare` | 答案量級錯（超出物理上下界） |
| 決策流程 | 交給 Mermaid，不用本 skill | — |

FBD 的畫法規定：隔離體用虛線框住，被切斷處**必須**同時標出軸力／剪力／彎矩三者
（即使某項為零也要標 0），否則圖本身就漏了自由度。

## SA 結構學

| 圖型 | recipe / 作法 | 攔下的錯誤 |
|---|---|---|
| 自由度辨識 | primitives（保留的 DOF 用藍色，消去的畫紅叉） | 忽略軸向變形後 DOF 數目算錯 → 矩陣階數錯 |
| 單位位移狀態（勁度矩陣每一行） | primitives ＋ `compose` | $K_{ij}$ 正負號寫反 |
| 變形形狀 ＋ 反曲點 | `column_shape` / `beam_shape` | 柱畫成單曲率；反曲點位置沒算 |
| 彎矩圖 BMD | `plot_function` 或 `polygon` 直接繪於受拉側 | 節點彎矩不平衡；受拉側畫反 |
| 梁三聯圖 | `beam_vm` | 剪力零點與彎矩極值位置不符 |
| 桁架力流 | `truss_forces` | 拉壓判斷錯；零桿沒認出來 |
| 影響線 | `plot_function`（x 為載重位置） | 與彎矩圖搞混 |

**單位位移狀態圖是 SA 矩陣題最值得畫的一張。** 矩陣位移法的失分幾乎都在耦合項正負號，
而純算式沒有任何地方會提醒。三個狀態各畫一格，力的方向直接看得出來。

**BMD 一律繪於受拉側**，並在圖說註明。同一份 wiki 內不得中途改慣例。

## SS 鋼結構設計

| 圖型 | recipe / 作法 | 攔下的錯誤 |
|---|---|---|
| 桁架力流（拉紅／壓藍） | `truss_forces` | 只對受壓桿檢核挫屈這件事被忽略 |
| 挫屈模態形狀 | `member_shape` ＋ 正弦函數 | 有效長度係數 $K$ 取錯（模態圖直接看出反曲點數） |
| $\lambda$–$F_{cr}$ 曲線 | `plot_function`（Euler 段與降伏段分色） | 用錯公式段（彈性 vs. 非彈性分界） |
| 斷面局部挫屈分類 | primitives（標 $b/t$、$h/t_w$ 與規範界限） | 半密實／細長判斷錯 |
| 側向扭轉挫屈 $L_b$ 分區 | `plot_function`（$L_p$、$L_r$ 分界） | 落在哪一區判斷錯 |
| 接合破壞模式對照 | primitives 多格 `compose` | 漏檢某一種破壞模式 |

挫屈模態圖的橫向撓度用 $\sin(n\pi\xi)$ 系列，$n$ 由邊界條件決定；
$K$ 值與圖上的反曲點數必須對得起來，這正是它攔錯的方式。

## RC 鋼筋混凝土

| 圖型 | recipe / 作法 | 攔下的錯誤 |
|---|---|---|
| 斷面／應變／應力三聯 | `rc_flexure` | 中性軸深度 $c$ 與 $a$ 搞混；$C_c \ne T$ |
| P-M 交互曲線 | `pm_interaction` | 平衡點位置錯；壓力／拉力控制分區搞反 |
| 剪力鋼筋配置與 $V_s$ 分擔 | `plot_function` ＋ primitives | $V_c$ 與 $V_s$ 分擔比例錯 |
| 裂縫型態／破壞模式 | primitives（撓曲裂縫垂直、剪力裂縫斜向） | 破壞模式判斷錯 |
| 開裂前後斷面轉換 | primitives 兩格對照 | 開裂慣性矩用錯 |

`rc_flexure` 的垂直尺度三格共用，所以 $c$、$a$、$d$ 的相對位置是真的；
水平尺度只是示意。若圖上 $a > c$，代表 $\beta_1$ 用錯（$a = \beta_1 c$ 且 $\beta_1 \le 0.85$）。

## SD 結構動力學

| 圖型 | recipe / 作法 | 攔下的錯誤 |
|---|---|---|
| 振態形狀（多自由度） | primitives，每個振態一格 `compose` | 振態正交性沒檢查；節點數與振態序號不符 |
| 位移時程 | `plot_function` | 阻尼衰減率與 $\xi$ 不符 |
| 反應譜 | `plot_function`（週期為橫軸） | 讀譜時週期取錯 |
| 動力放大係數 $DAF$–$\beta$ | `plot_function`（不同 $\xi$ 多條曲線） | 共振區判斷錯 |
| 集中質量模型 | primitives（質量畫方塊、彈簧畫鋸齒） | 自由度數目與質量數不符 |

第 $n$ 振態應有 $n-1$ 個節點（零位移點），畫出來一數就知道對不對——
這是振態圖最主要的檢核價值。

## SM 土壤力學

| 圖型 | recipe / 作法 | 攔下的錯誤 |
|---|---|---|
| 應力分佈（$\sigma_v$、$u$、$\sigma'_v$ 三線） | `plot_function`（深度為縱軸） | 有效應力與全應力搞混；水位以下算錯 |
| 莫爾–庫倫破壞包絡線 | `mohr2` ＋ 包絡線 | 破壞判準用錯 |
| 土層剖面 | primitives（各層填不同灰階＋水位符號） | 層次深度標錯 |
| 主動／被動土壓分佈 | `plot_function` | 主被動係數取反 |
| 壓密曲線 $e$–$\log p$ | `plot_function`（對數橫軸） | 前期固結壓力判讀錯 |

深度為縱軸的圖，把 `Canvas` 的 y 軸當深度用並在圖上明確標「深度向下為正」，
不要沿用 y 向上的直覺。

## MM 材料力學

| 圖型 | recipe / 作法 | 攔下的錯誤 |
|---|---|---|
| 三向莫爾圓 | `mohr3` | 絕對最大剪應力取到小圓（應恆為大圓半徑） |
| 二維莫爾圓 | `mohr2` | $2\theta_p$ 方向搞反 |
| 應力元素方向 | primitives（原始元素與主應力元素兩格對照） | 主軸旋轉方向畫反 |
| 梁彎曲正／剪應力分佈 | `plot_function`（斷面高度為縱軸） | 剪應力最大位置取在外緣（應在中性軸） |
| 扭轉剪應力分佈 | primitives（半徑線性分佈） | 實心與空心分佈搞混 |
| 應力–應變曲線 | `plot_function` | 比例限、降伏、極限點位置標錯 |

`mohr3` 的淡灰區（大圓內、兩小圓外）就是所有可能應力狀態的所在；
若解題算出的 $\tau_{max}$ 不等於大圓半徑，就是取錯圓。

## 不要畫的圖

以下情況直接跳過，不要為了湊數量而畫：

- **純代數推導**（例如三角函數恆等式化簡）——沒有幾何可畫。
- **純查表**（例如查鋼材規格表取 $Z_x$）——表格比圖清楚。
- **單一數值的驗算**——一行算式就夠了。
- **只是把算式重畫一次的圖**——沒有攔錯能力，是裝飾。
- **需要真實照片才有意義的內容**（工地破壞照、材料外觀）——本 skill 畫不了，也不該畫。

判準很簡單：**寫得出「這張圖攔下什麼錯」就畫，寫不出來就不畫。**
