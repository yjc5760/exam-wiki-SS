# 向量圖指南

## 原則

1. **所有幾何、曲線、標註數字都由程式算出**：曲線用 `Plot.curve(fn, a, b)` 逐點計算；挫屈形狀用解析解；斷面依實際尺寸比例。不手描、不用 AI 生圖、不截圖。
2. **一張圖一個結論**，結論寫在圖內（紫框）也寫在圖說（粗體）。
3. 向量優先：力、反力、合力用箭頭（`A()`），頭尾相接表示向量相加；彎矩用弧形箭頭（`curve_arrow()`）。
4. 寬固定 900（`svg(900, H, ...)`），高依內容；圖說放在 `{{FIG:name|圖說}}`。

## 已踩過的坑（一定要避開）

| 坑 | 症狀 | 解法 |
|---|---|---|
| 字級放大到 14px 後 | 原本剛好的標籤互相重疊、超出畫布 | 改字級後一定重跑 `render_check.py` 並逐張看圖 |
| 標籤放在曲線算出的 y 上 | 曲線超出 ymax 時標籤跑到畫布外（看不到） | 標籤位置用固定座標，或先 `min()` 夾在範圍內 |
| `.fig svg{display:block}` 寫成後代選擇器 | 圖說裡 KaTeX 的根號（內部是 svg）消失 | CSS 用 `.fig>svg`（build.py 已處理） |
| 中文寫進 `T()` 的 `*斜體*` | 中文被套成襯線斜體 | 只把變數放進 `*...*` |
| 分數字元 `⅔`、勾叉 `✔✘` | 部分字型缺字 | 寫成 `2/3`；勾叉只放在 HTML 內文 |
| 右側說明框 | 文字超出框寬 | 中文字寬約等於字級；先估寬度 |
| 圖內 x 軸標籤太長 | 被裁掉（例：「側向變位 δ」） | 軸標籤用符號，說明放圖說 |
| 只看自動檢查 | 文字壓到曲線抓不到 | 每張 `fig_NN.png` 都要目視 |
| 曲線用「圖說」的數字畫 | 圖文不一致 | 一律 import `calcs.py` |

## 好用的圖型（依用途）

- **向量合成**：兩根桿件對節點的力頭尾相接（穩定 vs 不穩定）。
- **兩線取小**：材料上限水平線＋幾何上限曲線，交點就是分界（柱強度、GSY vs NSF、最經濟長度）。
- **極限檢查曲線**：橫軸無因次化（\(L/\bar x\)、\(\lambda_c\)、\(G\)），標出 0、1、∞ 附近的行為。
- **由方程式解出的圖表**：例如對位圖背後的方程式逐點解出 \(K\)–\(G\)，比照抄圖表更能顯示方向性。
- **錯解對照**：同一張圖畫正解與常見錯解（虛線），標出錯在哪。
