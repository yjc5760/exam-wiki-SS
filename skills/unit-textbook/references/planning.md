# 計畫書範本與規劃方法

## 一、怎麼挑「種子」

種子是全書唯一要求記住的東西。挑選標準：

1. **第一性原理**：平衡、相容（變形協調）、材料律（應力–應變、降伏準則）、能量、穩定（推歪 vs 拉回）。
2. **一張圖就能記住**：每顆種子都要配一張「畫得出來」的圖（自由體圖、莫爾圓、應力分布、變形形狀）。
3. **能長出多條公式**：一顆種子至少推出 2 條規範公式；只推出 1 條的通常不是種子，是公式。
4. **無法推導的規範數字另列**：φ 值、安全係數、經驗係數。它們不硬背，而是用「破壞前有沒有預警」「真實世界沒有完美固接」這類**排序道理**記大小。
5. **4～8 顆**。超過 8 顆讀者記不住，就失去意義。

## 二、怎麼分章、分冊

- 依 `unit-XX-Un-m.json` 的考點群（`clusters`）與 `F[]` 的分組（`g`）排章；**每章 1～3 顆種子**。
- 單元有兩條本質不同的主軸（例：拉＝材料強度、壓＝幾何穩定）→ 分兩冊，章號連續。
- 久未出題、與他科重疊、投報率低的子題（看 `risk` 表）→ 請使用者決定精簡或不寫。
- 每冊最後一章固定是**總整理**。

## 三、計畫書範本（給使用者審閱）

```
一、核心設計：只記 N 顆種子，其他公式都在草稿紙上推出來
   （種子表：種子｜內容｜用哪張圖記｜會推出哪些公式）
   另外要背的數字只有一張小卡：……

二、每條公式都照同樣 6 步寫
   看圖 → 白話物理 → 從種子推導（每步一件事）→ 代極端值檢查 → 標示考卷給不給 → 30 秒重建卡

三、章節大綱（表：章｜主題｜主要向量圖）

四、為閱讀方便的排版：內文 18px、圖內最小字 14px、一頁一觀念、推導逐行編號

五、檔案與驗證：輸出 study/textbook-XX-Un-m.html＋.pdf；圖由程式依 calcs.py 數值繪製；
   數值重算、給背標籤對照 unit json、瀏覽器截圖檢查

請你決定（不回覆就照第一個選項）：
1. 既有草稿：沿用改寫（建議）／全部重寫
2. 篇幅：一冊／拆成 A、B 兩冊
3. 兩套規範：並列對照（建議）／以 X 為主、Y 放附錄
4. 低投報子題 Z：完整一章／精簡 2 頁／不寫
```
