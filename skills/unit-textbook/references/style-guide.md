# 寫作規範

## 1. 讀者與語氣

- 讀者記不住長串符號，但記得住**畫面**與**道理**。每一串符號都要翻譯回一個畫面。
- 繁體中文、台灣用語；專有名詞第一次出現附英文（分歧 bifurcation）。
- 短句；一段只講一件事；推導一行只做一步。
- 不用「顯然」「易知」。讀者看不出來的地方，就是要寫的地方。

## 2. 每條公式的六步

| 步 | 放在哪 | 內容 |
|---|---|---|
| ① 看圖 | `{{FIG:...}}` | 先有圖，公式是圖的結果 |
| ② 白話 | `<p>` 或 `.why` | 這條公式在防哪一種破壞／描述哪一種行為 |
| ③ 推導 | `.derive` + `.st` 編號 | 從種子出發，三步左右；最後一步 `\boxed{}` 並寫「✔ 這就是規範寫的那條」 |
| ④ 極限檢查 | `.check` | 代 0、代 ∞、代特殊值，說明為什麼合理；也用來抓寫錯的公式 |
| ⑤ 給背標籤 | `.tg must/half/give` | 依 `unit-XX-Un-m.json` 的 `F[].lv`；附證據年份或題號 |
| ⑥ 重建卡 | `.rebuild` | 畫什麼 → 從哪顆種子 → 兩三步 → 一個檢查 |

## 3. 各種框

| class | 用途 |
|---|---|
| `.lead` | 章首：「讀完這一章，你應該能自己寫出……」＋要記的只有哪幾個 |
| `.box` | 本章公式與考卷標籤表；範例題目 |
| `.seed` | 種子（全書只出現 4～8 次） |
| `.derive` + `<span class="st">①</span>` | 推導，逐行編號 |
| `.check` | 極限檢查、自我檢查比值 |
| `.why` | 白話、記法、「為什麼」 |
| `.trap` | 陷阱，附題號 |
| `.rebuild` | 30 秒重建卡 |
| `<details><summary>` | 🙈 蓋住重推（PDF 會自動展開答案） |
| `.kw` | 要記的數字（紫底） |
| `.tg.must／.half／.give` | 必背／別賭／會給 |

## 4. 誠實原則（最重要）

- **試驗迴歸式不能假裝推導**（例：\(U=1-\bar x/L\)、\(s^2/4g\)、0.658）。寫明「這是試驗式」，再給「長相有道理」的記法與方向性檢查。
- 記憶法若只是助記（例：「斜線多走的路打對折」），要標明是記法、不是嚴格推導。
- 自訂的簡化模型（例：線性殘留應力 ±0.3Fy）要寫明假設，並說明數值只代表趨勢。
- 規範版本差異（台灣 vs AISC、新舊版）要標註，並提醒「考卷有附就照考卷」。
- 發現既有教材或題解有錯：在講義用正確值，**另外告訴使用者**；不要擅自改 `raw/` 或其他教材。

## 5. 範例

- 一個貫穿全冊的範例，讓各章公式接成一個完整答案；最後一章總結「到底誰控制」。
- 兩套規範並列時，寫出可驗算的關係（例：拉力 LRFD／ASD 恰為 1.5；柱 1.39～1.47），讓讀者自我檢查。
- 數字全部抄自 `calcs.py` 的輸出。

## 6. 排版與顏色

- 內文 18px、行高 1.9；圖內最小字 14px；PDF 為 A4，每章換頁。
- 顏色固定：綠＝拉力／材料強度；紅＝壓力／挫屈／規範曲線；藍＝幾何／勁度／理想值；橘＝剪力／殘留應力／ASD；紫＝種子、關鍵交點。
- 標題：`h2` 加 `class="t"`（綠）、`"c"`（紅）、`"k"`（紫）；分冊封面 `theme` 用 `t`／`c`／`a`／`k`。
