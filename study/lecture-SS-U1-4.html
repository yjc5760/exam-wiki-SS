§0　全景：這個單元只有一句話

構材設計問「這個斷面撐不撐得住」，答案是一個強度；
接合設計問「力量在這裡換了幾次手、哪一次換手最弱」，答案是一串強度取最小值。

這句話決定了本單元 26 題的全部長相。構材題（U1-1 拉壓、U1-2 梁、U1-3 梁柱）你算的是一個控制斷面； 接合題你算的是一條傳力路徑：力從母材 A 走進來，交給緊結物（螺栓或銲道），再交還給母材 B。 每一次「換手」都是一個獨立的極限狀態，任何一站不及格，整個接合就不及格。

為什麼公式長那樣？只要問三件事 —— ① 這個極限狀態發生在哪一個面上？ ② 那個面是被剪的還是被拉的？（剪 → 乘 0.6；拉 → 不乘） ③ 我們允許它降伏還是要它斷裂？（降伏 → 用 \(F_y\) 配毛面積；斷裂 → 用 \(F_u\) 配淨面積）

§1　換手鏈：接合的極限狀態清單

接合的極限狀態不需要背 —— 沿著力量走一遍，路上會經過哪些面，那些面就是極限狀態。

1.1 螺栓接合：沿著力走一遍

拿一個單搭接（lap splice）來走：拉力從母材 A 進來 → 通過 A 的淨斷面（有孔）→ 在孔壁把力壓給螺栓 → 螺栓桿被剪 → 螺栓在 B 的孔壁把力壓回去 → 通過 B 的淨斷面出去。 另外，螺栓群後方的那塊母材有可能被整塊撕下來（塊狀剪力）；若是摩阻型接合，還多一個「不准滑動」的門檻。

1.3 為什麼還有一條「最小接合強度」規定

把上面的清單算完，你得到的是「這個接合能傳多少力」。但規範還會再壓一條下限：

最小接合強度規定（台灣鋼構規範／AISC 精神一致）：
  • 一般接合：設計強度不得小於 120 kN（約 12 tf）
  • 續接（splice）：不得小於被續接構材強度的一定比例（考題常見「不得小於構材強度之一半」）
  • 耐震接頭：需承受構材超強後的力（× \(R_y\) 或 × 1.25，見 §7）
為什麼要有下限？因為接合是脆性的、而構材是延性的。 如果接合比構材弱，破壞就會發生在沒有預警的那一端 —— 這叫「弱接合強構材」，是設計上的災難。 規範用一條下限強迫破壞順序倒過來：先讓構材降伏（看得見、變形大），接合始終保持完整。 這就是接合版的能力設計（Capacity Design）。

考試意義：看到「續接」兩個字，第一個反射動作是去算 \(0.5\times\) 構材強度， 再和題目給的 \(V_w\)、\(M_w\) 比大小取大者當設計力。 只用題目給的內力去設計 = 直接扣分。出自 SS-2020-4。
§1 因果鏈：力量必須換手 → 每一次換手產生一個新的破壞面 → 面有剪／拉之分、有降伏／斷裂之分 → 每個面一條公式 → 設計強度取最小值 → 再壓一條「不得低於構材強度」的下限。

§2　兩把尺：0.6 是什麼、\(F_y\) 與 \(F_u\) 怎麼選、\(\phi\) 為什麼不一樣

接合章節看起來有二十條公式，其實只有兩把尺在量：「剪還是拉」決定要不要乘 0.6； 「降伏還是斷裂」決定用 \(F_y\) 配毛面積、還是 \(F_u\) 配淨面積。剩下的只是把材料代號換掉。

2.1 為什麼是 0.6 —— von Mises 的 \(1/\sqrt{3}\)

金屬的降伏準則是 von Mises（畸變能準則）。單軸拉伸時降伏發生在 \(\sigma = F_y\)； 換成純剪狀態，同樣的畸變能只需要

$$\tau_y = \frac{F_y}{\sqrt{3}} = 0.577\,F_y \;\approx\; 0.6\,F_y$$

把 \(F_y\) 換成 \(F_u\)，就是剪力斷裂；把 \(F_u\) 換成銲材強度 \(F_{EXX}\)，就是銲喉剪斷。 三者是同一條式子的三種材料代號：

用在哪裡式子物理意義出現於
板材剪力降伏\(0.6F_y A_{gv}\)剪力面整片降伏（毛面積，尚未斷）塊狀剪力上限式、腹板剪力、接合鈑
板材剪力斷裂\(0.6F_u A_{nv}\)剪力面真的撕開（淨面積）塊狀剪力第一式

拉力面為什麼從來不乘 0.6？因為 0.6 是「剪」的折價。拉力面就是被拉開的，直接用 \(F_u A_{nt}\)。 所以塊狀剪力那兩條看起來很怪的混合式，其實只是「剪的那一項乘 0.6、拉的那一項不乘」—— 你不需要背它，只要能在圖上指出哪個面被剪、哪個面被拉。

2.2 \(F_y\) 配毛面積、\(F_u\) 配淨面積 —— 為什麼一定是這樣配

這個配對常被當成規定硬記，但它有很實在的理由：

降伏 → \(F_y\) ＋ 毛面積 \(A_g\)
降伏是整段構材的事。一旦到 \(F_y\)，應變迅速沿整個長度發展、伸長量以公分計， 孔那一小段（幾公分）的影響可以忽略，所以用全斷面。
破壞看得見 → \(\phi = 0.90\)
斷裂 → \(F_u\) ＋ 淨面積 \(A_n\)
斷裂是一個斷面的事，只發生在最弱的那一片。孔削掉多少就是少多少， 而且局部應力集中讓那一段先進入應變硬化，所以用 \(F_u\) 配淨面積。
破壞沒有預警 → \(\phi = 0.75\)

2.4 三個極限檢查，忘記公式時能自救

① 0.6 的方向檢查：剪力強度必須小於拉力強度。若你寫出 \(1.6F_y\)、\(0.06F_y\) 之類的係數，方向就錯了。
② \(U\) 的邊界檢查：\(U = 1-\bar{x}/L\)。\(\bar{x}=0\)（形心就在連接面上）→ \(U=1\)； \(L\to\infty\)（連接很長）→ \(U\to 1\)。兩個極限都必須回到「沒有遲滯」。若算出 \(U>1\)，取 1.0。
③ 塊狀剪力的量綱檢查：\(0.6F_u A_{nv}\) 與 \(F_u A_{nt}\) 都是力（tf 或 kN），可以相加。 若你把面積和應力加在一起，馬上就會看出量綱不對。
§2 因果鏈：von Mises → 純剪只需 \(F/\sqrt3\) → 剪的項一律乘 0.6 → 降伏是整段的事（\(F_y A_g\)）、斷裂是一個斷面的事（\(F_u A_n\)）→ 斷裂沒有預警 → \(\phi\) 從 0.90 降到 0.75 → ASD 就是同一組標稱強度除以 \(\Omega\)（1.5～2.0）。

§3　拉力接合端：剪力遲滯、淨斷面、塊狀剪力

本單元最高頻的組合（26 題中 10 題涉及）。三個極限狀態爭同一個位置， 而它們爭的其實是同一個問題：接合區的力，有沒有辦法均勻地分佈到整個斷面上？

3.1 剪力遲滯：力量不會轉直角

想像你抓著一支角鋼的一隻肢用力拉。力必須先沿著連接肢傳進來，再橫向剪過去才能傳到另一隻肢。 剪力傳遞需要距離，所以在接合端附近，未連接的那一肢來不及分擔到它該分擔的份 —— 這就是剪力遲滯（Shear Lag）。

圖 3-1　剪力遲滯的物理圖像。紫色虛線是實際的應力分佈包絡線 —— 離連接面越遠，應力落後越多。\(U\) 就是「這條實際分佈的面積」佔「均勻分佈面積」的比例。

3.2 \(U = 1-\bar{x}/L\)：兩個參數各自的物理意義

這條公式不是理論推導，是 Munse & Chesson（1963）大量拉力試件試驗的迴歸結果 （見 code-ref/shear-lag-u-basis）。但它的兩個參數各有很清楚的物理意義：
  • \(\bar{x}\)（形心到連接面的垂直距離）＝ 偏心程度。\(\bar{x}\) 越大，斷面的「重心」離施力面越遠， 力要繞的路越長 → 遲滯越嚴重。
  • \(L\)（接合長度）＝ 剪力有多少距離可以把力送過去。\(L\) 越長，橫向剪力有充分的長度把力送到外伸肢 → 遲滯越輕。
所以 \(U\) 的形式是 \(\bar{x}/L\) 的函數，這件事本身是可以理解的：偏心量除以可用長度＝無因次的遲滯程度。
圖 3-2　\(U\) 隨接合長度比的變化。曲線很快就趨近 1，代表把接合做長一點是消除剪力遲滯最便宜的手段； 反過來說，短接合（\(L/\bar{x} < 3\)）的懲罰非常重。這也解釋了規範為何有「最短接合長度」的規定。

3.3 塊狀剪力：把破壞塊「畫」出來

塊狀剪力（Block Shear Rupture）不是新公式，就是 §2 兩把尺的直接應用。它唯一的難點是畫對破壞塊。

圖 3-3　雙排螺栓的破壞塊：兩條剪力面（綠）＋一條拉力面（紅）。 剪力面的長度從最外排螺栓量到端部（含端距）；拉力面是兩條剪力面之間的橫向距離。
為什麼是 min(A, B) 而不是相加？因為 A、B 兩式描述的是同一個破壞的兩種可能路徑，不是兩個獨立的抗力來源：
  • 式 A：剪力面真的斷裂（\(0.6F_u A_{nv}\)）＋ 拉力面斷裂
  • 式 B：剪力面只到降伏（\(0.6F_y A_{gv}\)）＋ 拉力面斷裂
實際破壞會沿先發生的那條路徑走，所以取小值。相加＝把同一塊材料的抗力算了兩次。

\(U_{bs}\) 的意義：拉力面上的拉力是否均勻。均勻 → 1.0；明顯不均勻（例如單排螺栓的偏心接合、 梁端切槽 coped beam）→ 0.5。它就是「拉力面沒被充分利用」的折減。

題目設定：單角鋼 L125×125×12（\(A_g = 28.8\) cm²，形心到肢背 \(\bar{x} = 3.53\) cm）， 以一隻肢用 4 顆 M22 螺栓（\(d_b = 2.2\) cm）連接於接合板，縱向間距 7 cm、端距 4 cm， 螺栓線距肢背 4.5 cm。鋼材 \(F_y = 2.5\)、\(F_u = 4.1\) tf/cm²。求 LRFD 設計拉力強度。

Step 0：幾何

$$d_h = d_b + 0.3 = 2.5\ \text{cm}\ \text{（計算用孔徑，標準孔 } d_b+0.2 \text{ 再加 } 0.1 \text{ 衝孔損傷）}$$ $$L = 3\times 7 = 21\ \text{cm（4 顆螺栓 = 3 個間距）}$$

Step 1：全斷面降伏（GSY）—— 延性，\(\phi = 0.90\)

$$\phi_t P_n = 0.90\times 2.5\times 28.8 = \underline{64.8\ \text{tf}}$$

Step 2：淨斷面斷裂（NSF）—— 脆性，\(\phi = 0.75\)

$$A_n = 28.8 - 2.5\times 1.2 = 25.8\ \text{cm}^2$$ $$U = 1-\frac{\bar x}{L} = 1-\frac{3.53}{21} = 0.832 \quad\Rightarrow\quad A_e = 0.832\times 25.8 = 21.46\ \text{cm}^2$$ $$\phi_t P_n = 0.75\times 4.1\times 21.46 = \underline{66.0\ \text{tf}}$$

Step 3：塊狀剪力（BSR）—— 先畫塊

單排螺栓 → 一條剪力面（從最外螺栓到端部）＋一條拉力面（螺栓線到肢的自由邊）： $$L_{gv} = 4 + 3\times 7 = 25\ \text{cm}\quad\Rightarrow\quad A_{gv} = 25\times 1.2 = 30.0\ \text{cm}^2$$ $$A_{nv} = (25 - 3.5\times 2.5)\times 1.2 = 19.50\ \text{cm}^2 \quad\text{（4 顆螺栓，端孔算半個 → 3.5 孔）}$$ $$A_{nt} = \big[(12.5-4.5) - 0.5\times 2.5\big]\times 1.2 = 8.10\ \text{cm}^2$$ 取 \(U_{bs} = 1.0\)： $$\text{式A} = 0.6(4.1)(19.50) + 1.0(4.1)(8.10) = 47.97 + 33.21 = 81.18\ \text{tf}$$ $$\text{式B} = 0.6(2.5)(30.0) + 33.21 = 45.00 + 33.21 = 78.21\ \text{tf}$$ $$\phi R_n = 0.75\times \min(81.18,\ 78.21) = \underline{58.7\ \text{tf}}$$

Step 4：取最小值

$$\phi P_n = \min(64.8,\ 66.0,\ 58.7) = \boxed{58.7\ \text{tf}}\quad\text{塊狀剪力控制}$$
這個範例的自我檢查：
  • 三個數字應該落在同一個數量級（本例 58.7～66.0，差 12%）。若某一項只有其他項的 1/3， 通常是漏乘板厚、算錯孔數，或把 \(A_g\) 當 \(A_n\) 用。
  • 式 B 小於式 A 是正常的，因為 \(0.6F_y A_{gv}\)（45.0）小於 \(0.6F_u A_{nv}\)（47.97）。 若你算出式 B 遠大於式 A，八成是 \(A_{gv}\)、\(A_{nv}\) 弄反了。
  • 塊狀剪力控制是很常見的結果，尤其在端距小、接合短的情況 —— 這就是為什麼考題愛出它： 它是最容易被漏掉、卻最常控制的那一項。加大端距是最有效的補強手段（直接增加 \(A_{gv}\)、\(A_{nv}\)）。
\(U_{bs}\) 的爭議請照題目走。AISC J4.3 對角鋼單排螺栓的正規取值是 \(U_{bs}=1.0\)（拉力面上應力仍屬均勻）， 但部分教科書與 wiki/traps/CONNECTION-TRAPS 對「明顯偏心的單肢角鋼」採 \(U_{bs}=0.5\)。 考試時：題目給值就用題目的；沒給就用 1.0 並寫一句判斷理由（「螺栓對拉力面對稱、應力均勻，取 \(U_{bs}=1.0\)」）。 寫出理由比選對數字重要。
§3 因果鏈：只連部分斷面 → 力要橫向剪過去 → 需要距離 → 外伸肢應力落後（剪力遲滯）→ \(U = 1-\bar x/L\) → \(A_e = U A_n\) → 再加上「整塊被撕下來」的塊狀剪力 → 拉力接合端一律比 GSY／NSF／BSR 三者，取最小值。

§4　螺栓：兩個完全不同的世界

同一顆 A325 螺栓，可以用兩種完全不同的方式傳力。搞清楚「現在是哪個世界」， 本單元 10 題螺栓題就解決了一半。

4.1 傳力機制：摩擦 vs 承壓

圖 4-1　同一顆螺栓的兩個世界。左邊靠夾緊力產生的摩擦，右邊靠螺栓桿的剪力。 注意右圖的板已經錯開了 —— 承壓型接合本來就允許滑動，滑到孔壁貼住才開始傳力。

4.2 摩阻型：為什麼 \(\phi\) 可以等於 1.0

$$\phi R_n = \phi\,\mu\,D_u\,h_{sc}\,T_b\,n_s$$
符號典型值它從哪裡來
\(\mu\)（\(k_s\)）A 級 0.33～0.35／B 級 0.50接觸面處理試驗值。A 級＝軋延面除鏽；B 級＝噴砂處理
\(D_u\)1.13實際安裝預拉力的平均值比規範最小值高約 13%（統計結果）
\(h_{sc}\)標準孔 1.0／過大孔 0.85孔越大，滑動後移動量越大 → 折減
\(T_b\)A325-M22：176 kN規定最小預拉力 ≈ 0.7 \(F_{ub}A_{b,\text{有效}}\)（規範附表直接查）
\(n_s\)單剪 1／雙剪 2接觸面數，不是螺栓數
為什麼摩阻型的 \(\phi\) 是 1.0（或 0.85），而不是 0.75？ 因為滑動不是破壞。接合滑動了幾毫米，結構沒有斷、沒有掉，只是「不再是我原先設計的那個接合」—— 它變成了承壓型，還有第二層防線。既然後果不是崩塌，就不需要脆性破壞那種保守度。
  • 使用性極限（\(\phi = 1.0\)）：服務載重下不准滑動。用於疲勞構件、精密安裝、需要維持幾何的接合。
  • 強度極限（\(\phi = 0.85\)）：因數化載重下不准滑動。用於過大孔、滑動後會導致明顯二次效應的重要接合。
考試寫法：只寫「極限狀態是滑動」會被扣分，一定要把「使用性 vs 強度」兩層分清楚並說明選用時機。 出自 SS-2017-2。

4.3 承壓型：\(F_{nv}\) 與那個 2.4 的來源

螺栓剪斷 \(F_{nv}\)

規範直接給表（考試常用值：A325 \(F_{nv}=330\) MPa（N，螺紋在剪力面）／414 MPa（X，螺紋不在剪力面）； A490 為 414／517 MPa）。但這些數字是可以「還原」的：

\(F_{ub}\)（A325）≈ 830 MPa $$\underbrace{0.6}_{\text{von Mises 剪}} \times 830 \times \underbrace{0.8}_{\text{長接合力量不均勻的折減}} \approx 400\ \text{MPa} \;\approx\; F_{nv}(\text{X}) = 414$$ $$414 \times \underbrace{0.8}_{\text{螺紋處有效面積} \approx 0.75\!\sim\!0.8A_b} \approx 331\ \text{MPa} \;\approx\; F_{nv}(\text{N}) = 330$$ 所以 N／X 的差別 ≈ 0.8 倍，本質是「剪力面上到底是光桿還是螺紋」。記住 0.8 就不會把兩個值記反。

孔壁承壓 \(2.4F_u d t\) 與 \(1.2F_u L_c t\)

2.4 不是實驗湊出來的數字，它就是 1.2 的兩倍。 承壓的真實破壞是螺栓前方的板材被「犁」出去（撕裂），抗力與淨邊距 \(L_c\) 成正比： $$R_n = 1.2\,F_u L_c t$$ 但 \(L_c\) 很大時，破壞模式改成孔壁被壓陷（孔變形），規範以孔變形 6 mm（1/4 in）為使用性上限封頂。 這個上限剛好對應 \(L_c = 2d\)： $$1.2F_u (2d) t = \boxed{2.4F_u d t}$$ 所以 2.4 的物理意義是「淨邊距達到 2d 之後，再加邊距也沒有用了」。 反過來，題目若給的邊距很小（\(L_c < 2d\)），就必須用 \(1.2F_u L_c t\)，不能直接套 2.4。

4.4 手算範例 B：同一個接合，兩個世界差多少

題目設定：M22 A325 螺栓，雙剪（\(n_s = 2\)），接合板 \(t = 10\) mm，母材 \(F_u = 400\) MPa。 A 級接觸面（\(\mu = 0.35\)，\(D_u = 1.13\)，\(h_{sc} = 1.0\)，\(T_b = 176\) kN）。求每顆螺栓的設計強度。 $$A_b = \frac{\pi}{4}(22)^2 = 380.1\ \text{mm}^2$$

(a) 摩阻型（使用性極限，\(\phi = 1.0\)）

$$\phi R_n = 1.0\times 0.35\times 1.13\times 1.0\times 176\times 2 = \underline{139.2\ \text{kN}}$$

(b) 承壓型 — 螺栓剪斷（\(\phi = 0.75\)）

$$\text{N（螺紋在剪力面）：}\ 0.75\times 330\times 380.1\times 2 /1000 = \underline{188.2\ \text{kN}}$$ $$\text{X（螺紋不在剪力面）：}\ 0.75\times 414\times 380.1\times 2 /1000 = \underline{236.1\ \text{kN}}$$

(c) 孔壁承壓（母材，假設 \(L_c \geq 2d\)）

$$\phi R_n = 0.75\times 2.4\times 400\times 22\times 10 /1000 = \underline{158.4\ \text{kN}}$$

結論

設計方式控制項設計強度相對摩阻型
摩阻型滑動139.2 kN1.00
承壓型 A325-N孔壁承壓（158.4 < 188.2）158.4 kN1.14
承壓型 A325-X孔壁承壓（158.4 < 236.1）158.4 kN1.14
這個範例真正要你看見的三件事：
  1. 摩阻型的設計強度明顯低（約承壓型的 60～75%，本例因承壓控制而縮小到 88%）。 「不准滑動」是一種要花錢買的性能，不是免費的保險。
  2. 薄板時承壓常控制，不是螺栓剪斷。本例 \(t=10\) mm 就已經讓承壓（158.4）壓過螺栓 X 的剪斷（236.1）。 只算螺栓剪力就交卷，是本單元最常見的漏項。
  3. 自我檢查：\(F_{nv}\) 的 X／N 比值應該 \(=414/330=1.25\)； 螺栓剪斷（X）／滑動的比值一般落在 1.3～1.8（本例 236.1/139.2 = 1.70）。 若你算出摩阻型比承壓型還強，一定是把 \(\phi\) 或 \(n_s\) 用錯了。

§5　銲接：0.707 從哪裡來、方向為什麼被忽略

填角銲的公式只有一條，而它的每一個數字都能在一張三角形的圖上指出來。 把這張圖畫對，本單元 10 題銲道計算題就有共同的起點。

5.1 0.707：一個純幾何的數字

圖 5-1　填角銲的全部秘密都在這個三角形裡。\(w\) 是看得見、量得到的銲腳； \(t_e = 0.707w\) 是真正承力的最小斷面。兩者差了 29%，混用是本單元最常見的計算錯誤。
$$\boxed{\ \phi R_n = \underbrace{0.75}_{\phi} \times \underbrace{0.6F_{EXX}}_{\text{剪切}} \times \underbrace{0.707w}_{t_e} \times L_w\ }$$

E70XX（\(F_{EXX} = 70\) ksi \(= 4.92\) tf/cm² \(= 490\) MPa）代進去，得到一個很好用的速算式：

$$\phi R_n = 0.75\times 0.6\times 4.92\times 0.707\,w\,L = \boxed{1.565\,w\,L}\quad[\text{tf}],\ w,L\ \text{以 cm 代入}$$

ASD 版本：容許應力 \(f_w = 0.3F_{EXX} = 1.476\) tf/cm²，所以

$$R_a = 1.476\times 0.707\,w\,L = \boxed{1.043\,w\,L}\quad[\text{tf}]$$

5.2 方向性：規範故意忽略的那一半強度

實際上，垂直於銲道方向受力的填角銲比平行受力強約 50% （受力方向與銲道軸線的夾角 \(\theta\) 越大，喉部的應力狀態越接近「拉＋剪」而非「純剪」，抗力上升）。 AISC 允許用方向性公式 \(R_n = 0.6F_{EXX}(1.0+0.5\sin^{1.5}\theta)A_w\) 取回這部分紅利。

但規範的預設值把 \(\theta\) 當 0（純剪），也就是統一用最保守的那一刀。 理由很實務：一條銲道上各點的受力方向常常不同（想想偏心銲縫，§6）， 若逐點取不同強度，設計會變得極其麻煩，而多出來的那點強度不值得這個複雜度。

考試策略：一律用 \(0.6F_{EXX}\times 0.707w\)，除非題目明講「可考慮方向性」。 但答題時加一句「本計算未計入方向性紅利，屬保守」會加分。

5.3 填角銲 vs 開槽銲：誰控制強度

5.5 手算範例 C：反算銲腳，並用 LRFD／ASD 互相驗算

題目設定：一塊接合板以兩側縱向填角銲接於柱翼板，每側有效銲長 \(L = 25\) cm，E70XX。 需傳遞的力：LRFD \(P_u = 60\) tf（對應的服務載重約 \(P_a = 60/1.5 = 40\) tf）。 板厚 \(t = 12\) mm。求所需銲腳 \(w\)。

(a) LRFD

$$\phi R_n = 1.565\,w \times (2\times 25) = 78.3\,w \ \geq\ 60 \quad\Rightarrow\quad w \geq 0.767\ \text{cm} = 7.7\ \text{mm}$$

(b) ASD

$$R_a = 1.043\,w \times (2\times 25) = 52.2\,w \ \geq\ 40 \quad\Rightarrow\quad w \geq 0.767\ \text{cm} = 7.7\ \text{mm}$$

(c) 構造檢查

$$t = 12\ \text{mm} \Rightarrow w_{min} = 5\ \text{mm},\quad w_{max} = 12-2 = 10\ \text{mm}$$ $$L = 250\ \text{mm} \geq 4w = 32\ \text{mm}\ \checkmark$$ $$\Rightarrow \boxed{w = 8\ \text{mm}}\quad (5 \leq 8 \leq 10\ \checkmark)$$
(a) 與 (b) 算出完全相同的 7.7 mm，這不是巧合。 $$\frac{\text{LRFD 銲道係數}}{\text{ASD 銲道係數}} = \frac{0.75\times 0.6}{0.30} = \frac{0.45}{0.30} = 1.50 \quad\text{恰等於}\quad \frac{P_u}{P_a} = 1.50$$ 這是 §2.3 那個檢查的實戰版：兩套方法在同樣假設下必須給出同樣答案。 考試若同一題要求 LRFD 與 ASD 各算一次（本單元很愛這樣考）， 算完把兩個答案的比值算出來 —— 比值應落在 1.4～1.6。落在別處，回去找漏掉的係數。

最後一步不要忘：強度算出 7.7 mm，實務與規範都要取整到可施工的尺寸， 並同時滿足 \(w_{min}\)、\(w_{max}\)。只寫「\(w = 7.7\) mm」不算完成答案。
§5 因果鏈：填角銲斷面是等腰直角三角形 → 最短斷面在 45°（\(t_e = 0.707w\））→ 喉部受純剪 → 乘 0.6（von Mises）→ 現場品質變異大 → \(\phi = 0.75\) → 得 \(1.565wL\)（LRFD）／\(1.043wL\)（ASD），兩者比值恆為 1.5 → 強度算完再用 \(w_{min}\)、\(w_{max}\)、\(L\geq 4w\) 三道構造規定收尾。

§6　偏心接合：彈性向量法

本單元最會扣分的題型（5 題）。它不難，但有三個陷阱幾乎人人踩： 形心位置算錯、\(I_p\) 單位搞混、臨界點抓錯。

6.1 一個假設撐起整個方法

外力 \(P\) 不通過緊結物群的形心 → 對形心產生扭矩 \(M = P\cdot e\)。彈性向量法只做一個假設：

假設：緊結物群被夾在兩塊「剛性」板之間，只能繞形心整體旋轉。
從這個假設，其他全部是推論：
  • 剛體旋轉 → 各點的位移 \(\delta_i \propto r_i\)（離轉心越遠位移越大）
  • 彈性 → 力與位移成正比 → \(R_i \propto r_i\)
  • 旋轉 → 位移方向垂直於半徑向量 → 力的方向也垂直於 \(r_i\)
  • 力矩平衡：\(M = \sum R_i r_i = \dfrac{R_{max}}{r_{max}}\sum r_i^2\) → \(\displaystyle R_i = \frac{M r_i}{I_p}\)，其中 \(I_p = \sum r_i^2\)
所以 \(I_p\) 不是「查來的」，它是力矩平衡的必然產物 —— 完全類比於梁的 \(\sigma = My/I\)。 把「扭矩 ÷ 極慣性矩 × 半徑」記成「彎矩 ÷ 慣性矩 × 距離」的孿生兄弟，就不會忘。

直接剪力則平均分配（同一個剛體假設下，平移位移人人相同）：

$$\vec{R}_i = \underbrace{\vec{R}_V}_{P/n\ \text{或}\ P/\Sigma L} + \underbrace{\vec{R}_M}_{M r_i / I_p} \qquad R_i = \sqrt{R_x^2 + R_y^2}$$

6.3 手算範例 D：L 形銲道，並證明「最遠點不是臨界點」

題目設定：L 形填角銲（垂直段 \(d = 30\) cm 在 \(x=0\)；水平段 \(b = 20\) cm 在 \(y=0\)）， 銲腳 \(w = 10\) mm（E70XX）。垂直向下集中力 \(P\) 作用在 \(x = 35\) cm 處。求 \(P_u\)。

Step 1：形心

$$\sum L = 30+20 = 50\ \text{cm}$$ $$\bar x = \frac{30(0) + 20(10)}{50} = 4.0\ \text{cm},\qquad \bar y = \frac{30(15) + 20(0)}{50} = 9.0\ \text{cm}$$ （用速算式驗證：\(\bar x = b^2/[2(b+d)] = 400/100 = 4.0\ \checkmark\)，\(\bar y = d^2/[2(b+d)] = 900/100 = 9.0\ \checkmark\)）

Step 2：極慣性矩 \(I_p\)（線圖，cm³）

垂直段（\(x_c=0,\ y_c=15\)）： $$I_x = \frac{30^3}{12} + 30(15-9)^2 = 2250 + 1080 = 3330,\qquad I_y = 30(0-4)^2 = 480$$ 水平段（\(x_c=10,\ y_c=0\)）： $$I_x = 20(0-9)^2 = 1620,\qquad I_y = \frac{20^3}{12} + 20(10-4)^2 = 666.7 + 720 = 1386.7$$ $$I_p = (3330+480) + (1620+1386.7) = 3810 + 3006.7 = \underline{6816.7\ \text{cm}^3}$$

Step 3：偏心距與扭矩

$$e = 35 - \bar x = 31\ \text{cm},\qquad M = 31P\ (\text{順時針})$$ $$f_V = \frac{P}{\sum L} = \frac{P}{50} = 0.0200P\ \ (\text{向下，tf/cm})$$

Step 4：比較兩個候選點

Step 5：由臨界點求 \(P_u\)

$$t_e = 0.707\times 1.0 = 0.707\ \text{cm}$$ $$\phi\,0.6F_{EXX}\,t_e = 0.75\times 0.6\times 4.92\times 0.707 = 1.565\ \text{tf/cm}$$ $$0.1014\,P \leq 1.565 \quad\Rightarrow\quad \boxed{P_u = 15.4\ \text{tf}}$$

怎麼在三十秒內找到臨界點（不必逐點硬算）
  1. 畫出直接剪力方向（\(P\) 的方向，本例向下）。
  2. 判斷扭矩轉向：\(P\) 在形心的哪一側？本例在右側、力向下 → 順時針。
  3. 在圖上手畫幾個角點的扭矩分力（垂直於該點的半徑、順著轉向）。
  4. 找扭矩分力與直接剪力夾角最小的那個點 —— 通常是「扭矩轉向把它往下推」的那一側最外角。
  5. 只算那個點，另外再驗一個次候選點證明它較小。答題時寫出這個判斷過程，即使算錯數字也拿判斷分。
陷阱總結（本節三個必踩）
  • 形心不在幾何中心。L 形、U 形、C 形銲道的形心都要算。忘記算 → 偏心距 \(e\) 錯 → 後面全錯。 本例若誤以為形心在銲道左端（\(\bar x = 0\)），\(e\) 會變成 35（多了 13%），答案直接偏低。
  • \(e\) 是「\(P\) 到形心」的距離，不是「\(P\) 到柱面」、也不是「\(P\) 到托架板邊」。
  • \(I_p\) 要含全部銲段／全部螺栓，包含那些「看起來離形心很近所以應該沒差」的段。
§6 因果鏈：偏心 → 扭矩 \(M = Pe\) → 剛體繞形心旋轉 → 各點力 \(\propto r\) 且 \(\perp r\) → 力矩平衡給出 \(R = Mr/I_p\) → 疊加平均分配的直接剪力 → 向量相加（不是純量相加）→ 臨界點是「兩個分力最同向」的點 → 與該點的緊結物強度比較。

§7　梁柱接頭：彎矩怎麼分、節點域、耐震細部

梁柱接頭是本單元的第二主戰場（6 題）且與 SD-U3-1 耐震設計共用的區域。 它的核心問題只有一個：梁端的彎矩，是靠什麼形狀傳到柱裡去的？

7.1 彎矩分成兩份：翼板的「力偶」與腹板的「彎曲」

H 型梁的斷面模數，絕大部分由翼板貢獻（翼板離中性軸最遠）。所以梁端彎矩到了接頭處會自然分成兩份：

$$M = \underbrace{M_f}_{\text{翼板}} + \underbrace{M_w}_{\text{腹板}},\qquad \frac{M_f}{M} \approx \frac{S_f}{S_x},\quad \frac{M_w}{M}\approx \frac{S_w}{S_x}$$
為什麼要分？因為兩者的傳力形狀完全不同。
  • 翼板：離中性軸遠、應力接近 \(F_y\) 且幾乎均勻 → 相當於一對力偶 \(T = C = M_f/d\)。 所以翼板用CJP 全滲透銲（要傳全強度的軸力）。
  • 腹板：應力沿高度線性變化（三角形分佈），中間為零 → 腹板銲道受的是彎曲， 同時還要承擔全部的剪力 \(V\)。所以腹板銲道必須驗組合應力。
典型比例：H500 級的梁，\(M_f\) 約佔 80～85%、\(M_w\) 約佔 15～20% （SS-2018-3 給的 124.5 : 25.5 = 83% : 17%，正好落在這個範圍）。 這個比例可以當自我檢查：若題目要你自己分配，算出翼板只佔 50% 就一定錯了。
圖 7-1　梁端彎矩的兩條路。翼板走「力偶 → CJP」，腹板走「彎曲＋剪力 → 填角銲組合應力」。 考題若只讓你驗腹板銲道，通常會直接把 \(M_f\)、\(M_w\) 分好給你（如 SS-2018-3）。

7.2 手算範例 E：腹板填角銲的組合應力（ASD）

題目設定：H 型梁腹板以雙面 8 mm 填角銲接於箱型柱，有效銲長 \(L_w = 38\) cm。 腹板負擔 \(M_w = 3.0\) tf·m \(= 300\) tf·cm，設計剪力 \(V = 12\) tf。E70XX，ASD。

Step 1：銲喉幾何與斷面模數

$$t_e = 0.707\times 0.8 = 0.566\ \text{cm}$$ $$S_w = 2\times \frac{t_e L_w^2}{6} = 2\times\frac{0.566\times 38^2}{6} = 272.2\ \text{cm}^3 \quad(\text{雙面} \to \times 2)$$

Step 2：兩個應力分量

$$\sigma_{M} = \frac{M_w}{S_w} = \frac{300}{272.2} = 1.102\ \text{tf/cm}^2\quad(\text{銲道上下端最大})$$ $$\tau_{V} = \frac{V}{2\,t_e L_w} = \frac{12}{2\times 0.566\times 38} = 0.279\ \text{tf/cm}^2\quad(\text{均勻})$$

Step 3：向量合成並與容許應力比較

$$f_{res} = \sqrt{1.102^2 + 0.279^2} = 1.137\ \text{tf/cm}^2$$ $$f_a = 0.3F_{EXX} = 0.3\times 4.92 = 1.476\ \text{tf/cm}^2$$ $$\frac{1.137}{1.476} = 0.77 < 1.0 \quad\Rightarrow\quad \boxed{\text{8 mm 雙面填角銲 OK}}$$
三個自我檢查
  • 誰主宰？彎矩項（1.102）遠大於剪力項（0.279），合成值只比彎矩項大 3%。 這是梁柱接頭的常態 —— 若你算出剪力項主宰，先回去檢查 \(S_w\) 有沒有漏乘 2 或把 \(L_w^2\) 寫成 \(L_w\)。
  • \(\sqrt{a^2+b^2}\) 的合理性：當 \(b \ll a\) 時合力應該只略大於 \(a\)。 若你合成後得到 1.38（＝直接相加），就是把向量當純量加了。
  • 不足時怎麼補：\(f_{res}\propto 1/t_e \propto 1/w\)（因 \(S_w\)、剪力面積都與 \(t_e\) 成正比）。 所以需求銲腳 \(w_{req} = w \times \dfrac{f_{res}}{f_a}\) —— 一次就算出來，不必反覆試。 本例若 \(f_{res} = 1.9 > 1.476\)，則 \(w_{req} = 8\times 1.9/1.476 = 10.3 \to 11\) mm。

7.3 節點域：柱腹板被兩邊的梁「剪」

力偶傳進柱裡之後不會消失。左右兩根梁的翼板力在柱腹板上形成一組剪力， 被剪的那塊矩形（梁上下翼板之間、柱翼板之間）就是節點域（Panel Zone）。

圖 7-2　節點域被兩側梁翼板的力偶剪成平行四邊形（紅虛線）。 \(V_{pz}\) 要扣掉柱剪力 \(V_c\)（它與翼板力方向相反，幫忙抵抗一部分）—— 忘記扣就過度保守。 連續板（綠）的作用不是抗剪，是把梁翼板的集中力順利接續到柱的另一側，避免柱翼板局部彎曲、柱腹板局部降伏。
節點域「太弱」與「太強」都不好。 太弱 → 節點域先大量剪切降伏，梁端塑鉸發展不出來、柱翼板被扭出「狗骨頭」變形，銲道根部承受極大應變而脆斷。 太強 → 全部塑性變形都被逼到梁端一個很小的區域，該處應變需求過高。 規範因此對節點域強度給的是一個區間而非單邊下限 —— 這是耐震設計裡少見的「不要太強」條款，很值得在概念題引用。

耐震接頭細部檢查清單（概念題直接照抄）
  1. 梁翼板 CJP 全滲透銲，銲材需具規定衝擊韌性（如 27 J @ −20 °C）
  2. 移除背墊板／回銲根部：下翼板的背墊板本身就是人造裂縫，是 Northridge 的主因之一
  3. 銲趾切角（weld access hole）幾何：太尖銳會造成應力集中
  4. 連續板：柱翼板／腹板承受不了梁翼集中力時必設
  5. 節點域剪力：不可太弱，也不宜過強（§7.3）
  6. 強柱弱梁：\(\sum M^*_{pc} / \sum M^*_{pb} > 1.0\)
  7. 塑鉸區側撐：塑鉸兩側需設側向支撐，避免 LTB 搶先發生（與 U1-2 相扣，SS-2012-2）
  8. UT 全數探傷：CJP 銲道 100% 超音波檢測

  • 層狀撕裂（Lamellar Tearing）：鋼板在軋延方向的夾雜物呈層狀分佈，厚度方向（Z 向）韌性最差。 梁翼板 CJP 把拉力直接施加在柱翼板的厚度方向 → 沿夾雜層剝離。 對策：改善接頭幾何讓拉力不作用於 Z 向、使用 Z 向性能保證鋼板、降低銲接束制。
  • 電熱熔渣銲（ESW）的熱輸入問題：ESW 一次成型效率極高，但熱輸入極大 → HAZ 晶粒粗化、韌性大幅下降。用於箱型柱內隔板時必須嚴格管控熱輸入並做衝擊試驗。
§7 因果鏈：梁端彎矩按斷面模數分成翼板（力偶 → CJP）與腹板（彎曲＋剪力 → 填角銲組合應力）→ 力偶進到柱裡變成節點域剪力 \(V_{pz}\) → 需要連續板把集中力接續、必要時加補強板 → 地震下要求 \(\theta_p \geq 0.04\) rad → 塑鉸不能長在銲道上 → 補強式（做強接頭）或削弱式（RBS，做弱梁）→ 再加上厚板的層狀撕裂與 HAZ 韌性管控。

§8　剪力流與斷續銲：銲道要「多密」而不是「多大」

當接合的任務是「讓兩個構件像一個構件一樣作用」（組合梁加蓋板、組合斷面）， 設計量就不是強度而是單位長度的剪力流。

把蓋板銲在梁翼板上，蓋板要跟著梁一起彎，就必須有水平剪力把它「拖著走」。 這個每單位長度的水平剪力就是剪力流：

$$q = \frac{VQ}{I}\quad[\text{tf/cm}],\qquad Q = A_{\text{被連接部分}}\times \bar y_{\text{該部分形心到全斷面中性軸}}$$
為什麼是 \(Q\)（一次矩）而不是面積？ 因為剪力流來自「彎矩沿長度變化」造成的正應力差。被連接的那塊面積上， 正應力的合力 \(= \int \sigma\,dA = \dfrac{M}{I}\int y\,dA = \dfrac{MQ}{I}\)。 把它對 \(x\) 微分：\(\dfrac{d}{dx}\left(\dfrac{MQ}{I}\right) = \dfrac{VQ}{I} = q\)。
所以 \(Q\) 出現的原因是「該部分離中性軸有多遠、有多大」—— 離中性軸越遠的附加板，需要的銲道越密，這件事是可以直覺理解的。

手算範例 F：斷續銲的間距（結果由構造規定控制）

題目設定：PL 200×12 蓋板銲於 H 梁上翼板（兩側縱向填角銲）， 全斷面 \(I = 200{,}000\) cm⁴，蓋板形心到中性軸 \(\bar y = 26\) cm，設計剪力 \(V = 40\) tf， 擬用 \(w = 6\) mm 斷續銲、每段長 6 cm。求最大間距 \(s\)。 $$Q = (20\times 1.2)\times 26 = 624\ \text{cm}^3 \qquad q = \frac{40\times 624}{200{,}000} = 0.1248\ \text{tf/cm}$$

兩側銲道分擔 → 每側 \(q_1 = 0.0624\) tf/cm。

$$\text{每側銲道容量：}\ 1.565\times 0.6 = 0.939\ \text{tf/cm} \qquad \frac{q_1}{\text{容量}} = \frac{0.0624}{0.939} = 0.066$$

即銲道只需「有 6.6% 的長度」就夠。若每段銲 6 cm：

$$s_{\text{強度}} = \frac{6}{0.066} = 90\ \text{cm}\ (!!)$$

但構造規定封頂：斷續銲的最大間距不得超過 \(24t\)（受壓）或 \(300\) mm：

$$s \leq 24\times 1.2 = 28.8\ \text{cm} \quad\Rightarrow\quad \boxed{s = 28\ \text{cm}\ \text{（構造規定控制）}}$$
這個範例的重點不是算術，是結論的性質。 組合斷面的剪力流通常小到不可思議（本例只需要 6.6% 的銲道長度）， 所以斷續銲的間距幾乎總是由構造規定控制，不是由強度控制。 考試若你算出 90 cm 就寫上去，會被扣掉構造規定那一段的分數。

為什麼要限制間距？三個理由： ① 兩板之間縫隙太長會滲水鏽蝕（腐蝕）； ② 受壓時未連接段的板件會像獨立柱一樣局部挫屈（間距即為該段的無支撐長度）； ③ 蓋板端部的剪力流反而最大（\(V\) 最大處），端部通常需要連續銲。
陷阱：\(Q\) 用錯部位。\(Q\) 是被這條銲道連接過去的那部分的一次矩 —— 蓋板銲道就用蓋板的 \(A\bar y\)，不是全斷面、也不是半個斷面。 另一個常錯：\(I\) 必須用含蓋板的全斷面慣性矩（加了蓋板後 \(I\) 變大，\(q\) 反而變小）。

§10　八條因果鏈與解題決策流程

10.1 把整個單元濃縮成八句話（能用嘴巴講出來才算懂）

  1. 換手鏈：力量必須換手 → 每次換手產生一個破壞面 → 每個面一條公式 → 取最小值 → 再壓「不得低於構材強度」的下限。
  2. 兩把尺：von Mises → 純剪只需 \(F/\sqrt3\) → 剪的項乘 0.6 → 降伏配 \(F_yA_g\)、斷裂配 \(F_uA_n\) → 斷裂無預警 → \(\phi\) 從 0.90 降到 0.75。
  3. 剪力遲滯：只連部分斷面 → 力要橫向剪過去 → 需要距離 → 外伸肢應力落後 → \(U = 1-\bar x/L\) → \(A_e = UA_n\)。
  4. 塊狀剪力：畫出破壞塊 → 兩側是剪力面（乘 0.6）、後方是拉力面（不乘）→ 剪力面可能斷裂也可能只降伏 → 兩式取小。
  5. 螺栓兩個世界：預緊 → 夾緊力 → 摩擦（滑動前螺栓不受剪）→ 滑動非崩塌 → \(\phi = 1.0/0.85\) → 一旦滑動切換成承壓型（\(F_{nv}A_bn_s\) 與 \(2.4F_udt\)）。
  6. 填角銲：等腰直角三角形 → 最短斷面在 45°（\(0.707w\)）→ 喉部純剪（×0.6）→ 品質變異（\(\phi=0.75\)）→ \(1.565wL\)；ASD 為 \(1.043wL\)，比值恆 1.5。
  7. 偏心接合：偏心 → 扭矩 \(Pe\) → 剛體繞形心轉 → 力 \(\propto r\) 且 \(\perp r\) → \(R = Mr/I_p\) → 向量疊加直接剪力 → 臨界點是「兩分力最同向」處。
  8. 梁柱接頭：彎矩按斷面模數分成翼板力偶（CJP）與腹板彎曲（填角銲組合應力）→ 力偶進柱變節點域剪力 → 需連續板 → 耐震要 \(\theta_p\ge0.04\) → 塑鉸不能長在銲道上 → 補強式或 RBS。

看完講義後，用這 12 題檢查你是不是真的懂了。答不出來的，回到括號裡的章節。 能用自己的話講出「為什麼」，才是真的懂。
Q1　為什麼所有「剪」的強度公式都有一個 0.6，而「拉」的沒有？（§2.1）

因為 von Mises 準則：純剪狀態下達到相同畸變能只需 \(\tau = F/\sqrt3 = 0.577F\)，規範取整為 \(0.6F\)。 拉力面本來就是被拉開的，直接用單軸強度，不需要折。

Q2　為什麼降伏配毛面積、斷裂配淨面積？不能反過來嗎？（§2.2）

降伏是整段構材的行為（伸長量以公分計），孔那幾公分的影響可忽略，所以用 \(A_g\)。 斷裂只發生在一個最弱斷面，孔削掉多少就是少多少，所以用 \(A_n\)。 反過來配的話，物理上等於「假設整根構材都在斷裂」或「只有一個斷面在降伏」，兩者都不成立。

Q3　為什麼接合的 \(\phi\) 幾乎都是 0.75，而構材彎矩是 0.90？（§2.2）

因為 \(\phi\) 量化的是「破壞有沒有預警」。彎矩降伏變形明顯、可觀察； 螺栓剪斷、銲道破壞、淨斷面斷裂都是脆性、無預警，而且 \(F_u\) 的離散性比 \(F_y\) 大、現場品質變異更大。 這也順帶回答了「為什麼接合強度必須高於構材」——不要把破壞逼到沒有預警的那一端。

Q4　\(U = 1-\bar x/L\) 的兩個參數各代表什麼物理量？（§3.2）

\(\bar x\)＝偏心程度（形心離施力面多遠，力要繞多遠的路）；\(L\)＝可用的傳遞長度（剪力有多少距離把力送到外伸肢）。 兩者相除得到無因次的遲滯程度。極限檢查：\(\bar x = 0 \Rightarrow U=1\)；\(L\to\infty \Rightarrow U\to1\)。

Q5　塊狀剪力的兩條式子為什麼取 min 而不是相加？（§3.3）

因為它們描述的是同一個破壞的兩種可能路徑（剪力面斷裂＋拉力面斷裂／剪力面降伏＋拉力面斷裂）， 不是兩個獨立的抗力來源。實際破壞沿先發生的那條路走 → 取小值。相加＝把同一塊材料算兩次。

Q6　摩阻型接合的 \(\phi\) 為什麼可以等於 1.0？（§4.2）

因為滑動不是崩塌。滑動幾毫米後接合變成承壓型，還有第二層防線。 既然後果不是失去承載力，就不需要脆性破壞那種保守度。若滑動本身即不可接受（過大孔、重要接合）， 則歸為強度極限狀態，取 \(\phi = 0.85\)。

Q7　承壓強度公式裡的 2.4 是怎麼來的？（§4.3）

它是 1.2 的兩倍。真實抗力與淨邊距成正比：\(R_n = 1.2F_uL_ct\)； 但孔變形 6 mm 的使用性上限把它封頂，該上限剛好對應 \(L_c = 2d\)：\(1.2F_u(2d)t = 2.4F_udt\)。 所以 2.4 的意思是「淨邊距超過 \(2d\) 之後再加也沒用」。邊距小於 \(2d\) 時必須用 \(1.2F_uL_ct\)。

Q8　0.707 是實驗值還是幾何值？（§5.1）

純幾何。填角銲斷面是等腰直角三角形，材料一定沿面積最小的斷面剪開， 而最小的那一刀是 45° 對角線：\(t_e = w\cos45° = w/\sqrt2 = 0.7071w\)。

Q9　為什麼規範預設忽略填角銲的方向性（明明垂直受力強 50%）？（§5.2）

因為一條銲道上各點受力方向常不同（尤其偏心銲縫），逐點取不同強度會讓設計極其麻煩， 多出來的強度不值得這個複雜度。規範採「統一用最保守的純剪」的工程折衷。

Q10　偏心銲縫的 \(I_p\) 為什麼是 cm³ 而不是 cm⁴？（§6.2）

因為用線圖法：銲道被當成寬度＝1 的線，\(I_p = \int r^2 ds\)（長度³）。 喉厚 \(t_e\) 是在最後比較 \(f_{max}\) 與 \(\phi\,0.6F_{EXX}t_e\) 時才乘進去的。 單位本身就是防止重複計算的檢查工具。

Q11　為什麼離形心最遠的點不一定是臨界點？（§6.3）

因為合力是向量相加。扭矩分力的大小 \(\propto r\)，但方向垂直於半徑； 若它與直接剪力反向，兩者會抵消，合力反而變小。臨界點是「兩個分力最同向」的那個點。

Q12　為什麼節點域「太強」也不好？（§7.3）

節點域適度的剪切降伏是耐震設計中預期的消能機制之一。若節點域過強， 全部塑性變形被逼到梁端一個很小的區域，該處的應變需求（與銲道根部的應變）會過高，反而提早脆斷。 所以規範對節點域強度給的是一個區間，而非單邊下限 —— 這是耐震條文中少見的「不要太強」條款。

§14　★ 精選 6 題（時間有限就練這些）

從 26 題中挑出彼此重疊最少、能練到最多獨立技能的 6 題。 選題邏輯不是「覆蓋率最高」，而是「練完之後，其他 20 題你都知道該從哪裡下手」。

練這六題的正確方法

  1. 先讀對應章節，再看題目，不要先看解答。本講義的章節是為了讓你「看到題目就知道該用哪條鏈」而寫的。
  2. 計算題先寫「極限狀態清單」再開始算。清單寫對就先拿到骨架分，即使某項算錯也不會全盤皆輸。
  3. 每題算完做一次自我檢查（§3.4、§4.4、§5.5、§7.2 各示範了一種）： 三個模式是否落在同一數量級？LRFD／ASD 比值是否落在 1.4～1.6？彎矩項是否主宰？
  4. 概念題（③⑥）用嘴巴答一次再寫。如果你講不出因果鏈，寫出來一定也是條列式的散裝知識，拿不到高分。
  5. 做完六題後，回頭掃 §12 陷阱總表。你會發現大部分陷阱你剛剛都親自踩過一次 —— 這時候記住的才會留下來。
