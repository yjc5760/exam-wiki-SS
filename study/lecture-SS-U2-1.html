§0 全景：降伏是一個點的事，崩塌是整個結構的事

彈性設計在最外一根纖維第一次碰到 \(F_y\) 時就喊停；塑性設計問的是另一件事：載重還能再加多少，結構才真的變成一組會動的連桿（機構）？ 這兩個門檻之間隔著兩段儲備——斷面儲備（一個斷面從 \(M_y\) 長到 \(M_p\)）和結構儲備（第一個塑性鉸出現後，彎矩轉給別的斷面去扛）。本單元 10 題全部落在這兩段儲備裡。
SS-2005-4 的同一根梁：①最外纖維降伏、②固定端成鉸、③跨間成第二個鉸。三個門檻由 calcs.py 依題解數值算出，撓度以塑性鉸模型（鉸以外保持彈性）計算。 真實的曲線在 ① 之後就開始緩緩彎下（斷面部分塑性化，見 §1），但三個載重門檻不變。
這張圖攔的錯：把 ①（彈性設計極限）當成崩塌，或以為 ②「第一個塑性鉸出現」就是崩塌——靜不定結構還要再撐 46%。

§1 從 \(M_y\) 到 \(M_p\)：一個斷面怎麼「用完」

\(M_y\) 怕的是「第一根纖維降伏」——斷面並沒有壞，只是從此不再線性。\(M_p\) 是「每一根纖維都已降伏」，斷面再也拿不出更多彎矩。 兩者之間的差距（形狀因子）完全由面積怎麼分佈決定，與材料無關。

1.1 兩個假設就夠了

  1. 平面保持平面：應變沿斷面高度永遠是直線 \(\varepsilon = \varphi\,y\)，不論彈性或塑性。
  2. 理想彈塑性：\(\sigma = E\varepsilon\)，到 \(F_y\) 為止就走平台，不計應變硬化與殘留應力。

所以「塑性化」其實就是：應變那條直線繼續變陡，而應力被 \(F_y\) 從兩端開始截頂。下圖是 SS-2010-1 斷面在三個曲率下的應力分佈（纖維法逐點算出，不是示意）。

SS-2010-1（\(F_y = 4.0\) tf/cm²）：① 頂部凸塊外緣先到 \(F_y\)（它離 ENA 4.5 cm，比底緣 3.5 cm 遠）；② 曲率 3 倍時，頂部一段與底部一段已截頂，中性軸移到 3.60；③ 全斷面降伏，應力只剩兩塊矩形，中性軸落在等面積軸 4.00。
這張圖攔的錯：以為中性軸永遠在形心。中性軸的位置是「合力為零」算出來的，應力形狀一變，它就跟著搬家。
為什麼彈性時是形心、全塑時是等面積軸？同一條方程式。 純彎曲沒有軸力，所以 \(\int \sigma\,dA = 0\)。 彈性時 \(\sigma = E\varphi\,y\) → \(\int y\,dA = 0\) → 中性軸過形心（ENA）。 全塑時 \(\sigma = \pm F_y\) → \(F_y A_c - F_y A_t = 0\) → \(A_c = A_t = A/2\) → 中性軸是等面積軸（PNA）。 上下對稱的斷面兩者重合；不對稱時一定分開——這就是 SS-2010-1、SS-2023-3、SS-2020-2 的考點。

1.2 \(M_p\) 是漸近線，不是一個「點」

① 三種斷面的彎矩–曲率曲線（纖維法），各以自己的 \(M_y\)、\(\varphi_y\) 正規化：越過 \(M_y\) 之後曲線彎下，但只會無限逼近 \(f = M_p/M_y\)，要曲率無限大才真正等於 \(M_p\)。 H 型鋼在 \(\varphi \approx 2\varphi_y\) 時就已到 0.98 \(M_p\)（翼板一降伏就幾乎用完），T 型要慢得多。 ② T 型梁（SS-2005-4）正彎矩下中性軸從 ENA 5.27 cm 一路往翼板走，最後停在 PNA 1.942 cm——落在翼板內（翼板厚 2.6 cm）。
這張圖攔的錯：以為斷面可以「超過」\(M_p\)；以及以為塑性鉸是突然出現的。曲率需求 → ∞ 正是 §3 要把它理想化成「鉸」的理由。

1.3 手算範例 A：SS-2010-1（\(M_y\)、\(M_p\)）

題目：斷面由下而上為 6×2 全寬、2×2 中段、6×2 全寬、2×2 頂部凸塊（cm），SS540，\(F_y = 4.0\) tf/cm²，求強軸 \(M_y\)、\(M_p\)。 SS-2010-1

① ENA：\(A = 12+4+12+4 = 32\) cm²，\(\bar y = (12\times1 + 4\times3 + 12\times5 + 4\times7)/32 = 112/32 = 3.5\) cm（距底）。

② \(I_x\)（平行軸）：\(I_x = \tfrac{32}{3} + 152 = 162.67\) cm⁴。

③ 哪一側先降伏：\(c_{top} = 8 - 3.5 = 4.5 > c_{bot} = 3.5\) → 頂側控制，\(S = 162.67/4.5 = 36.15\) cm³

$$M_y = F_y S_{min} = 4.0 \times 36.15 = 144.6\ \text{tf}\cdot\text{cm}$$

④ PNA：\(A/2 = 16\)；由底累加 12 → 16，恰在第 ②、③ 塊交界，\(y_{PNA} = 4.0\) cm。

⑤ \(Z\)：\(12\times3 + 4\times1 + 12\times1 + 4\times3 = 64\) cm³

$$M_p = F_y Z = 4.0 \times 64 = 256\ \text{tf}\cdot\text{cm},\qquad f = \frac{64}{36.15} = 1.77$$

自我檢查（力偶法）：\(C = T = F_y \cdot A/2 = 64\) tf；上半形心距 PNA \(24/16 = 1.5\) cm、下半 \(40/16 = 2.5\) cm，力臂 4.0 cm → \(64 \times 4.0 = 256\) ✓。兩條路得同一個數字，才算算完。

陷阱：先讀對斷面再算。這題的舊解曾把斷面讀成上下對稱十字形（底部也是 2×2 凸塊），得 \(M_y = 106.7\)、\(M_p = 192\)；2026-11-01 依考卷原圖更正為底部是 6 cm 全寬段。 上下不對稱、ENA ≠ PNA 正是本題考點——讀成對稱，整題就只剩算術。
因果鏈 ①：應變線性 → 應力被 \(F_y\) 截頂 → 中性軸由「合力為零」決定 → 彈性時在形心、全塑時在等面積軸 → \(M_y = F_yS_{min}\)、\(M_p = F_yZ\) → \(f = Z/S\) 只反映面積分佈

§2 \(Z\) 的算法與形狀因子：一個力偶，兩塊面積

\(Z\) 不是新的幾何量，它就是「全塑時那對力偶的力臂 × 半面積」。看懂這句話，所有斷面（T、非對稱 I、圓管、H）都用同一套步驟：先找 PNA 落在哪一塊 → 跨 PNA 的板切開 → 每塊面積乘以離 PNA 的距離再加總。
$$M_p = \underbrace{F_y\,\tfrac{A}{2}}_{C\,=\,T}\times(\bar y_c + \bar y_t) \;\Longrightarrow\; Z = \frac{A}{2}(\bar y_c + \bar y_t) = \sum A_i\,|d_i|$$

其中 \(\bar y_c\)、\(\bar y_t\) 是受壓半與受拉半的形心到 PNA 的距離。注意它和彈性的 \(S = I/c\) 完全無關——\(Z\) 用一次矩，\(S\) 用二次矩。

2.1 半面積法：先問「PNA 在哪一塊」

左：SS-2020-2 非對稱 H（上翼板 30×2.5、腹板 55×1.5、下翼板 20×2.5，依比例）。上翼板只有 75 cm²，不到半面積 103.75，PNA 掉進腹板，腹板必須在 PNA 處切成兩段。 右：SS-2005-4 T 型（翼板 40×2.6、全深 24），翼板 104 cm² 已超過半面積 77.68，PNA 落在翼板內，翼板本身被切成兩段，整根肢都在 PNA 同一側。 紅＝受壓半、綠＝受拉半；表格數字由 calcs.py 算出，與題解差在四捨五入。
這張圖攔的錯：把跨過 PNA 的那塊板當成一整塊、用它的形心算 \(A\cdot d\)（會把兩段的貢獻互相抵掉）；以及在 T 型梁上直覺以為 PNA 在腹板。

2.2 手算範例 B：SS-2020-2 的 \(Z\)

SS-2020-2：\(A = 75 + 82.5 + 50 = 207.5\) cm²，\(A/2 = 103.75\)。

由頂往下累加：上翼板 75 < 103.75 → 還差 28.75 → 進腹板 \(28.75/1.5 = 19.17\) cm → PNA 距頂 21.67 cm（ENA 距頂 26.54 cm，兩者差 4.9 cm）。

$$Z = \underbrace{75(20.42)}_{\text{上翼板}} + \underbrace{28.75(9.58)}_{\text{腹板上段}} + \underbrace{53.75(17.92)}_{\text{腹板下段}} + \underbrace{50(37.08)}_{\text{下翼板}} = 4{,}624\ \text{cm}^3$$ $$M_p = 2.5 \times 4{,}624 = 11{,}560\ \text{tf}\cdot\text{cm}$$

自我檢查：PNA 以下 \(53.75 + 50 = 103.75\) ✓（上下面積相等是 PNA 的定義，順手驗一次就不會錯）。

陷阱：非對稱斷面的 \(M_y\) 要取 \(S_{min}\)，而它常常在「窄」的那一側。 SS-2023-3 頂翼板 50 寬、底翼板 30 寬；形心被寬翼板拉上去（距底 63.75），所以窄的底緣離 ENA 較遠（63.75 > 46.25），\(S_{bot} = 19{,}201\) 較小、底緣先降伏： \(M_y = 2.5 \times 19{,}201 \approx 48{,}002\) tf·cm。直覺「寬的那側承擔多」會選錯 \(S\)。 （SS-2023-3：PNA 距底 80、\(Z = 24{,}750\)、\(M_p = 61{,}875\) tf·cm、\(f = 1.289\)。）

2.3 封閉形式：圓管為什麼可以「外減內」

SS-2013-1：外徑 \(D\)、內徑 \(0.6D\)，以 \(D\) 表示 \(S_x\)、\(Z_x\)、\(f\)。

$$Z_x = \frac{D^3 - d^3}{6} = \frac{(1 - 0.6^3)D^3}{6} = 0.1307\,D^3$$ $$S_x = \frac{I_x}{D/2} = \frac{\pi(D^4 - d^4)}{32\,D} = 0.0855\,D^3,\qquad f = \frac{Z_x}{S_x} = 1.529$$

為什麼 \(Z\) 可以外圓減內圓，\(S\) 卻不行？\(Z\) 是對 PNA 的一次矩，外圓與內圓的 PNA 是同一條軸，一次矩可以直接相減； \(S = I/c\) 的分母 \(c\) 是外圓的 \(D/2\)，所以只能先 \(I_{外} - I_{內}\)、再除以 \(D/2\)——寫成 \(S_{外} - S_{內}\) 會把內圓除以錯的 \(c\)。

極限檢查（忘記公式時自救）：\(d \to 0\) 得實心圓 \(f = 16/(3\pi) = 1.698\)；\(d \to D\)（極薄管）得 \(f \to 4/\pi = 1.273\)。1.529 落在兩者之間 ✓。

2.4 雙對稱 H 型鋼：一條式子

PNA 在腹板中央，上半 = 翼板力 × 力臂 + 半腹板：

$$Z_x = b_f t_f\,(d - t_f) + \frac{t_w (d - 2t_f)^2}{4}$$

SS-2006-3（H600×300×12×20）：\(300\times20\times580 + 12\times560^2/4 = 3{,}480{,}000 + 940{,}800 = 4{,}420{,}800\) mm³，\(M_p = 3.5 \times 4{,}420.8 = 15{,}472.8\) tf·cm。 翼板力臂是 \(d - t_f\)（兩翼板形心間距），不是 \(d\)。

2.5 形狀因子：面積離中性軸越遠，\(f\) 越小

本單元出現過的所有斷面，\(f = Z/S_{min}\) 全由 calcs.py 算出。H 型鋼把面積放在翼板，彈性時翼板已經幾乎全在高應力區，塑性化能多拿的很少（1.12）； 矩形、圓的面積大量堆在中性軸附近，彈性時那裡應力很低，塑性化等於把閒置的材料叫醒（1.5～1.7）。T 型的 \(S_{min}\) 取在肢端，所以 \(f\) 最大。
這張圖攔的錯：把「形狀因子大」當成「斷面效率高」。剛好相反：\(f\) 大代表彈性時材料閒置得多。H 型鋼 \(f\) 小，是因為它的 \(S\) 已經很大。
形狀因子＝「斷面儲備」。它只在斷面層級起作用：固定端從 \(M_y\) 長到 \(M_p\)，載重跟著乘上 \(f\)。§0 那張圖的 × 1.79 就是 SS-2005-4 T 型斷面的 \(f\)。 接下來 §3–§5 談的是另一段儲備——結構層級的彎矩重分配，它與 \(f\) 互相獨立、彼此相乘。
因果鏈 ②：全塑應力只有 ±\(F_y\) → 合力為零 → 上下各半面積 → 一對力偶 \(F_yA/2\) → 力臂 = 兩半形心距 → \(Z = \sum A_i|d_i|\)（跨 PNA 的板切開）→ \(f = Z/S\) 衡量彈性時閒置了多少材料

§3 塑性鉸：一個「有強度」的鉸

§1 說過：斷面要曲率無限大才真正到 \(M_p\)。真實梁裡，這個大曲率只發生在彎矩最大處附近很短的一段；把那一段縮成零長度，就得到塑性鉸—— 轉角可以任意增加，但轉的時候一直傳遞 \(M_p\)。塑性分析的全部便利，都來自這個理想化。
左：一般鉸（支承或接頭）不傳彎矩，轉多少都行，也不耗能。右：塑性鉸（剛塑性理想化）在 \(|M| < M_p\) 時完全不轉，到 \(M_p\) 才開始轉；卸載時轉角留下（永久變形），要反向轉就得把彎矩推到 \(-M_p\)。
這張圖攔的錯：以為「成了鉸」就是 \(M = 0\)。塑性鉸處的彎矩是 \(\pm M_p\)，正因如此它在虛功裡耗能 \(M_p\theta\)；一般鉸處 \(M = 0\)，內功為零。
一般鉸（pin、滾支、簡支端）塑性鉸（plastic hinge）
傳遞彎矩\(M = 0\)\(M = \pm M_p\)
何時出現設計時就決定（構造細節）彎矩到 \(M_p\) 時自動出現
轉動方向任意只能沿 \(M_p\) 的方向轉；反轉需反向 \(M_p\)
會不會消失不會會：彎矩一降就恢復剛性（轉角留下）
虛功內功0\(M_p \times\) 該鉸相對轉角

3.1 鉸會出在哪裡？——彎矩最先到 \(M_p\) 的地方

  • 固定端、連續支承：靜不定結構的負彎矩峰值。
  • 集中載重作用點：彎矩圖的折點就是峰值，位置已知。
  • 均布載重下的最大正彎矩點：位置不知道，要設 \(x\) 再求極值（§4）。
  • 斷面變化處：\(M_p\) 較小的那一側先到（例如翼板截斷處）。
  • 剛架節點：梁端或柱端，取 \(M_p\) 較小者——耐震設計的「強柱弱梁」就是刻意讓鉸出在梁端。

3.2 前提：鉸要轉得動（破壞要有預警）

為什麼塑性設計對寬厚比比較嚴？——用「破壞有沒有預警」想。 塑性分析能多拿 46% 的結構儲備（§5），全靠先出現的鉸邊維持 \(M_p\) 邊轉，等最後一個鉸形成。 如果翼板在轉動途中局部挫屈，或整根梁側扭挫屈，彎矩會掉下來——這是突然、沒有預警的破壞，重分配也就不存在了。 所以規範在「結實」之上再多一級塑性設計斷面，要求更小的寬厚比（\(\lambda \le \lambda_{pd}\)），並限制側撐間距。
國內鋼結構極限設計法（\(F_y\) 以 tf/cm² 計）翼板 \(b_f/2t_f\)腹板 \(h/t_w\)能做什麼
塑性設計斷面 \(\lambda_{pd}\)\(14/\sqrt{F_y}\)\(138/\sqrt{F_y}\)到 \(M_p\) 且有足夠轉動能力 → 可做塑性分析、耐震韌性構材
結實斷面 \(\lambda_p\)\(17/\sqrt{F_y}\)\(170/\sqrt{F_y}\)局部挫屈前可達 \(M_p\)，轉動能力有限

數值出處：SS-2021-3 考卷所附公式（熱軋 I 型梁）；國內規範分「塑性設計／結實／半結實／細長肢」四級，AISC 360 只有三級（塑性設計的要求放在 360 附錄 1 與 AISC 341），見 SS-2014-3 題解 §5。

檢核範例（\(F_y = 2.5\)，\(\lambda_{pd}\) 翼板 \(= 14/\sqrt{2.5} = 8.85\)、腹板 \(= 87.3\)）

  • SS-2005-4 T 型翼板：\(20/2.6 = 7.69 \le 8.85\) ✓（結實斷面的 \(17/\sqrt{F_y} = 10.75\) 當然也通過；做塑性分析時以 \(\lambda_{pd}\) 檢核才嚴謹）。
  • SS-2020-2：上翼板 \(15/2.5 = 6.0\)、下翼板 \(10/2.5 = 4.0\)、腹板 \(55/1.5 = 36.7\)，全部 ✓。

考題通常寫「假設為結實斷面、有充分側撐」，就是在替你把這一步做掉；題目沒寫時，答案最後補一行檢核。

因果鏈 ③：\(M \to M_p\) 需曲率 → ∞ → 大曲率集中在峰值附近一小段 → 理想化成零長度、可轉、傳 \(M_p\) 的鉸 → 鉸要撐到最後一個鉸形成 → 不可局部或側扭挫屈 → \(\lambda \le \lambda_{pd}\)＋側撐

§4 崩塌機構與虛功法：讓結構「動一下」，算它付了多少功

每多一個塑性鉸，結構就少一個贅餘約束。靜不定度 \(n\) 的結構，\(n\) 個鉸讓它變成靜定，第 \(n+1\) 個鉸讓它變成機構。 機構可以自由動一下，於是能用虛功：外力做的功 = 所有塑性鉸消耗的功，一條方程式就解出崩塌載重。

4.1 \(n+1\) 個鉸：規則與例外

結構（只計彎曲）\(n\)完整機構鉸數鉸位
簡支梁01最大彎矩處
一端固定一端簡支（propped cantilever）12固定端＋跨間
兩端固定23兩端＋跨間
例外：局部機構。連續梁或剛架可以只有「某一跨」先動（梁機構），所需鉸數比 \(n+1\) 少。\(n+1\) 是整體（完整）機構的鉸數，不是崩塌的必要條件。 答觀念題（如 SS-2025-4）時寫「完整機構需 \(n+1\) 個塑性鉸，且鉸的位置必須讓結構幾何可動；局部機構可少於此數」，比只寫公式完整。

4.2 虛功的兩邊各算什麼

外功 \(W_{ext}\)
集中力：\(P \times\) 該點虛位移。
均布力：\(w \times\) 虛位移圖的面積（三角形就是 \(\tfrac12\times\)底×高）。
內功 \(W_{int}\)
每個塑性鉸：\(M_p \times\) 該鉸的相對轉角（兩側桿段轉角之和）。
支承的真鉸、滾支：\(M = 0\)，不計。
① 依 SS-2005-4 尺寸畫出的機構（豎向位移放大）：A 轉 \(\theta\)，C 點下沉 \(\delta = x\theta\)，CB 段轉 \(\theta x/(L-x)\)；C 的相對轉角是兩段之和。B 是簡支端，轉了也不耗能。 ② 把 \(w\) 寫成 \(x\) 的函數並取點畫出：每個 \(x\) 都對應一個「機構」、一個 \(w\)；曲線最低點 \(x = (2-\sqrt2)L = 0.5858L\) 才是答案，\(w_u = 11.657\,M_p/L^2\)。 直覺猜跨中（\(x = L/2\)）得 12.000，比真值高 2.9%——高估崩塌載重，偏不安全。
這張圖攔的錯：把均布載重的跨間鉸放在跨中；以及漏算 C 點相對轉角中 CB 段的那一份。

4.3 手算範例 C：SS-2005-4（全流程）

SS-2005-4：T 型梁（翼板 40×2.6、全深 24、肢厚 2.4 cm），左端固定、右端簡支，\(L = 600\) cm，\(F_y = 2.5\)，以塑性設計求 \(w_u\)。

① \(M_p\)（§2.1 右圖）：肢淨高 \(24 - 2.6 = 21.4\)，\(A = 104 + 51.36 = 155.36\)，\(A/2 = 77.68 < 104\) → PNA 在翼板內、距頂 \(77.68/40 = 1.942\) cm；

$$Z = 75.43 + 8.66 + 583.35 = 667.43\ \text{cm}^3,\qquad M_p = 2.5 \times 667.43 = 1{,}668.6\ \text{tf}\cdot\text{cm}$$

② 機構：\(n = 1\) → 2 個鉸：A（\(-M_p\)）與跨間 C（\(+M_p\)，距 A 為 \(x\)）。

③ 虛功：

$$w\,\frac{L\,x\theta}{2} = M_p\theta + M_p\theta\frac{L}{L-x} \;\Longrightarrow\; w(x) = \frac{2M_p\,(2L - x)}{L\,x\,(L - x)}$$

④ 取最小：\(dw/dx = 0 \Rightarrow x^2 - 4Lx + 2L^2 = 0 \Rightarrow x = (2-\sqrt2)L = 351.5\) cm（距固定端）

$$w_u = (6 + 4\sqrt2)\frac{M_p}{L^2} = 11.657 \times \frac{1{,}668.6}{600^2} = 0.0540\ \text{tf/cm} = 5.40\ \text{tf/m}$$

⑤ 自我檢查

  • 夾擠：簡支 \(8M_p/L^2\) < 一端固定 11.657 < 兩端固定 \(16M_p/L^2\) ✓（多一端固定，崩塌載重應該介於兩者之間）。
  • 平衡（下限，§5）：\(R_A = w_uL/2 + M_p/L = 18.99\) tf，\(M(351.5) = 18.99\times351.5 - 0.0540\times351.5^2/2 - 1{,}668.6 = M_p\) ✓，且全跨沒有一處超過 \(M_p\)。
陷阱：尺寸線量的是全深還是腹板高。本題舊解把「24 cm」當腹板高、全深取 26.6 cm，得 \(w_u = 6.58\) tf/m（高估 22%）； 2026-11-01 依考卷原圖更正為全深 24 cm、\(w_u = 5.40\) tf/m。看尺寸線兩條界線各對齊哪一條邊，再動筆。

4.4 同一個機構，換一端量：SS-2020-2

SS-2020-2：A 端滾支、B 端固定，\(L = 800\) cm，\(M_p = 11{,}560\) tf·cm（§2.2）。題解把 \(x\) 量自滾支端 A：

$$w = \frac{2M_p}{L}\left(\frac1x + \frac{2}{L-x}\right),\quad \frac{dw}{dx}=0 \Rightarrow x = (\sqrt2 - 1)L = 331.4\ \text{cm}$$ $$w_u = 2(1+\sqrt2)^2\frac{M_p}{L^2} = 11.657 \times \frac{11{,}560}{800^2} = 0.2106\ \text{tf/cm} = 21.06\ \text{tf/m}$$

\((\sqrt2-1)L\) 距滾支端，就是 \((2-\sqrt2)L\) 距固定端——同一個點；\(2(1+\sqrt2)^2 = 6 + 4\sqrt2\)，同一個常數。 記「0.586」不如記「離固定端較遠、離簡支端較近」：固定端那一側有 \(M_p\) 在幫忙扛，所以鉸被推向簡支端。

4.5 集中載重：鉸位已知，不必求極值

SS-2025-4 的觀念例：一端固定一端簡支、跨中集中力 \(P\)。鉸在 A 與跨中，A 轉 \(\theta\)、跨中相對轉角 \(2\theta\)：

$$P\cdot\frac{L}{2}\theta = M_p\theta + M_p(2\theta) \;\Longrightarrow\; P_u = \frac{6M_p}{L}$$
因果鏈 ④：每個鉸拿掉一個贅餘 → \(n+1\) 個鉸成完整機構 → 機構可動 → 給虛位移 → 外功（\(w\)×位移圖面積）＝內功（Σ\(M_p\)×相對轉角）→ 鉸位未知就對 \(x\) 求最小

§5 上下限定理與彎矩重分配：答案為什麼可信

機構法給的是上限：猜錯機構，算出來的崩塌載重一定偏高（不安全）。平衡法給的是下限：任何滿足平衡、且全處 \(|M| \le M_p\) 的彎矩圖，對應的載重一定不超過真值。 兩邊夾到同一個數字，就是精確解——這也是虛功算完之後一定要畫一次彎矩圖的理由。
上限（機構法、運動學定理）
假設一個機構 → 虛功 → \(w_{機構} \ge w_u\)。
猜錯的機構忽略了「別處其實已超過 \(M_p\)」，所以高估。
→ 對所有候選機構與位置取最小。
下限（平衡法、靜力定理）
找一個平衡的彎矩圖，處處 \(|M| \le M_p\) → \(w_{平衡} \le w_u\)。
→ 機構法的答案代回去畫彎矩圖，沒有一處超過 \(M_p\)，上下限重合，答案確定。
SS-2005-4 兩個時刻的彎矩圖（以 \(M_p\) 正規化，取點計算）。橘：第一個鉸剛出現（\(w_1 = 8M_p/L^2\)），固定端已達 \(-M_p\)，跨間最大只有 \(0.5625M_p\)——跨間的材料還閒著。 紫：崩塌（\(w_u = 11.657M_p/L^2\)），固定端被鎖在 \(-M_p\) 不再增加，多出來的載重全由跨間扛到 \(+M_p\)；全跨無一處超過 \(M_p\)，所以這也是下限解。
這張圖攔的錯：以為「第一個鉸」就是崩塌；以及虛功算完不驗彎矩圖——若彎矩圖某處超過 \(M_p\)，代表機構選錯，要換。

5.1 結構儲備有多大？看彈性彎矩圖有多不均

結構第一個鉸崩塌結構儲備 \(w_u/w_1\)
簡支梁 均布\(8M_p/L^2\)\(8M_p/L^2\)1.00（靜定，沒有東西可以重分配）
一端固定一端簡支 跨中集中\(5.333M_p/L\)\(6M_p/L\)1.13
兩端固定 均布\(12M_p/L^2\)\(16M_p/L^2\)1.33
一端固定一端簡支 均布\(8M_p/L^2\)\(11.657M_p/L^2\)1.46

規律：靜定結構沒有贅餘，第一個鉸就是最後一個鉸；彈性彎矩圖越不均（峰值與其他斷面差越多），第一個鉸出現時其他斷面越閒，重分配能多拿的就越多。

SS-2005-4 三個門檻（§0 那張圖的數字）

$$w_e = \frac{8M_y}{L^2} = 2.07,\qquad w_1 = \frac{8M_p}{L^2} = 3.71,\qquad w_u = \frac{11.657M_p}{L^2} = 5.40\ \ \text{tf/m}$$

\(w_u/w_e = 1.79 \times 1.46 = 2.61\)：前一個是斷面儲備（形狀因子），後一個是結構儲備（重分配）。題解 §5.2 的「塑性 / 彈性 = 2.61」就是這兩段相乘。 這裡 \(M_y = F_yS_{min} = 930\) tf·cm，由肢端控制——固定端是負彎矩、肢端受壓，離 ENA 18.73 cm，遠比翼板頂的 5.27 cm 遠。

因果鏈 ⑤：彈性彎矩圖不均 → 峰值處先成鉸 → 鉸處彎矩被鎖在 \(M_p\) → 新增載重轉給其他斷面 → 直到第 \(n+1\) 個鉸 → 結構儲備 \(= w_u/w_1\)；機構法給上限、畫彎矩圖驗下限，兩者重合才是答案

§6 規範與前提：考卷的「塑性設計」和現行規範差在哪

考題寫「以塑性設計法／塑性分析」，就用 \(M_p = F_yZ\) 與機構法作答——本單元所有題解都這樣做。但現行規範對 \(M_n\) 另有上限與前提，答完可以補一段「依現行規範」的說明，這常是拉開分數的地方。

§7 因果鏈總表與解題決策流程

五條鏈都能用嘴巴講出來，這個單元就讀懂了：

① 斷面：應變線性 → 應力被 \(F_y\) 截頂 → 中性軸由合力為零決定 → 彈性在形心、全塑在等面積軸 → \(M_y = F_yS_{min}\)、\(M_p = F_yZ\)
② \(Z\)：全塑只有 ±\(F_y\) → 上下各半面積 → 力偶 \(F_yA/2\) × 兩半形心距 → \(Z = \sum A_i|d_i|\)（跨 PNA 切開）→ \(f = Z/S\) 衡量彈性時閒置的材料
③ 鉸：\(M \to M_p\) 需曲率 → ∞ → 集中成零長度的鉸 → 轉動時仍傳 \(M_p\)、耗能 \(M_p\theta\) → 要撐到最後 → \(\lambda \le \lambda_{pd}\)＋側撐
④ 機構：每個鉸拿掉一個贅餘 → \(n+1\) 個鉸成完整機構 → 虛位移 → 外功 = Σ\(M_p\)×相對轉角 → 鉸位未知對 \(x\) 求最小
⑤ 重分配：彈性彎矩圖不均 → 峰值先成鉸並被鎖住 → 載重轉給閒置斷面 → 第 \(n+1\) 個鉸才崩塌；機構法上限＋彎矩圖下限重合 → 精確解
解題決策流程。第一個菱形分開兩條題型線；右支一定會借用左支的 \(M_p\)。右下的菱形是「下限檢核」：機構法算完畫一次彎矩圖，有任何一處超過 \(M_p\) 就回到候選鉸位重來。兩支最後都匯到「前提檢核」再作答。
這張圖攔的錯：機構法算完就交卷（沒做下限檢核），以及非對稱斷面直接把 PNA 當形心。

§10 自我檢測：12 個「為什麼」

1. 為什麼彈性中性軸在形心，全塑中性軸在等面積軸？

兩者都來自 \(\int\sigma\,dA = 0\)。彈性時 \(\sigma \propto y\)，條件變成一次矩為零（形心）；全塑時 \(\sigma = \pm F_y\)，條件變成受壓面積 = 受拉面積。

2. 為什麼斷面永遠到不了「剛好」\(M_p\)？那塑性鉸怎麼來的？

中心那一小塊要應變無限大才會降伏，所以 \(M_p\) 是 \(M\)–\(\varphi\) 曲線的漸近線。實務上曲率集中在峰值附近一小段，理想化成零長度、可轉、傳 \(M_p\) 的塑性鉸。

3. SS-2023-3 頂翼板比底翼板寬，為什麼是底緣先降伏？

寬翼板把形心拉向頂部，底緣離 ENA 63.75 cm、頂緣只 46.25 cm；同一曲率下離中性軸越遠應變越大，所以底緣先到 \(F_y\)，\(S_{min} = S_{bot}\)。

4. 為什麼 \(Z = \sum A_i|d_i|\) 而不是 \(\sum A_i d_i^2\)？

全塑時每塊的應力都是常數 \(F_y\)，力 \(= F_yA_i\)，對 PNA 的力矩 \(= F_yA_i|d_i|\)，只有一次方。二次方出現在彈性，因為應力本身也和 \(d\) 成正比。

5. 空心圓管為什麼 \(Z\) 可以外減內，\(S\) 不行？

\(Z\) 是對同一條 PNA 的一次矩，可疊加；\(S = I/c\) 的 \(c\) 是外緣距離，內圓的 \(S\) 用的是內緣 \(c\)，分母不同不能相減。

6. H 型鋼的形狀因子為什麼只有 1.12 左右？

面積大多在翼板，彈性時翼板應力已接近 \(F_y\)，塑性化只能多叫醒腹板那一點點材料；\(S\) 已經很大，\(Z/S\) 自然小。

7. 塑性鉸和一般鉸最大的差別是什麼？在虛功裡怎麼體現？

塑性鉸傳 \(M_p\)、一般鉸傳 0。所以虛功內功只算塑性鉸的 \(M_p\times\)相對轉角，支承的真鉸不計。

8. 一端固定一端簡支、均布載重，跨間鉸為什麼不在跨中？偏向哪一端？

固定端的 \(-M_p\) 把靠近它那一側的正彎矩壓低，最大正彎矩被推向簡支端：距固定端 \(0.586L\)、距簡支端 \(0.414L\)。

9. 機構法為什麼是上限？猜錯機構會怎樣？

假設的機構只保證鉸處 \(M = M_p\)，不保證別處 \(|M| \le M_p\)。猜錯時某處實際已超過 \(M_p\)，等於高估強度，算出的 \(w\) 偏大（不安全）；所以取最小並畫彎矩圖驗證。

10. 為什麼兩端固定梁的結構儲備（1.33）比一端固定（1.46）小？

儲備大小取決於第一個鉸出現時其他斷面還閒置多少。一端固定時跨間只用到 \(0.5625M_p\)，兩端固定時跨中已到 \(0.5M_p\) 而兩端同時成鉸、可重分配的空間相對較小；比值由 \(w_u/w_1\) 決定：11.657/8 對 16/12。

11. 為什麼做塑性分析的寬厚比要比「結實」更嚴？

結實只保證到得了 \(M_p\)；塑性分析還要求先成的鉸在 \(M_p\) 下持續轉動，直到最後一個鉸形成。轉動中局部挫屈會讓彎矩掉下、無預警，重分配就不存在，所以要 \(\lambda \le \lambda_{pd}\)。

12. SS-2005-4 依 AISC 360-16 F9 重做，為什麼 \(w_u\) 會變小？

固定端負彎矩讓 T 型肢受壓，F9 限 \(M_n \le M_y = 930\) tf·cm（遠低於 \(M_p\) 1,669）；跨間肢受拉也被 \(1.6M_y = 1{,}488\) 截掉。兩個鉸都變弱，崩塌載重降為 4.28 tf/m（低 21%）。
