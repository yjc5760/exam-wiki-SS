1. 原始題目重述

（依考卷原文，93 年第 2 頁第三題）

三、有一托架（bracket）承受一偏心因數化載重（factored load, $P_u$），托架上下端分別銲接於柱子翼板，接頭與銲接相關尺寸如附圖所示。柱子為 W 型鋼，鋼柱、雙角鋼皆使用 A36 鋼材，使用填角銲（fillet weld）與 E70XX 銲條，假設接合相關各接板強度足夠。若使用銲接尺寸（weld size）為 10 mm 之填角銲，試根據極限設計法規範，以彈性分析求該托架所能承受之最大因數化載重（$P_u$）。（25 分）

參考資料：A36 鋼材：$F_y = 2.50$ t/cm²。E70XX 銲條 $F_{EXX} = 4.93$ t/cm²。附錄 鋼結構極限設計法規範及解說 表 10.2.5（填角銲有效面積上之剪力：$\phi = 0.75$，標稱強度 $0.6F_{EXX}$）。

圖說（依考卷原圖 400 dpi 目視判讀，2026-11-01 更正）：托架板搭在柱翼板上，上、下各有一組 ⊐ 形填角銲（斜線區）：沿托架上（下）緣的水平段 7.5 cm（自托架左緣至柱翼板右緣），加上沿托架左緣的垂直段 5 cm；中間 15 cm 不銲。托架總高 5＋15＋5＝25 cm。$P_u$ 作用於托架上緣、距柱翼板右緣 10 cm 處，箭頭以 1:1 斜率指向左下（朝柱）。

判讀表

項目 判讀
銲道 上、下各一組 ⊐ 形：水平 7.5 cm＋垂直 5 cm；單面銲，總長 $L_w = 2(7.5+5) = 25$ cm
銲腳 $w = 10$ mm → 喉厚 $a = 0.707$ cm
載重作用點 托架上緣，距銲道左緣 $7.5 + 10 = 17.5$ cm
載重方向 1:1 向左下：$P_x = P_u/\sqrt{2}$（←）、$P_y = P_u/\sqrt{2}$（↓）
求 彈性法（向量法）最大 $P_u$

2. 考題核心精神與出題者意圖

本題測驗 LRFD 偏心填角銲群的彈性向量法：

  1. 讀圖決定銲道群：上下各一組 ⊐ 形（水平＋垂直段），不是只有兩段水平銲
  2. 斜向載重兩分量的力矩方向：垂直分量（↓、作用於形心右側）產生順時針矩；水平分量（←、作用於形心上方）產生逆時針矩，兩者相減
  3. 出題者刻意讓載重作用線幾乎通過銲道形心，淨扭矩很小 → 直接剪力主控，$P_u$ 比「兩分量相加」大得多
  4. 銲縫群線性質（形心、$I_x$、$I_y$、$J$）與最不利點的向量疊加

3. 解題戰略地圖與陷阱分析

作戰計畫：
1. $\phi R_{nw}$（每 cm 銲道設計強度）
2. 銲道群形心 $\bar{x}$ 與 $J = I_x + I_y$
3. 作用點相對形心的座標 → 淨扭矩 $M = x\,P_y' - y\,P_x'$（帶正負號）
4. 各角點：直接剪力＋扭矩剪力向量疊加，取最大
5. $f_{r,\max} = \phi R_{nw}$ 解 $P_u$

陷阱分析：

陷阱 說明 應對策略
⚠️ 漏看垂直銲段 斜線區是 ⊐ 形，上下各含 5 cm 垂直段 放大附圖逐段數；$L_w = 25$ cm
⚠️ 載重方向看反 箭頭指向托架（朝柱、向左下），水平分量向左 水平分量力矩與垂直分量反向
⚠️ 偏心量的起點 10 cm 量自柱翼板右緣，不是銲道形心 形心距左緣 2.25 cm → $x = 17.5 - 2.25 = 15.25$ cm
⚠️ 形心不在銲道中點 垂直段在左緣，形心偏左 $\bar{x} = \Sigma L x / \Sigma L$
⚠️ 喉厚 公制 $a = 0.707w$ $a = 0.707$ cm

3.5 變數層次分析（Variable Hierarchy Analysis）

複習提示：解題後，在每個卡住的知識點「卡關?」欄標記 ⚠；第二次複習時只看有 ⚠ 的項目。

最終目標： LRFD 偏心填角銲（彈性向量法）→ 銲道群性質 → 帶正負號的淨扭矩 → 最不利點合力 → $P_u$

主要公式（$\boxed{\phantom{x}}$ = 未知，待推導）

$$\phi R_{nw} = 0.75 \times 0.6F_{EXX} \times \boxed{a}, \qquad a = 0.707w$$

$$\boxed{\bar{x}} = \frac{\Sigma L_i x_i}{\Sigma L_i}, \qquad \boxed{J} = I_x + I_y$$

$$\boxed{M} = x_P\,P_y - y_P\,P_x \quad \text{（帶正負號，逆時針為正）}$$

$$f_x = \frac{P_x}{L_w} - \frac{M\,y}{J}, \qquad f_y = \frac{P_y}{L_w} + \frac{M\,x}{J}, \qquad \boxed{f_r} = \sqrt{f_x^2 + f_y^2} \le \phi R_{nw}$$

知識點 說明 卡關?

彈性法 vs 瞬心法 彈性法偏保守；ICR 法可得較高強度

4. 步驟化詳細計算過程

4.1 填角銲設計強度

$$a = 0.707 \times 1.0 = 0.707\ \text{cm}$$

$$\phi R_{nw} = 0.75 \times 0.6 \times 4.93 \times 0.707 = \boxed{1.568\ \text{t/cm}}$$

4.2 銲道群線性質（以托架左緣、上下中點為原點）

銲段 長度 (cm) 位置
上水平 7.5 $y = +12.5$，$x = 0 \sim 7.5$
上垂直 5 $x = 0$，$y = 7.5 \sim 12.5$
下水平 7.5 $y = -12.5$，$x = 0 \sim 7.5$
下垂直 5 $x = 0$，$y = -7.5 \sim -12.5$

$$L_w = 25\ \text{cm}, \qquad \bar{x} = \frac{2 \times 7.5 \times 3.75}{25} = 2.25\ \text{cm}, \qquad \bar{y} = 0$$

$$I_x = 2(7.5)(12.5^2) + 2\left[5(10^2) + \frac{5^3}{12}\right] = 2343.75 + 1020.83 = 3364.6\ \text{cm}^3$$

$$I_y = 2\left[\frac{7.5^3}{12} + 7.5(3.75 - 2.25)^2\right] + 2\left[5(2.25)^2\right] = 104.06 + 50.63 = 154.7\ \text{cm}^3$$

$$J = I_x + I_y = \boxed{3519.3\ \text{cm}^3}$$

4.3 淨扭矩（逆時針為正）

作用點相對形心：$x_P = 17.5 - 2.25 = 15.25$ cm，$y_P = 12.5$ cm；$P_x = P_y = -0.7071P_u$（向左、向下）。

$$M = x_P P_y - y_P P_x = 15.25(-0.7071P_u) - 12.5(-0.7071P_u) = \boxed{-1.944\,P_u\ \text{t}\cdot\text{cm}}\ \text{（順時針）}$$

垂直分量產生順時針 $10.78P_u$、水平分量產生逆時針 $8.84P_u$，兩者大部分抵銷——載重作用線幾乎通過銲道形心。

圖 1　載重線幾乎通過銲道形心：兩個分量的力矩大部分抵銷，淨扭矩只有 $1.944P_u$。這張圖攔的是把形心放在托架左緣，或只用垂直分量取矩（扭矩放大 5.5 倍、$P_u$ 嚴重低估）。

4.4 各點應力（每 cm 銲道，$\times P_u$）

直接剪力：$f_{dx} = f_{dy} = -0.7071/25 = -0.02828$

扭矩剪力：$f_{tx} = -My/J$，$f_{ty} = Mx/J$

點 $(x, y)$ 相對形心 $f_x$ $f_y$ $f_r$
上水平右端 (5.25, 12.5) −0.02138 −0.03119 0.03781
上垂直上端 (−2.25, 12.5) −0.02138 −0.02704 0.03447
上垂直下端 (−2.25, 7.5) −0.02414 −0.02704 0.03625
下水平右端 (5.25, −12.5) −0.03519 −0.03119 0.04702

控制點：下水平銲右端，$f_r = 0.04702P_u$ t/cm（順時針扭矩使下緣右端的扭矩剪力朝左下，與直接剪力同向）。

4.5 求解最大 $P_u$

$$0.04702\,P_u = 1.568 \quad\Rightarrow\quad \boxed{P_u = 33.4\ \text{tf}}$$

4.6 雙路徑驗算

  • 路徑二（離散積分）：把四段銲道各切 600 等分，逐點計算面積、形心、$J$ 與合力，得 $\bar{x} = 2.25$、$J = 3519.3$、$f_{r,\max} = 0.04702P_u$，與閉合式一致。
  • 上限檢查：若無扭矩（純剪），$P_u = 1.568 \times 25 = 39.2$ t；本解 33.4 t 小於上限且接近，符合「載重線接近形心」的判斷。

圖 2　六個端點的應力向量與最大 $P_u$。控制點在下水平銲右端（$0.04702P_u$），$P_u = 33.4$ tf 為無扭矩上限的 85%；這張圖攔的是選錯控制點，以及答案遠低於上限仍不察覺扭矩算大了。
