2. 考卷給的公式、附表與參數

  • 卷首「◎參考公式集（請自行使用適合之公式，並檢查其正確性，若有問題應自行修正）」，與本題相關者照錄：

$$C_c = \sqrt{\frac{2\pi^2E}{F_y}},\qquad F_a = \frac{12}{23}\times\frac{\pi^2E}{(k\ell/r)^2},\qquad F_a = \frac{\left[1 - \dfrac{(k\ell/r)^2}{2C_c^2}\right]\cdot F_y}{\dfrac53 + \dfrac{3(k\ell/r)}{8C_c} - \dfrac{(k\ell/r)^3}{8C_c^3}}$$

$$\lambda_c = \left(\frac{k\ell}{r\pi}\right)\sqrt{\frac{F_y}{E}},\qquad F_{cr} = \left[\exp(-0.419\cdot\lambda_c^2)\right]\cdot F_y,\qquad F_{cr} = \left(\frac{0.877}{\lambda_c^2}\right)\cdot F_y$$

（公式集另有 $L_p$、$L_r$、$C_b$、$M_n$、$M_{cr}$，屬梁題。）公式未標適用範圍（$k\ell/r$ 與 $C_c$、$\lambda_c$ 與 1.5 的分界考卷沒寫）。

2. 考題核心精神與出題者意圖 (Core Concepts & Examiner's Intent)

核心觀念：組合柱斷面性質（平行軸定理）＋ ASD 與 LRFD 兩法柱強度

出題者測驗重點：
- 平行軸距離要配對正確的軸：角鋼繞水平軸的 $I_x$ 要配「形心到組合斷面水平軸的垂直距離」$20 - c_x$；繞垂直軸的 $I_y$ 要配水平距離 $20 - c_y$。
- 兩個方向都算，取較小的 $I$ 控制。
- ASD：$KL/r > C_c$ 用彈性 $F_a = 12\pi^2E/[23(KL/r)^2]$；LRFD：$\lambda_c > 1.5$ 用 $F_{cr} = 0.877F_y/\lambda_c^2$。

3. 解題戰略地圖與陷阱分析 (Strategic Roadmap & Trap Analysis)

作戰計畫：

Step 1  讀單角鋼圖：c_x 是垂直距離（對應水平軸 X），c_y 是水平距離（對應垂直軸 Y）
Step 2  組合慣性矩（平行軸定理）：
        I_X = 4[I_x + A(20 − c_x)²] = 4[782 + 35.3×15.0²]  = 34,898 cm⁴（控制）
        I_Y = 4[I_y + A(20 − c_y)²] = 4[276 + 35.3×17.47²] = 44,198 cm⁴
Step 3  r = √(34,898/141.2) = 15.72 cm，KL/r = 2500/15.72 = 159.0
(一) ASD：C_c = 126.4 < 159.0 → 彈性 → F_a = 0.415 → P_a = 58.7 t
(二) LRFD：λ_c = 1.779 > 1.5 → F_cr = 0.698 → φcPn = 83.8 t

陷阱分析：

陷阱 說明 對策
❶ 平行軸距離配錯軸 $I_x$（繞水平軸）必須配垂直距離 $20 - c_x$；把 $I_y = 276$ 配上 15 cm 就是把兩個方向混在一起 每一項都問「繞哪一軸？距離是不是垂直於這軸量的？」

最終目標： 四角鋼組合柱 → ASD 挫屈（容許）載重 $P_a$ 與 LRFD 設計強度 $\phi_c P_n$

主要公式（$\boxed{\phantom{x}}$ = 未知，待推導）

$$\boxed{I_X} = 4\left[I_x + A(20 - c_x)^2\right],\quad \boxed{I_Y} = 4\left[I_y + A(20 - c_y)^2\right],\quad \boxed{r} = \sqrt{\frac{\min(I_X, I_Y)}{4A}}$$

4. 步驟化詳細計算過程 (Step-by-Step Calculation)

一、組合斷面性質

$$A_{total} = 4 \times 35.3 = 141.2\ \text{cm}^2$$

各角鋼形心到組合形心的距離：

方向 計算 用於
垂直距離 $d_X = 20 - c_x = 20 - 5.0 = 15.0$ cm 繞水平軸 $X$
水平距離 $d_Y = 20 - c_y = 20 - 2.53 = 17.47$ cm 繞垂直軸 $Y$

繞水平軸 $X$：

$$I_X = 4\left(782 + 35.3 \times 15.0^2\right) = 4(782 + 7{,}942.5) = 34{,}898\ \text{cm}^4$$

繞垂直軸 $Y$：

$$I_Y = 4\left(276 + 35.3 \times 17.47^2\right) = 4(276 + 10{,}773.6) = 44{,}198\ \text{cm}^4$$

$I_X < I_Y$，繞水平軸控制：

$$r = \sqrt{\frac{34{,}898}{141.2}} = 15.72\ \text{cm},\qquad \frac{KL}{r} = \frac{2500}{15.72} = 159.0$$

圖 1　平行軸定理要同軸配對：$I_x = 782$ 配垂直距離 $d_X = 15.0$、$I_y = 276$ 配水平距離 $d_Y = 17.47$，$I_X = 34{,}898$ 控制。這張圖攔的是 276 配上 15 cm（得 32,874、$KL/r$ 163.8）、把 40 cm 當形心間距，或選錯控制軸。

二、ASD

$$C_c = \sqrt{\frac{2\pi^2 \times 2040}{2.52}} = 126.4 < 159.0\ \Rightarrow\ \text{彈性挫屈}$$

$$F_a = \frac{12\pi^2E}{23(KL/r)^2} = \frac{12\pi^2 \times 2040}{23 \times 159.0^2} = 0.415\ \text{tf/cm}^2$$

$$\boxed{P_a = 0.415 \times 141.2 = 58.7\ \text{tf}}$$

若題目「挫屈載重」指的是理論（尤拉）挫屈載重：$P_{cr} = \pi^2EI_X/(KL)^2 = 112.4$ tf；$P_a = P_{cr}/(23/12)$ ✔（112.4 ÷ 1.917 = 58.7）。

三、LRFD

$$\lambda_c = \frac{KL}{r\pi}\sqrt{\frac{F_y}{E}} = \frac{159.0}{\pi}\sqrt{\frac{2.52}{2040}} = 1.779 > 1.5\ \Rightarrow\ \text{彈性挫屈}$$

$$F_{cr} = \frac{0.877}{\lambda_c^2}F_y = \frac{0.877}{1.779^2} \times 2.52 = 0.698\ \text{tf/cm}^2$$

$$P_n = 0.698 \times 141.2 = 98.6\ \text{tf}$$

$$\boxed{\phi_cP_n = 0.85 \times 98.6 = 83.8\ \text{tf}}$$

圖 2　$KL/r = 159.0 > C_c = 126.4$，兩種方法都在彈性段：$P_a = 58.7$ tf、$\phi_cP_n = 83.8$ tf（Euler $P_{cr} = 112.4$ tf）。這張圖攔的是超過 $C_c$ 仍套非彈性式，或把 Euler 載重當容許載重。

雙路徑驗算： 彈性段兩式都等於尤拉載重乘係數：ASD $P_a = P_{cr} \times 12/23 = 112.4 \times 0.522 = 58.7$ ✔；LRFD $\phi_cP_n = 0.85 \times 0.877 \times P_{cr} = 0.745 \times 112.4 = 83.8$ ✔。

與舊版解析的差異： 舊解把角鋼繞垂直軸的 $I_y = 276$ 配上垂直距離 15 cm，得 $I = 32{,}876$、$r = 15.26$、$KL/r = 163.8$，$P_a = 55.3$、$\phi_cP_n = 79.0$ tf，約低估 6%。正確配對後兩個方向都比它大，控制方向是繞水平軸。
