1. 考卷原文（逐字）

二、如圖 2 所示之剛架承受均佈載重 w，柱 CD 為靠桿。已知梁及柱之 $E = 2{,}040$ tf/cm²，梁及柱之長度 $L = 6$ m，柱之 $I_c = 30{,}094$ cm⁴，梁之 $I_b = 136{,}108$ cm⁴。試使用 AISC Alignment Chart 及萊梅厥公式（LeMessurier formula），求解剛架中柱 AB 之有效長度係數 $K'_{AB}$ 及挫屈載重 $w_{cr}$(tf/m)＝？今若僅於梁 BC 上配置單位重 $\rho = 240$ tf/m² 之均佈載重，試求該載重容許配置的厚度 $d$(m)＝？（25 分）
（柱邊界為固接（Fixed end）時 G 使用 1、為鉸接（hinged end）時 G 使用 10。）

萊梅厥公式（LeMessurier formula）：$K' = \sqrt{\dfrac{P_e}{P_I} \times \dfrac{\Sigma P}{\Sigma P_{eK}}}$

$P_I$：欲求 K 值之柱所受的垂直載重
$P_e$：柱之尤拉載重（Euler buckling load）
$\Sigma P$：整體結構承受的總垂直外載重
$\Sigma P_{eK}$：整體結構所有非靠桿且考慮相應有效長度係數後之柱挫屈載重（Buckling load）

2. 考題核心精神與出題者意圖 (Core Concepts & Examiner's Intent)

核心觀念：靠桿（leaning column）把自己的重力載重「寄生」到有側向抵抗能力的柱上，必須用 LeMessurier 修正 $K$ 值。

一般對位圖（Alignment Chart）內含一個隱藏假設：同層所有柱同時達到挫屈、且每根柱都按比例分攤側移抵抗。當層內有靠桿（兩端鉸接、不提供側移勁度）時，這個假設破裂——靠桿的重力照樣會放大整層的 $P\text{-}\Delta$ 效應，但抵抗全靠 AB 一根。LeMessurier 公式就是把「別人的重量」折算成 AB 的額外有效長度：

$$K'_{AB} = \underbrace{K_{AB}}_{\text{對位圖}} \times \sqrt{\underbrace{\frac{\sum P}{P_I}}_{\text{靠桿懲罰}}}$$

步驟 計算項目 關鍵要領
1 判讀 A、D 支承與 C 鉸接 A、D 皆鉸 → $G_A = 10$；C 為鉸 → CD 為靠桿
2 $G_B = \sum(I_c/L_c)/\sum(I_b/L_b)$ 同長度時即 $I_c/I_b$
3 查側位移不束制對位圖 得 $K_{AB}$
4 靜力求各柱軸力 CD 為二力構件 → $P_{CD} = wL/2$，故 $P_{AB} = wL/2$
5 LeMessurier $\sum P_{eK}$ 只計 AB（CD 是靠桿要剔除）
6 $w_{cr} \to d$ $d = w_{cr}/\rho$

出題者測驗重點：

  1. 認得「靠桿」三個字 → 知道 $\sum P_{eK}$ 要把 CD 剔除，而 $\sum P$ 要把 CD 的載重算進去
  2. 會用考卷給的 LeMessurier 公式（不是自己編一條 $\sum P = \sum P_e$）
  3. 由靜力（不是「各分一半」的直覺）確認 $P_{AB} = P_{CD} = wL/2$
  4. 單位換算：$w_{cr}$ 為 tf/m，最後 $d = w_{cr}/\rho$

3. 解題戰略地圖與陷阱分析 (Strategic Roadmap & Trap Analysis)

作戰計畫：

Step 1  判讀邊界：A 鉸、D 鉸、B 剛接、C 鉸 → CD 為靠桿
Step 2  G_A = 10（A 鉸接）、G_B = Ic/(0.5Ib) = 0.442（C 端梁柱鉸接 → 梁遠端修正 ×0.5）
Step 3  查「側位移不束制」對位圖 → K_AB ≈ 1.78（方程式精解 1.777）
Step 4  Pe = π²EIc/L²（K=1）；PeK,AB = Pe/K_AB²
Step 5  靜力：CD 為二力構件 → P_CD = wL/2 → P_AB = wL/2，ΣP = wL
Step 6  LeMessurier：K' = √[(Pe/P_I)(ΣP/ΣPeK)]，ΣPeK 只含 AB
Step 7  P_I = π²EIc/(K'L)² → 解 w_cr → d = w_cr/ρ

關鍵陷阱：

⚠️ 陷阱 1（本題最致命）：「靠桿」不是「鉸接柱」
「靠桿（leaning column）」＝上下兩端皆鉸、只能承重不能抗側移的柱。
若把 CD 誤讀成「底端鉸接的一般柱」而去查它自己的 $K_{CD}$，並寫成
$w_{cr}L = P_{eK,AB} + P_{eK,CD}$，會把 $w_{cr}$ 高估 2～3 倍（詳見 §5.1）。
判別要訣：看圖上 C 點有沒有畫小圓圈（鉸）。有圓圈 → 梁無法拘束 CD 頂端轉動 → 靠桿。

⚠️ 陷阱 1-2：同一個小圓圈也改變 $G_B$
對位圖（有側移）假設梁兩端同向等角轉動、呈反向曲率，近端勁度 $6EI/L$；圖上的 $G$ 只放 $I/L$，等於已內含此假設。
本題梁 BC 的 C 端鉸接，B 端轉 $\theta$ 時梁只能提供 $3EI\theta/L$，是假設的一半 → 計算 $G_B$ 時梁的 $I_b/L$ 要乘 0.5（AISC 解說 Appendix 7）。
不修正會高估梁對 AB 的轉動束制 → $K$ 偏小 → $w_{cr}$ 高估約 8%（偏不保守）。

⚠️ 陷阱 2：$\sum P$ 與 $\sum P_{eK}$ 的「不對稱」
$\sum P$（要抵抗的力）＝全部柱的垂直載重（含靠桿）；
$\sum P_{eK}$（可用的容量）＝只有非靠桿柱的挫屈載重。
這個「載重算你的、容量不算你的」正是靠桿的懲罰機制，也是本公式的靈魂。

⚠️ 陷阱 3：對位圖用哪一張
本題整層可自由側移（A、D 皆鉸、無斜撐）→ 查側位移不束制（右圖，$K \ge 1.0$）。
誤查左圖（側位移束制，$K \le 1.0$）會嚴重低估 $K$、高估承載力。

⚠️ 陷阱 4：$P_e$ 用 $K=1$，不是用 $K_{AB}$
考卷定義 $P_e$ 為「柱之尤拉載重」＝ $\pi^2EI/L^2$。分子用 $P_e$、分母用 $\sum P_{eK}$（含 $K$），
兩者相除才會生出 $K_{AB}^2$。若分子也代 $K_{AB}$，$K'$ 會退化成 $\sqrt{2}$，喪失對位圖資訊。

⚠️ 陷阱 5：$d$ 的量綱
$\rho = 240$ tf/m² 為「每 m² 每 m 厚」的面載重密度，$w = \rho \cdot d$ 得 tf/m，
故 $d[\text{m}] = w_{cr}[\text{tf/m}] / \rho[\text{tf/m}^2]$，不需再乘梁寬。

3.5 變數層次分析（Variable Hierarchy Analysis）

複習提示：解題後，在每個卡住的知識點「卡關?」欄標記 ⚠；第二次複習時只看有 ⚠ 的項目。

最終目標： 含靠桿之側移剛架 → 對位圖 $K_{AB}$ → LeMessurier 修正 $K'_{AB}$ → 挫屈載重 $w_{cr}$ → 容許堆置厚度 $d$

主要公式（$\boxed{\phantom{x}}$ = 未知，待推導）

$$\text{Step 1:}\quad G_A = 10\ (\text{A 鉸接}),\qquad \boxed{G_B} = \frac{\sum (I_c/L_c)}{\sum (I_b/L_b)} = \frac{I_c}{I_b}$$

$$\text{Step 2:}\quad \boxed{K_{AB}} \;\Leftarrow\; \text{側位移不束制對位圖}\left(G_A,\ \boxed{G_B}\right)$$

$$\text{Step 3:}\quad P_e = \frac{\pi^2 E I_c}{L^2},\qquad \boxed{P_{eK,AB}} = \frac{P_e}{\boxed{K_{AB}}^{\,2}}$$

$$\text{Step 4:}\quad \sum M_A = 0 \;\Rightarrow\; \boxed{P_{CD}} = \frac{wL}{2},\qquad P_I = P_{AB} = \frac{wL}{2},\qquad \sum P = wL$$

$$\text{Step 5:}\quad \boxed{K'_{AB}} = \sqrt{\frac{P_e}{P_I} \times \frac{\sum P}{\sum P_{eK}}} = \boxed{K_{AB}}\sqrt{\frac{\sum P}{P_I}}\quad\left(\sum P_{eK} = \boxed{P_{eK,AB}}\ \text{only}\right)$$

$$\text{Step 6:}\quad P_I = \frac{\pi^2 E I_c}{\left(\boxed{K'_{AB}}L\right)^2} = \frac{w_{cr}L}{2} \;\Rightarrow\; \boxed{w_{cr}}$$

$$\text{Step 7:}\quad \boxed{d} = \frac{\boxed{w_{cr}}}{\rho}$$

L3：深層知識（不懂就卡住）

知識點 說明 卡關?
靠桿（leaning column）的定義 上下兩端皆鉸接之柱：可承重、零側向勁度；其重力仍放大整層 $P\text{-}\Delta$，抵抗全由非靠桿柱承擔

靠桿本身的檢核用 $K = 1.0$ 靠桿不承擔側移抵抗，其自身強度以 $K=1.0$ 檢核即可（本題 $P_{e,CD}=1683 \gg 288$ tf，OK）

二、計算 G 值

節點 B：

未修正比值：$\dfrac{I_c/L}{I_b/L} = \dfrac{30{,}094}{136{,}108} = 0.221$。

梁遠端修正： 對位圖（有側移）假設梁兩端同向等角轉動 $\theta$、呈反向曲率，近端勁度 $6EI/L$。本題梁 BC 的 C 端與靠桿 CD 鉸接（圖上小圓圈），C 端不能傳彎矩，B 端轉 $\theta$ 時梁只提供 $3EI\theta/L$，為假設值的一半 → 梁的 $I_b/L$ 乘 0.5：

$$G_B = \frac{\sum (I_c / L_c)}{\sum 0.5\,(I_b / L_b)} = \frac{30{,}094/600}{0.5 \times 136{,}108/600} = \boxed{0.442}$$

支承 A（鉸接，依題目規定取 10）：

$$G_A = 10$$

三、由 AISC Alignment Chart 查有效長度係數

整層可側移 $\Rightarrow$ 使用側位移不束制（sidesway uninhibited）對位圖：

$$G_A = 10,\quad G_B = 0.442 \quad \Longrightarrow \quad \boxed{K_{AB} \approx 1.78}$$

（Jackson–Moreland 近似式驗算）

$$K_{AB} = \sqrt{\frac{1.6G_AG_B + 4(G_A+G_B) + 7.5}{G_A+G_B+7.5}} = \sqrt{\frac{1.6(10)(0.442)+4(10.442)+7.5}{10.442+7.5}}$$

$$= \sqrt{\frac{7.07+41.77+7.50}{17.94}} = \sqrt{3.140} = 1.772 \ \checkmark$$

（精解超越方程式 $\dfrac{G_AG_B(\pi/K)^2-36}{6(G_A+G_B)} = \dfrac{\pi/K}{\tan(\pi/K)}$ 得 $K = 1.777$；以下用精解值。）

策略註解： 此處 $K_{AB} = 1.78$ 只是「AB 自己一根、按比例分攤」的答案。它還沒有包含靠桿 CD 把重量壓過來的效應——那是下一步 LeMessurier 的工作。

四、各柱之尤拉載重與挫屈載重

共用量：

$$\pi^2 E I_c = 9.8696 \times 2040 \times 30{,}094 = 6.059 \times 10^8 \ \text{tf}\cdot\text{cm}^2$$

尤拉載重（$K = 1$，考卷定義之 $P_e$）：

$$P_e = \frac{\pi^2 E I_c}{L^2} = \frac{6.059 \times 10^8}{600^2} = \frac{6.059 \times 10^8}{360{,}000} = \boxed{1{,}683 \ \text{tf}}$$

柱 AB（非靠桿）考慮 $K_{AB}$ 後之挫屈載重：

$$P_{eK,AB} = \frac{\pi^2 E I_c}{(K_{AB}L)^2} = \frac{P_e}{K_{AB}^2} = \frac{1{,}683}{1.777^2} = \frac{1{,}683}{3.156} = \boxed{533.3 \ \text{tf}}$$

$\sum P_{eK}$（僅計非靠桿柱）：

$$\sum P_{eK} = P_{eK,AB} = 533.3 \ \text{tf}$$

⚠️ 柱 CD 是靠桿，依考卷對 $\sum P_{eK}$ 的定義（「所有非靠桿且考慮相應有效長度係數後之柱挫屈載重」），不得加入 $P_{eK,CD}$。

五、靜力求各柱垂直載重

柱 CD 兩端鉸接、桿上無橫向載重 $\Rightarrow$ 二力構件，只能沿桿軸（垂直）傳力，故 $D_x = 0$。

取「柱 AB＋梁 BC」為自由體（A 為鉸，未知 $A_x$、$A_y$、$P_{CD}$，共 3 個未知量，靜定）：

$$\sum M_A = 0:\quad (wL)\cdot\frac{L}{2} - P_{CD}\cdot L = 0 \quad \Longrightarrow \quad P_{CD} = \frac{wL}{2}$$

$$\sum F_y = 0:\quad P_{AB} = wL - P_{CD} = \frac{wL}{2}$$

因此：

$$P_I = P_{AB} = \frac{wL}{2},\qquad \sum P = P_{AB} + P_{CD} = wL,\qquad \boxed{\frac{\sum P}{P_I} = 2}$$

策略註解： $\sum P / P_I = 2$ 與 $w$ 無關（純幾何比），所以 $K'$ 可以在還不知道 $w$ 的情況下先算出來——這是本題能「先求 $K'$ 再求 $w_{cr}$」的關鍵。

六、（一）萊梅厥公式求 $K'_{AB}$

$$K'_{AB} = \sqrt{\frac{P_e}{P_I} \times \frac{\sum P}{\sum P_{eK}}} = \sqrt{\frac{P_e}{\sum P_{eK}} \times \frac{\sum P}{P_I}} = \sqrt{K_{AB}^2 \times 2}= K_{AB}\sqrt{2}$$

$$= \sqrt{\frac{1{,}683}{533.3} \times 2} = \sqrt{3.156 \times 2} = \sqrt{6.312}$$

$$\boxed{K'_{AB} = 2.51}$$

物理解讀： 對位圖給 1.78，LeMessurier 把它放大 $\sqrt{2} = 1.414$ 倍到 2.51。
根號裡那個「2」就是「AB 自己 1 份重量 ＋ 靠桿 CD 塞給它 1 份重量」。

七、（二）挫屈載重 $w_{cr}$

以 $K'_{AB}$ 檢核柱 AB：

$$P_{cr,AB} = \frac{\pi^2 E I_c}{(K'_{AB}L)^2} = \frac{1{,}683}{2.513^2} = \frac{1{,}683}{6.313} = 266.6 \ \text{tf}$$

（等價寫法 $P_{eK,AB}/(\sum P/P_I) = 533.3/2 = 266.6$ tf。）

令 $P_{AB} = P_{cr,AB}$：

$$\frac{w_{cr}L_{beam}}{2} = 266.6 \ \text{tf}, \qquad L_{beam} = 6 \ \text{m}$$

$$\boxed{w_{cr} = \frac{2 \times 266.6}{6} = 88.87 \approx 88.9 \ \text{tf/m}}$$

獨立驗算（層穩定觀點）： $K'$ 的定義本身就等價於「整層總垂直載重不得超過非靠桿柱之挫屈容量總和」：

$$\sum P \le \sum P_{eK} \;\Rightarrow\; w_{cr}L_{beam} \le 533.3 \ \text{tf} \;\Rightarrow\; w_{cr} = \frac{533.3}{6} = 88.9 \ \text{tf/m} \ \checkmark$$

兩條路徑吻合，確認 $K'$ 用法正確。

八、（三）容許配置厚度 $d$

堆置材料單位重 $\rho = 240$ tf/m²，堆厚 $d$（m）在梁上產生之線載重：

$$w = \rho \cdot d \quad [\text{tf/m}]$$

令 $w = w_{cr}$：

$$240\,d = 88.87 \quad \Longrightarrow \quad \boxed{d = \frac{88.87}{240} = 0.370 \ \text{m} \approx 37 \ \text{cm}}$$

5. 關鍵爭議點與進階探討 (Critical Issues & Advanced Discussion)

5.1 若把 CD 誤當成一般柱：高估 2 倍以上

這是本題最常見的錯法，值得完整寫下來當反例：

步驟 誤解法（CD 視為「底端鉸接的一般柱」） 正解（CD 為靠桿）

穩定條件 $w_{cr}L = \sum P_{eK}$ $K' = K\sqrt{\sum P/P_I}$，$P_I = \pi^2EI_c/(K'L)^2$

若更進一步把 $G_A$ 也誤取 1（誤判 A 為固接），$K_{AB}$ 掉到 1.21、$P_{eK,AB}$ 升到 1,150 tf，$w_{cr}$ 會衝到約 287 tf/m，高估約 3 倍。

圖 3　同一個結構、四種讀法的挫屈載重量級。攔錯： 算出 $w_{cr}$ 落在 190～290 tf/m 卻沒察覺——那正是把靠桿的容量也算進 $\sum P_{eK}$ 的徵兆；正解只有 88.9 tf/m。

錯在哪： C 點是鉸，梁 BC 對柱 CD 頂端的轉動沒有任何拘束，$G_C$ 根本無意義；CD 挫屈時只會隨 AB 一起平移（剛體傾斜），不會自己彎曲。它對整層穩定的貢獻是負的（送重量、不送勁度）。

5.2 LeMessurier 公式的兩種等價寫法

考卷給的形式：

$$K' = \sqrt{\frac{P_e}{P_I}\cdot\frac{\sum P}{\sum P_{eK}}}$$

代入 $P_e / P_{eK} = K^2$ 後可整理為：

$$K' = K\sqrt{\frac{\sum P}{P_I}} \qquad\text{或等價的層穩定判準}\qquad \frac{\sum P}{\sum P_{eK}} \le 1$$

後者計算最快，但考場請照抄考卷給的形式逐步代入，才拿得到過程分。第七節的兩路驗算就是在示範這件事。

5.3 依最新規範的作法：對位圖已非首選

穩定分析主流程 有效長度法（$K$ 值＋對位圖） 直接分析法 Direct Analysis Method（Ch. C）：取 $K = 1.0$，改以「勁度折減 $0.8\tau_b$ ＋ 名義側向載重 $N_i = 0.002Y_i$ ＋ 二階分析」處理

5.4 對位圖端部條件的 G 值修正

端部 理論 $G$ 規範建議 $G$ 原因
固接（完全固端） 0 1 基礎必有彈性轉動，$G = 0$ 過於樂觀
鉸接（完全鉸端） $\infty$ 10 數值穩定性；實際鉸接仍有少量轉動拘束

本題 A 為鉸支承，依題目規定取 $G_A = 10$。若誤取理論值 $G_A = \infty$：

$$K_{AB} \to 2.15\ (\text{精解；近似式}\ \sqrt{1.6G_B + 4} = 2.17) \;\Rightarrow\; K' = 3.04 \;\Rightarrow\; P_{eK,AB} = 365.2\ \text{tf} \;\Rightarrow\; w_{cr} \approx 60.9\ \text{tf/m}$$

比正解低約 32%（過度保守）。這說明題目為什麼要特地交代「鉸接時 $G$ 使用 10」——不是細節，而是會改變答案三成的關鍵指示。

5.5 若不作梁遠端修正（直接套圖）：高估約 8%，偏不保守

對位圖的 $G$ 只放構材的 $I/L$，但推導時默認了梁的變形型態：有側移圖假設所有節點同向等角轉動 $\theta$、梁呈反向曲率，近端勁度 $6EI/L$；無側移圖假設梁呈單曲率，近端勁度 $2EI/L$。梁的實際遠端條件不同時，梁的 $I/L$ 要乘修正係數（AISC 解說 Appendix 7）：

梁遠端 有側移 無側移
鉸接 ×0.5（$3EI/L \div 6EI/L$） ×1.5（$3EI/L \div 2EI/L$）
固接 ×0.67（$4EI/L \div 6EI/L$） ×2.0（$4EI/L \div 2EI/L$）

本題梁 BC 的 C 端鉸接、構架有側移 → ×0.5，即主答的 $G_B = 0.442$。若直接以 $G_B = 0.221$ 套圖：

$$G_B = 0.221 \;\Rightarrow\; K_{AB} = 1.71\ (\text{精解 } 1.724) \;\Rightarrow\; K' = 2.42\ (2.44) \;\Rightarrow\; w_{cr} = 96.0\ (94.3)\ \text{tf/m},\ d = 0.40\ (0.39)\ \text{m}$$

梁實際只能提供一半的轉動束制，不修正等於高估梁對柱 AB 頂端的束制 → $G$ 偏小、$K$ 偏小 → 挫屈載重高估約 8%，偏不保守。考卷只說「使用 AISC Alignment Chart」，未提示修正；本解以修正值為主答，因為圖上 C 點的小圓圈正是本題考點，且與本庫 SS-2011-4（A 點梁柱鉸接，乘 ½）的處理一致。考場若時間有限，至少寫出修正係數與方向，未修正值可作對照。
