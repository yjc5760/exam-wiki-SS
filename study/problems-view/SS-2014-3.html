1. 原始題目重述 (Problem Restatement)

原卷逐字：「有一 ASTM A572 Gr.50 之 W21×93 簡支鋼梁，梁長 4 m，在梁兩端（一端為鉸接支承，另一端為滾支承）均有側向支撐，梁全長承受均佈的雙向彎矩 $M_{ux}=400$ kN-m 及 $M_{uy}=50$ kN-m（兩彎矩均已含載重係數且均作用在梁之剪力中心），利用極限設計法（LRFD）檢核此梁是否滿足設計要求。（25 分）」

⚠️ 題意關鍵：「均佈的雙向彎矩」修飾的是「彎矩」而非「載重」，且明言彎矩「作用在梁之剪力中心」——最直接的解讀是彎矩沿全長為定值（均勻彎矩），此時 $C_b = 1.0$。另一種解讀（均佈載重造成之最大彎矩）則 $C_b = 1.136$。本解析以 $C_b = 1.0$ 為主答（貼合原文且較保守），並完整列出另一解讀之結果；兩者結論皆為「滿足設計要求」。詳見 §5 ①。

2. 考題核心精神與出題者意圖 (Core Concepts & Examiner's Intent)

核心觀念：
- 雙向彎曲（Biaxial Bending）：強弱軸各有不同的強度計算邏輯，最終用互制公式疊加
- 非彈性 LTB（側扭挫屈）：$L_p < L_b < L_r$ 時，強度介於 $M_p$ 與 $M_r$ 之間，Cb 可提升

出題意圖：
1. 測試 LTB 三段式（塑性、非彈性、彈性）的判斷與計算
2. 測試弱軸彎矩強度的特殊限制（$M_{ny} \leq 1.5 F_y S_y$）
3. 測試雙向彎矩互制公式的正確應用

陷阱：
- ⚠️ 弱軸強度上限：$Z_y/S_y = 1.57 > 1.5$，2010 規範／AISC LRFD 1993 必須用 $1.5F_yS_y$ 而非 $F_yZ_y$（AISC 360-10 起放寬為 $1.6F_yS_y$，見 §6）
- ⚠️ Cb 的判讀：先確認彎矩圖形狀再套四點求積式——「均勻彎矩」得 $C_b = 1.0$；「均佈載重」得 $C_b = 1.136$。不可跳過判讀直接假設
- ⚠️ 無側向中間支撐：$L_b$ = 全梁長 = 4 m（不是一半）

作戰計畫：

  └─ Mux/φbMnx + Muy/φbMny ≤ 1.0

4. 步驟化詳細計算過程 (Step-by-Step Detailed Calculation)

Step 1：局部挫屈檢核

翼板寬厚比：

$$\lambda = \frac{b_f}{2t_f} = \frac{214}{2 \times 23.6} = \frac{214}{47.2} = 4.53$$

題目給定：$\lambda_p = 9.19$，$\lambda_r = 22.3$

$$\lambda = 4.53 < \lambda_p = 9.19 \quad \Rightarrow \quad \textbf{結實斷面（翼板）✓}$$

腹板寬厚比：

$$h = d - 2t_f = 548.6 - 2(23.6) = 501.4 \text{ mm}$$

$$\frac{h}{t_w} = \frac{501.4}{14.7} = 34.1$$

$$\lambda_{p,\text{web}} = 3.76\sqrt{\frac{E}{F_y}} = 3.76\sqrt{\frac{200{,}000}{350}} = 3.76 \times 23.9 = 89.8$$

$$34.1 < 89.8 \quad \Rightarrow \quad \textbf{結實斷面（腹板）✓}$$

斷面為結實斷面（Compact Section），可達全塑性彎矩 $M_p$。

Step 2：強軸彎矩強度 $\phi_b M_{nx}$

圖說：LTB 核心藍圖——三區段理論。橫軸為無支撐長度 $L_b$，縱軸為標稱彎矩強度 $M_n$。① 塑性區（$L_b \leq L_p$）：強度由材料塑性能力決定，梁能達全塑性彎矩 $M_p$。② 非彈性 LTB 區（$L_p < L_b \leq L_r$）：強度由材料塑性與幾何不穩定性共同決定，曲線線性下降（含 $C_b$ 修正）。③ 彈性 LTB 區（$L_b > L_r$）：強度純粹由幾何不穩定性決定，為典型的尤拉挫屈行為（$M_n = M_{cr}$）。本題 $L_b = 4$ m 落於第②區（非彈性 LTB）。

2a. 確定 LTB 範圍

無側向中間支撐，兩端支承處有側向支撐：

$$L_b = 4 \text{ m}$$

比較：$L_p = 2 \text{ m} < L_b = 4 \text{ m} < L_r = 5.8 \text{ m}$

$$\Rightarrow \textbf{非彈性 LTB 控制}$$

2b. 計算 $C_b$（依原卷「均佈的雙向彎矩」＝均勻彎矩）

原卷寫「梁全長承受均佈的雙向彎矩 $M_{ux} = 400$ kN-m」，且彎矩「作用在梁之剪力中心」——即 $M_{ux}$ 沿全長為定值（兩端施加等值同向端彎矩，彎矩圖為矩形）。四分點彎矩全等於 $M_{\max}$：

位置 相對位置 彎矩
$M_A$（$L/4$處） $x = 1$ m $M_A = M_{max} = 400$ kN-m
$M_B$（$L/2$處） $x = 2$ m $M_B = M_{max} = 400$ kN-m
$M_C$（$3L/4$處） $x = 3$ m $M_C = M_{max} = 400$ kN-m

$$C_b = \frac{12.5 \times 400}{2.5(400) + 3(400) + 4(400) + 3(400)} = \frac{5000}{5000} = \boxed{1.0}$$

均勻彎矩是 LTB 最不利的載重型態（$C_b = 1.0$，$C_b$ 的定義基準），因為整段無側撐長度內壓力翼板都承受最大壓應力。題目給出 $C_b$ 公式的用意，正是要考生套式驗證得 1.0，而非憑印象套用其他值。

另一解讀（若視為「均佈載重造成之最大彎矩」）：彎矩圖為拋物線，$M(x) = 4M_{max}x(L-x)/L^2$，四分點 $M = \frac{3}{4}M_{max} = 300$ kN-m：

$$C_b = \frac{12.5 \times 400}{2.5(400) + 3(300) + 4(400) + 3(300)} = \frac{5000}{4400} = 1.136$$

本解析以 $C_b = 1.0$ 為主答，$C_b = 1.136$ 全程並列（見 §5 ①）。

2c. 計算 $M_p$ 與 $M_r$

$$M_p = F_y Z_x = 350 \times 3{,}621{,}541 = 1{,}267{,}539{,}350 \text{ N-mm} = \boxed{1267.5 \text{ kN-m}}$$

$$M_r = (F_y - F_r) S_x = (350 - 78) \times 3{,}146{,}316 = 272 \times 3{,}146{,}316 = 855{,}798{,}000 \text{ N-mm} = \boxed{855.8 \text{ kN-m}}$$

策略註解：$F_r = 78$ MPa 為殘留應力，題目已給定，不可忘記

2d. 非彈性 LTB 標稱強度

圖說：非彈性 LTB 線性內插公式的物理意義拆解。$M_n = C_b \left[ M_p - (M_p - M_r) \cdot \dfrac{L_b - L_p}{L_r - L_p} \right] \leq M_p$。各項含義：「天花板」= $M_p$，梁的塑性強度極限；「地板」= $M_r$，非彈性挫屈的強度起點；「總墜距離」= $M_p - M_r$，從塑性區到彈性區的強度縮幅；「相對位置」= $(L_b - L_p)/(L_r - L_p)$，梁的 $L_b$ 在 $L_p$ 與 $L_r$ 之間走了多遠的比例（0 到 1）。此公式本質是描述梁強度從「純材料」過渡到「材料＋幾何」行為的線性內插模型。$C_b$ 乘入後需以 $M_p$ 為上限截斷。

$$M_n = C_b \left[ M_p - (M_p - M_r)\frac{L_b - L_p}{L_r - L_p} \right] \leq M_p$$

中括號內的基準值（與 $C_b$ 無關）：

$$\left[ 1267.5 - (1267.5 - 855.8) \times \frac{4 - 2}{5.8 - 2} \right] = 1267.5 - 411.7 \times 0.5263 = 1267.5 - 216.7 = 1050.8 \text{ kN-m}$$

主答（$C_b = 1.0$）：

$$M_{nx} = 1.0 \times 1050.8 = 1050.8 \text{ kN-m} < M_p = 1267.5 \ \checkmark$$

$$\boxed{\phi_b M_{nx} = 0.9 \times 1050.8 = \textbf{945.8 kN-m}}$$

另解（$C_b = 1.136$）：

$$M_{nx} = 1.136 \times 1050.8 = 1193.8 \text{ kN-m} < M_p = 1267.5 \ \checkmark \quad \Rightarrow \quad \phi_b M_{nx} = 1074.4 \text{ kN-m}$$

兩解讀下 $M_n$ 皆未觸及 $M_p$ 上限（$C_b$ 需 1.206 才會觸頂），故 $C_b$ 完全以比例反映在結果上。

Step 3：弱軸彎矩強度 $\phi_b M_{ny}$

弱軸彎曲：I 型斷面弱軸無 LTB，僅考量斷面強度。

$$M_{p,y} = F_y Z_y = 350 \times 568{,}631 = 199{,}021{,}000 \text{ N-mm} = 199.0 \text{ kN-m}$$

⚠️ 陷阱：弱軸強度上限

AISC-LRFD 規範對雙對稱 I 型斷面弱軸彎曲，設有上限：
$$M_{ny} \leq 1.5 \times F_y \times S_y$$

驗算形狀因數：

$$\frac{Z_y}{S_y} = \frac{568{,}631}{362{,}154} = 1.570 > 1.5$$

由於 $Z_y > 1.5 S_y$，以上限值控制：

$$M_{ny} = 1.5 F_y S_y = 1.5 \times 350 \times 362{,}154 = 190{,}131{,}000 \text{ N-mm} = 190.1 \text{ kN-m}$$

$$\boxed{\phi_b M_{ny} = 0.9 \times 190.1 = \textbf{171.1 kN-m}}$$

注意規範版本：AISC 360-10 起上限放寬為 $1.6F_yS_y = 202.8$ kN-m，此時 $F_yZ_y = 199.0 < 202.8$ 不再受上限控制，$M_{ny} = 199.0$ kN-m（+4.7%）。本題依 2010 規範（＝AISC LRFD 1993 §6.6）取 1.5 倍。詳見 §6。

策略註解：$Z_y/S_y = 1.57 > 1.5$，這是 W 型寬翼鋼梁的常見情況，考試重要陷阱！

Step 4：雙向彎矩互制公式檢核

無軸力（$P_u = 0$）時，AISC-LRFD／台灣 2010 規範的 H1-1b 式自動退化為線性疊加：

$$\frac{P_u}{2\phi P_n} + \left(\frac{M_{ux}}{\phi_b M_{nx}} + \frac{M_{uy}}{\phi_b M_{ny}}\right) \leq 1.0 \quad \xrightarrow{\ P_u = 0\ } \quad \frac{M_{ux}}{\phi_b M_{nx}} + \frac{M_{uy}}{\phi_b M_{ny}} \leq 1.0$$

⚠️ 規範中並無編號「H1-2」的式子；純彎曲的線性互制式是 H1-1b 在 $P_u = 0$ 時的退化型（H1-1a 適用 $P_u/\phi P_n \geq 0.2$）。

主答（$C_b = 1.0$）：

$$\frac{400}{945.8} + \frac{50}{171.1} = 0.423 + 0.292 = \boxed{0.715} \leq 1.0 \quad \textbf{✅ 滿足}$$

另解（$C_b = 1.136$）：

$$\frac{400}{1074.4} + \frac{50}{171.1} = 0.372 + 0.292 = 0.664 \leq 1.0 \quad \textbf{✅ 滿足}$$

$$\Rightarrow \quad \textbf{兩種題意解讀下，本梁皆滿足設計要求}$$

補充：剪力強度確認

📝 考場策略說明： 本題未提供剪力強度公式，且核心考點明確落在 LTB、弱軸上限與雙向互制。對 W 型鋼受均布載重而言，彎矩幾乎必然先於剪力達到極限，剪力公式省略有其出題邏輯。

考場建議作法： 在總結處補一句「W 型斷面腹板充足，剪力強度安全無虞，省略詳細計算」，即可向閱卷委員展示你知道這個極限狀態的存在，同時不浪費時間。

若需完整驗算（參考用），由彎矩反推均布載重：

$$w_u = \frac{8 M_{ux}}{L^2} = \frac{8 \times 400}{4^2} = 200 \text{ kN/m}$$

$$V_u = \frac{w_u L}{2} = \frac{200 \times 4}{2} = 400 \text{ kN}$$

腹板寬厚比 $h/t_w = 34.1 < 2.45\sqrt{E/F_y} = 58.6$，屬非細長腹板，適用最基本的降伏公式：

$$V_n = 0.6 F_y A_w = 0.6 \times 350 \times (548.6 \times 14.7) = 0.6 \times 350 \times 8064 = 1{,}694 \text{ kN} \quad (A_w = d\,t_w)$$

$$\phi_v V_n = 0.9 \times 1{,}694 = 1{,}524 \text{ kN} \gg V_u = 400 \text{ kN} \quad \textbf{✓ 剪力利用率僅 26\%，無虞}$$

若改採台灣規範的 $A_w = (d - 2t_f)t_w = 7{,}371$ mm²：$V_n = 1{,}548$ kN，$\phi_vV_n = 1{,}393$ kN，利用率 28.7%，同樣無虞。
AISC 360-16 §G2 因 $h/t_w = 34.1 \leq 2.24\sqrt{E/F_y} = 53.5$ 而取 $\phi_v = 1.00$，$\phi_vV_n = 1{,}694$ kN。

5. 關鍵爭議點與進階探討 (Critical Issues & Advanced Discussion)

①「均佈的雙向彎矩」的解讀——本題唯一的實質爭議：

原卷文字為「梁全長承受均佈的雙向彎矩 $M_{ux}=400$ kN-m 及 $M_{uy}=50$ kN-m（兩彎矩均已含載重係數且均作用在梁之剪力中心）」。兩種解讀：

解讀 依據 彎矩圖 $C_b$ $\phi_bM_{nx}$ 互制比
(甲) 均勻彎矩（主答） 「均佈」修飾「彎矩」；彎矩「作用在剪力中心」＝施加彎矩；題目給 $C_b$ 公式即為驗證得 1.0 矩形（定值） 1.0 945.8 0.715
(乙) 均佈載重之最大彎矩 「均佈」慣用於載重；$M_{ux}$、$M_{uy}$ 為跨中最大值 拋物線 1.136 1074.4 0.664

採 (甲) 為主答的三個理由：
1. 文法：「均佈的雙向彎矩」的中心語是「彎矩」，「均佈」是彎矩的性質 → 彎矩沿全長均勻。若為 (乙)，慣常寫法應是「梁全長承受均佈載重，所生之雙向彎矩為…」。
2. 「作用在梁之剪力中心」：這句話是在交代「無扭矩」，其主語是彎矩本身；施加彎矩才有「作用點」的說法，均佈載重則會寫「載重作用在剪力中心」。
3. 偏保守：$C_b = 1.0$ 給出較小的 $\phi_bM_{nx}$，設計上安全；且 $C_b = 1.0$ 正是 $C_b$ 定義的基準情形（均勻彎矩為 LTB 最不利型態）。

⚠️ 前版解析的錯誤論證：前版曾稱「簡支梁在簡支條件下不可能有常數彎矩（需要端力矩）」——此說法有誤。簡支梁兩端各施加等值同向的端彎矩，即產生沿全長為定值的彎矩圖（這正是 $C_b$ 定義與 LTB 基本理論所採用的標準情形，也是本題「一端鉸接、一端滾支承」＋「彎矩作用於剪力中心」所描述的狀態）。此錯誤論證已刪除。

結論：兩種解讀下互制比分別為 0.715 與 0.664，皆遠小於 1.0，「是否滿足設計要求」的答案不受影響。考場作答時寫明所採解讀即可；若時間允許，並列兩者最為穩妥。

②弱軸 $1.5F_y S_y$ 上限的規範依據與物理原因：

規範出處：台灣《鋼結構設計規範─極限設計法》第 6.6 節「對弱軸彎曲之 I 型斷面與槽型斷面」（對應 AISC Chapter F, Section F6）。

物理原因：I 型斷面繞弱軸彎曲時，兩片翼板幾乎承擔全部力矩。翼板的行為近似「兩塊獨立矩形板」，其形狀因數恰好為 1.5。若允許強度發展到 $F_y Z_y$，工作載重下翼板外緣將產生大範圍深度降伏，造成不可恢復的永久變形，故規範以 $1.5 F_y S_y$ 設定上限。

考場提醒： 即使題目未給此公式，$M_{ny} \leq 1.5 F_y S_y$ 屬於必須內化的規範常識——題目同時給出 $Z_y$ 和 $S_y$ 本身就是陷阱信號。$Z_y/S_y = 1.57 > 1.5$ 時若直接用 $F_y Z_y$，會高估弱軸強度，屬扣分項。（新版 AISC 360-10 起上限放寬為 $1.6 F_y S_y$，本題依 2014 年考試時點採 $1.5$）

③若 Lb > Lr（彈性 LTB）時的計算變化：
若 $L_b > L_r = 5.8$ m，則：$M_n = C_b \frac{\pi}{L_b}\sqrt{EI_yGJ + \left(\frac{\pi E}{L_b}\right)^2 I_y C_w} \leq M_p$
此時 $C_b$ 的效益更顯著，但需輸入 $GJ$ 和 $C_w$（題目未給），彈性 LTB 通常不是此題考點。

⑤題目給定 $\lambda_p = 9.19$、$\lambda_r = 22.3$ 的來源（可用於自我校核）：
這兩個數字是 AISC LRFD 1993 Table B5.1 的英制式，代入 Gr.50（$F_y = 50$ ksi、$F_r = 10$ ksi）：
$$\lambda_p = \frac{65}{\sqrt{F_y}} = \frac{65}{\sqrt{50}} = 9.19 \ \checkmark \qquad \lambda_r = \frac{141}{\sqrt{F_y - F_r}} = \frac{141}{\sqrt{40}} = 22.29 \ \checkmark$$
兩者完全吻合，可反證題目採 AISC LRFD 1993 體系。（附註：題目另給 $F_r = 78$ MPa $= 11.3$ ksi，與 $\lambda_r$ 所隱含的 10 ksi 略有出入，屬原卷單位換算的小瑕疵；$M_r$ 應依題目明文給的 78 MPa 計算。）
另以公制對照：$\lambda_p = 0.38\sqrt{E/F_y} = 0.38\sqrt{205{,}000/350} = 9.20$，同樣吻合。

④實務上的側向支撐設計建議：
本題梁因 $L_b = 4$ m = $2L_p$，LTB 已削減強度。若在梁中點加設側向支撐，則 $L_b$ 減半為 2 m = $L_p$，可達全塑性強度 $\phi_b M_p = 0.9 \times 1267.5 = 1140.8$ kN-m；強軸利用率由 42.3% 降至 35.1%，互制比由 0.715 降至 0.643。一支中間側撐即讓強軸強度提升 20.6%，這是 LTB 題型最重要的實務啟示。
