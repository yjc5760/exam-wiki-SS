📐 核心公式速查

Type A 壓力桿件—挫屈強度

LRFD（我國規範 AISC）
$\lambda_c = \dfrac{KL}{r\pi}\sqrt{\dfrac{F_y}{E}}$
$\lambda_c \leq 1.5$：$F_{cr} = 0.658^{\lambda_c^2} F_y$（非彈性）
$\lambda_c > 1.5$：$F_{cr} = \dfrac{0.877}{\lambda_c^2} F_y$（彈性）
$\phi_c P_n = 0.85 \cdot F_{cr} \cdot A_g$
ASD（舊規範）
$C_c = \sqrt{\dfrac{2\pi^2 E}{F_y}}$（彈性/非彈性界限細長比）
$KL/r \leq C_c$：$F_a = \dfrac{\left[1 - \dfrac{(KL/r)^2}{2C_c^2}\right]F_y}{F.S.}$，$F.S. = \dfrac{5}{3}+\dfrac{3(KL/r)}{8C_c}-\dfrac{(KL/r)^3}{8C_c^3}$
$KL/r > C_c$：$F_a = \dfrac{12\pi^2 E}{23(KL/r)^2}$
⚠ 殘留應力（Fr = 0.3Fy）會降低非彈性挫屈強度 → 柱強度曲線低於理想值
⚠ 切線模數 Et < E（非彈性區間）→ 真實挫屈載重低於 Euler 值

Type B 壓力桿件—有效長度 K

對位圖（Alignment Chart）G 值計算
$G = \dfrac{\sum (I_c/L_c)}{\sum (I_g/L_g)}$（柱與梁之剛度比）
端部條件：固接 G=1（理論）；鉸接 G=10；自由 G=∞
查圖：無側移構架左圖；有側移構架右圖
LeMessurier 公式（側移構架精確法）
$K = \sqrt{\dfrac{1.6\,G_1 G_2 + 4(G_1+G_2)+7.5}{G_1+G_2+7.5}}$
靠柱效應修正：$K_i^2 = \dfrac{\pi^2 E I_i}{L_i^2} \cdot \dfrac{P_{crit}}{P_i}$（系統挫屈）
ASD 非彈性修正（τa 折減）
當 $\dfrac{P_u}{P_y} > 0.5$：$G^* = \tau_a \cdot G$，$\tau_a = \dfrac{4(P_u/P_y)[1-(P_u/P_y)]}{1}$
以修正後 G* 查對位圖
⚠ 對位圖假設所有梁承受均勻載重（無遠端抵抗）→ 實際上偏保守
⚠ LeMessurier 公式考慮靠柱效應，適合不規則框架

Type C 拉力桿件—淨截面 / 剪力遲滯

LRFD 三種破壞模式
① 全斷面降伏：$\phi_t P_n = 0.9 F_y A_g$
② 淨截面斷裂：$\phi_t P_n = 0.75 F_u A_e$，$A_e = U \cdot A_n$
③ 塊狀剪力：$\phi R_n = 0.75(0.6F_u A_{nv} + U_{bs} F_u A_{nt})$
上限：$0.75(0.6F_y A_{gv} + U_{bs} F_u A_{nt})$
剪力遲滯係數 U（常用值）
連接所有板件：$U = 1.0$
W 型鋼翼板接合（$b_f \geq 2d/3$）：$U = 0.9$；否則 $U = 0.85$
一般情況：$U = 1 - \bar{x}/L$（$\bar{x}$ 為形心至接觸面距離，$L$ 為連接長度）
縱向銲接 $L \geq 2w$：$U=1.0$；$w \leq L < 2w$：$U=0.87$；$L < w$：$U=0.75$
ASD
全面積降伏：$P_{all} = 0.6 F_y \cdot A_g$
淨截面斷裂：$P_{all} = 0.5 F_u \cdot A_e$
⚠ U 值取計算值與查表值之較大者
⚠ 螺栓孔面積：$A_n = A_g - \sum (d_h + 3.2) \cdot t$（孔徑加 3.2 mm）

Type D 複合柱 / SRC

有效材料性質（包覆型 SRC）
$F_{my} = F_y + 0.85f'_c\dfrac{A_c}{A_s} + F_{yr}\dfrac{A_r}{A_s}$
$E_m = E_s + 0.4E_c\dfrac{A_c}{A_s}$
其中：$A_s$ 鋼材面積、$A_c$ 混凝土面積、$A_r$ 鋼筋面積
使用限制
鋼材面積 $A_s \geq 4\%$ 總面積（AISC 規定）
鋼骨承擔載重 = $\phi_c P_n = 0.85 F_{cr} A_s$（$F_{cr}$ 以 $F_{my}$、$E_m$ 計算 $\lambda_c$）
組合柱（鋼構件拼合）
$r_{min} = \sqrt{\dfrac{I_{total}}{A_{total}}}$（以平行軸定理疊加各構件）
ASD 判斷彈性/非彈性：比較 $KL/r$ 與 $C_c = \sqrt{2\pi^2 E/F_{my}}$
⚠ 混凝土 Ec 不是 Es；別混用
⚠ 複合柱 Cc 要用 Fmy（不是 Fy）計算
📋 考題清單
⚠️ 高頻陷阱 Top 8
陷阱 01 · Type A
λc 分界點記錯（1.5 不是 1.0）
非彈性與彈性挫屈的分界是 λc = 1.5，對應 KL/r ≈ 133（Fy=250 MPa）。常見錯誤是誤用 λc = 1.0 或直接套 Cc。
考題：SS-2014-1、SS-2018-2
陷阱 02 · Type A
ASD Cc 計算時忘記 Fmy（複合柱）
一般壓力柱 Cc 用 Fy；複合柱或 SRC 則需用 Fmy 計算臨界細長比。兩者公式相同但代入值不同，考題中常陷阱。
考題：SS-2015-3、SS-2003-1
陷阱 03 · Type B
對位圖端部條件設錯（固接 G=1，非 G=0）
理論固接端 G=0，但設計上取 G=1.0（有限剛度假設）；理論鉸接端 G=∞，設計取 G=10。直接代 G=0 或 G=∞ 會讀到不合理的 K 值。
考題：SS-2023-1、SS-2007-4、SS-2011-4
陷阱 04 · Type B
LeMessurier 公式：只算單柱忘記靠柱效應
側移構架中，各柱的挫屈互相影響（靠柱效應）。弱柱依賴強柱提供側向束制，系統挫屈載重 ΣPcr 需全樓層計算，不能只算單柱。
考題：SS-2008-2、SS-2011-2、SS-2013-2
陷阱 05 · Type C
螺栓孔扣除面積多加 3.2 mm（孔比螺栓大）
計算淨截面積時，孔徑 = 螺栓標稱直徑 + 1.6 mm（沖孔）；在計算 An 時再額外加 1.6 mm 損傷，共加 3.2 mm。不加或少加均常見失誤。
考題：SS-2022-2、SS-2005-1
陷阱 06 · Type C
U 值選錯（銲接 vs 螺栓接合規則不同）
縱向銲接 U 值依銲道長度 L 與銲件寬度 w 的比值查表（1.0 / 0.87 / 0.75）；螺栓接合則用 $\bar{x}/L$ 公式或翼板/腹板接合類型查表。兩者不能混用。
考題：SS-2025-2、SS-2024-2、SS-2015-2
陷阱 07 · Type C
塊狀剪力面判斷錯誤（哪個路徑控制）
塊狀剪力有兩個可能破壞面，需各自計算後取最小值。常見錯誤是只算一個面，或搞錯剪力面（Anv）與拉力面（Ant）的方向。
考題：SS-2015-2、SS-2005-1、SS-2003-1
陷阱 08 · Type D
複合柱 Fmy 中 Ec 代入 Es（單位混淆）
Em 公式中的 0.4Ec 是混凝土彈性模數（Ec ≈ 4700√f'c MPa），不是鋼材 Es。混淆後 Em 會嚴重偏大，λc 偏小，導致設計強度誇大。
考題：SS-2003-2、SS-2010-3
🎯 備考優先序
SS-U1-1 是全科出題頻率最高的子項之一，歷年幾乎每年必考 1～2 題。建議以 Type A（LRFD λc 計算）和 Type C（拉力桿件剪力遲滯）為核心，再補強 Type B（K 值對位圖）。
