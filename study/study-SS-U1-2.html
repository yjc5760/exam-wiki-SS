④ 核心公式速查
LTB 分界長度（LRFD）
$$L_p = 1.76\, r_y \sqrt{\frac{E}{F_y}}$$
$$L_r = r_x \frac{X_1}{F_y - F_r}\sqrt{1 + \sqrt{1 + X_2(F_y-F_r)^2}}$$
$X_1 = \dfrac{\pi}{S_x}\sqrt{\dfrac{EGJA}{2}}$，$X_2 = \dfrac{4C_w}{I_y}\left(\dfrac{S_x}{GJ}\right)^2$
$F_r = 11.5\text{ ksi}$（熱軋），$F_r = 16.5\text{ ksi}$（銲接組合）
LTB 彎矩強度 Mn
$L_b \le L_p$：$M_n = M_p = F_y Z_x$
$L_p < L_b \le L_r$：$M_n = C_b\!\left[M_p - (M_p-M_r)\frac{L_b-L_p}{L_r-L_p}\right] \le M_p$
$L_b > L_r$：$M_n = C_b M_{cr} \le M_p$
$M_r = (F_y - F_r)S_x$，$\phi_b = 0.90$
Cb 彎矩梯度係數
$$C_b = \frac{12.5 M_{max}}{2.5 M_{max} + 3M_A + 4M_B + 3M_C}$$
$M_A$、$M_C$：未支撐段 1/4、3/4 點彎矩
$M_B$：中點彎矩（取絕對值）
常用值：均布單跨 $C_b \approx 1.14$；集中中點 $C_b \approx 1.32$
懸臂梁：$C_b = 1.0$（保守）
斷面強度 Mp / My
$M_p = F_y Z_x$（塑性力矩）
$M_y = F_y S_x$（降伏力矩）
$f = Z_x / S_x$（形狀因子，H型鋼 ≈ 1.12）
等面積法求 PNA：上半斷面面積 = 下半斷面面積
$Z_x = A_{上} \cdot \bar{y}_{上} + A_{下} \cdot \bar{y}_{下}$
寬厚比（LRFD 結實）
翼板（H型鋼）：$\lambda_p = 0.38\sqrt{E/F_y}$，$\lambda_r = 0.83\sqrt{E/(F_y-F_r)}$
腹板：$\lambda_p = 3.76\sqrt{E/F_y}$，$\lambda_r = 5.70\sqrt{E/F_y}$
$\lambda = b_f/(2t_f)$（翼板）；$\lambda = h/t_w$（腹板）
結實：$\lambda \le \lambda_p$ → 可達 $M_p$
非結實：$\lambda_p < \lambda \le \lambda_r$ → $M_n$ 線性折減
合成梁 PNA（LRFD）
完全合成：$\sum A_s F_y = 0.85 f'_c A_c$（混凝土壓碎控制）
PNA 在鋼梁中：$\sum F_{上} = \sum F_{下}$（等面積原則）
$M_n = \sum (F_i \cdot d_i)$（各力×到基準點力臂）
有效版寬：$b_{eff} = \min(L/8 \times 2, s, 邊距)$
SRC：鋼骨 + 鋼筋 + 混凝土共同承壓
板梁 剪力強度（LRFD）
$V_n = 0.6 F_y A_w C_v$
張力場效應（有加勁板）：$V_n = 0.6F_yA_w\!\left[C_v + \dfrac{1-C_v}{1.15\sqrt{1+(a/h)^2}}\right]$
$C_v$：剪力挫屈係數（依 h/tw 分三段）
$a$：加勁板間距；$h$：腹板有效高度
使用性撓度
均布載重：$\delta = \dfrac{5wL^4}{384EI}$
集中中點：$\delta = \dfrac{PL^3}{48EI}$
限制：$\delta_{活載} \le L/360$；$\delta_{全} \le L/240$
規範為使用限制，不計 $\phi$ 係數
選梁時可先估 $I \ge 5wL^4/(384E \cdot L/360)$
ASD 梁設計（參考）
$F_b = 0.66 F_y$（有完整側撐，結實斷面）
$F_b = 0.60 F_y$（僅滿足最基本側撐）
ASD LTB 判斷：$l/r_T$ 或 $l/b_f$ vs $L_c$、$L_u$
$l$：未支撐長度；$r_T$：受壓翼板 + 腹板 1/3 壓縮區的迴轉半徑

⑥ 高頻陷阱 Top 10
🔄 Cb 值套錯公式
Cb 分子是 12.5（非 12），$M_A$、$M_C$ 是 1/4、3/4 點而非端點。懸臂梁要用 $C_b = 1.0$，不可用公式計算。
常見題：SS-2008-3、SS-2011-3
🔄 Mn 忘記與 Mp 取較小值
非彈性 LTB 公式 $C_b[\cdots] \le M_p$，彈性 LTB $C_b M_{cr} \le M_p$。加了 Cb 後可能超過 Mp，必須截斷！
常見題：SS-2012-1、SS-2007-3
🔄 Fr 殘留應力值混淆
熱軋型鋼 $F_r = 10\text{ ksi}$（LRFD 1st），有時規範更新為 $11.5\text{ ksi}$。銲接組合斷面 $F_r = 16.5\text{ ksi}$（較大）。
常見題：SS-2025-1、SS-2012-1
💡 λp / λr 判斷翼板用 bf/2tf
翼板寬厚比 $\lambda = b_f/(2t_f)$（半翼板），腹板用 $h/t_w$（全腹板）。常見錯誤：翼板忘記除以 2。
常見題：SS-2016-1
📐 非對稱斷面 PNA ≠ 幾何中心
PNA 用等面積法（上半 = 下半面積），不是幾何形心。$Z_x = A_{上}\bar{y}_{上} + A_{下}\bar{y}_{下}$（各到 PNA 的力臂）。
常見題：SS-2023-3、SS-2009-3
🔗 合成梁有效版寬計算
$b_{eff}$ = min(跨度/8×2，梁中心距，邊梁到板邊) — 要核算哪個控制，不可只取一種。
常見題：SS-2019-2、SS-2005-2
🔄 ASD 中 Lc 與 Lu 的定義
$L_c$：維持 $F_b=0.66F_y$ 的最大未支撐長；$L_u$：維持 $F_b=0.60F_y$ 的最大長。超過 Lu 才用 $rT$ 公式。
常見題：SS-2002-2、SS-2008-1
📋 張力場效應只適用於有加勁板
板梁腹板加了中間加勁板後才能計張力場效應（桁架式拉力帶）。端部加勁板格 (end panel) 不得用張力場公式。
常見題：SS-2006-4
↕️ 撓度限制：活載與全載重
L/360 為活載重撓度限制，L/240（或 L/180）為全載重。不可混用。選梁時先用活載重 I 值，再用全載重驗算。
常見題：SS-2010-4、SS-2015-1
🔄 雙向彎曲互制公式
$\dfrac{M_{ux}}{\phi M_{nx}} + \dfrac{M_{uy}}{\phi M_{ny}} \le 1.0$（梁的雙向彎曲）。注意弱軸無 LTB（對稱斷面），$M_{ny} = M_{py}$。
常見題：SS-2014-3
