④ 核心公式速查
ASD 互制方程式（fa/Fa > 0.15）
$$\frac{f_a}{F_a} + \frac{C_{mx}f_{bx}}{\left(1-\dfrac{f_a}{F'_{ex}}\right)F_{bx}} + \frac{C_{my}f_{by}}{\left(1-\dfrac{f_a}{F'_{ey}}\right)F_{by}} \le 1.0$$
強度驗算（同時）：$\dfrac{f_a}{0.6F_y} + \dfrac{f_{bx}}{F_{bx}} + \dfrac{f_{by}}{F_{by}} \le 1.0$
$F'_e = \dfrac{12\pi^2 E}{23(KL/r)^2}$（對應方向歐拉應力）
$f_a/F_a \le 0.15$ 時：直接線性疊加
$C_m$ 係數
無側移（有端點彎矩）：$C_m = 0.6 - 0.4\dfrac{M_1}{M_2}$
側移構架：$C_m = 0.85$
有橫向載重（無端部約束）：$C_m = 1.0$
$M_1/M_2$：小/大端彎矩比（同向曲率取正，反向取負）
雙曲率（反向）時 $M_1/M_2 < 0$，$C_m < 0.6$（有利）
LRFD P-M 互制（Chapter H）
$\dfrac{P_u}{\phi_c P_n} \ge 0.2$：$\quad\dfrac{P_u}{\phi_c P_n} + \dfrac{8}{9}\!\left(\dfrac{M_{ux}}{\phi_b M_{nx}} + \dfrac{M_{uy}}{\phi_b M_{ny}}\right) \le 1.0$
$\dfrac{P_u}{\phi_c P_n} < 0.2$：$\quad\dfrac{P_u}{2\phi_c P_n} + \left(\dfrac{M_{ux}}{\phi_b M_{nx}} + \dfrac{M_{uy}}{\phi_b M_{ny}}\right) \le 1.0$
$\phi_c = 0.85$（壓力）；$\phi_b = 0.90$（彎矩）
弱軸對稱斷面：$M_{ny} = M_{py} = F_y Z_y$（無 LTB）
B1 放大係數（P-δ 效應）
$$B_1 = \frac{C_m}{1 - \alpha P_r / P_{e1}} \ge 1.0$$
$P_{e1} = \dfrac{\pi^2 EI}{(K_1 L)^2}$（對應方向，$K_1$ 取無側移值 $\le 1.0$）
$\alpha = 1.0$（LRFD）；$\alpha = 1.6$（ASD）
$M_u = B_1 M_{nt} + B_2 M_{lt}$（含側移時）
$B_1 \ge 1.0$，若計算值 < 1.0 取 1.0
B2 放大係數（P-Δ 效應）
$$B_2 = \frac{1}{1 - \dfrac{\alpha \sum P_r}{\sum P_{e2}}} \ge 1.0$$
$\sum P_{e2} = \dfrac{\pi^2 EI}{(KL)^2}$（有側移，K 用對位圖求）
$\sum P_r$：同層所有柱的設計軸力總和
$\sum P_{e2}$：同層所有柱的有側移彈性挫屈載重總和
斜撐構架：通常 $M_{lt} = 0$，$B_2$ 不起作用
有效長度係數 K
對位圖：$G = \dfrac{\sum(I_c/L_c)}{\sum(I_g/L_g)}$（柱端約束比）
特殊邊界：固接端 $G = 1.0$（建議）；鉸接端 $G = 10$（或取 $\infty \to G = 10$）
無側移構架（斜撐）：$K \le 1.0$
有側移構架（剛架）：$K \ge 1.0$
簡化保守：無側移取 $K=1.0$；有側移需用對位圖
直接分析法（DAM，AISC Ch. C）
剛度折減：$EI^* = 0.8\tau_b EI$，$EA^* = 0.8EA$
$\tau_b = 1.0$（$\alpha P_r \le 0.5P_y$）；$\tau_b < 1.0$（軸壓較大時）
假想水平力：$N_i = 0.002 \alpha Y_i$（每層）
DAM 中 $K=1.0$（不需對位圖），以折減剛度 + 初始不完美替代
LRFD：$\alpha=1.0$；ASD：$\alpha=1.6$
與 B1B2 法主要差別：K 值不同、剛度修正方式不同
柱強度 Fa（ASD）與 φcPn（LRFD）
ASD：$F_a = \left[\dfrac{1-(KL/r)^2}{2C_c^2}\right]F_y / FS$（$KL/r \le C_c$）
LRFD：$F_{cr} = \left[0.658^{\lambda_c^2}\right]F_y$（$\lambda_c \le 1.5$）
$\lambda_c = \dfrac{KL}{r\pi}\sqrt{\dfrac{F_y}{E}}$，$\phi_c = 0.85$
$C_c = \pi\sqrt{2E/F_y}$（彈塑性分界細長比）
$KL/r > C_c$ 時（彈性）：$F_a = 12\pi^2 E / (23(KL/r)^2)$
⑤ 考題清單
⑥ 高頻陷阱 Top 8
📐 ASD：穩定方程式與強度方程式要同時驗算
fa/Fa > 0.15 時，必須同時驗算兩個方程式，取不利者。許多人只算穩定方程式就停，忘記強度方程式 $f_a/(0.6F_y) + f_{bx}/F_{bx} + f_{by}/F_{by} \le 1.0$ 也要滿足。
常見題：SS-2003-4、SS-2008-4
📐 F'e 的 KL/r 方向要正確
$F'_{ex}$ 用強軸（x方向）的 $(KL/r)_x$ 計算，$F'_{ey}$ 用弱軸。加了彎矩在哪個方向，放大係數就用對應方向的歐拉應力，方向不能搞混。
常見題：SS-2007-2、SS-2019-3
📐 Cm 符號：反向彎矩（雙曲率）M₁/M₂ 為負
$C_m = 0.6 - 0.4(M_1/M_2)$，單曲率（同方向）$M_1/M_2 > 0$ → $C_m < 0.6$；雙曲率（反向）$M_1/M_2 < 0$ → $C_m > 0.6$。反向曲率對穩定有利（$C_m$ 較小），別弄反了。
常見題：SS-2004-4
🔵 LRFD：H1-1a/H1-1b 門檻值判斷
$P_u/\phi_c P_n \ge 0.2$ 用 H1-1a（彎矩係數 8/9）；$< 0.2$ 用 H1-1b（軸力係數除以2）。先求比值再選公式，不可兩個都算取大。
常見題：SS-2012-3、SS-2020-3
🔵 B1 放大只作用於 Mnt，B2 作用於 Mlt
$M_u = B_1 M_{nt} + B_2 M_{lt}$。$M_{nt}$：假設無側移的分析彎矩；$M_{lt}$：側移引起的彎矩。斜撐構架通常 $M_{lt} = 0$，$B_2$ 不起作用；剛架才需要算 $B_2$。
常見題：SS-2013-4、SS-2014-4
🔷 B2 計算：ΣPr 是全層，Pe2 也是全層
$B_2$ 分子 $\alpha\sum P_r$ 是同層所有柱的設計軸力總和，$\sum P_{e2}$ 也是全層彈性挫屈載重之和，不是單根柱子的值。
常見題：SS-2013-4
🔷 對位圖 G 值：固接端取 1.0，鉸接端取 10
理論上固接端 $G = 0$，鉸接端 $G = \infty$，但規範建議：固接端用 $G = 1.0$（考慮基礎轉動），鉸接端用 $G = 10$（避免 K 趨向無窮大）。
常見題：SS-2013-4
💡 直接分析法 DAM：α 在 ASD 是 1.6
DAM 假想水平力 $N_i = 0.002 \alpha Y_i$，LRFD 的 $\alpha = 1.0$，ASD 的 $\alpha = 1.6$。剛度折減也一樣：$EI^* = 0.8\tau_b EI$。ASD 用 DAM 時載重係數不能忘。
常見題：SS-2011-1
