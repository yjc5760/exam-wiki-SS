## 題幹摘要

型鋼桿件中若存在殘餘應力可能導致桿件軸向壓力強度下降。在無殘餘應力之理想狀態下，桿件之挫屈強度曲線可由 $\dfrac{F_{cr}}{F_y}$ 對應 $\lambda = \dfrac{KL}{\pi r}\sqrt{\dfrac{F_y}{E}}$ 如圖 (a) 所示。

試考慮一斷面為 **RH400×400×13×21** 之受壓桿件，假設其斷面因製程過程所導致之殘餘應力分布如圖 (b) 所示，包含**殘餘壓應力 $0.5F_y$** 及**殘餘拉應力 $0.4F_y$**。假設其鋼材之應力–應變關係為**完全彈塑性**（圖 c），而斷面之慣性矩 $I_x = 66{,}600$ cm⁴、$I_y = 22{,}400$ cm⁴。

針對此具殘餘應力影響之受壓桿件，繪製該斷面**強軸（$x$ 軸）挫屈方向**之挫屈強度曲線圖（$\dfrac{F_{cr}}{F_y}\sim\lambda$ 圖），圖中須標註**曲線之函數方程式**，並標註圖中**轉折點之坐標數值**。（25 分）

**殘餘應力分布（圖 b，單位 mm）：**

| 部位 | 寬度／高度 | 殘餘應力 |
|:---|:---|:---|
| 上、下翼板**外側兩端** | 各 113.5 mm（共 4 塊） | $-0.5F_y$（壓） |
| 上、下翼板**中央段** | 173 mm | $+0.4F_y$（拉） |
| **腹板**（全高） | $400 - 2(21) = 358$ mm | $+0.4F_y$（拉） |

*自平衡驗算：* 翼板 $2 \times 21 \times [2(113.5)(-0.5) + 173(+0.4)] = -1{,}861$ mm²·$F_y$；腹板 $358 \times 13 \times (+0.4) = +1{,}862$ mm²·$F_y$，合計 $\approx 0$ ✓（確認題目給的分布是自平衡的）

**參考公式（考卷提供，並註明「僅供參考應自負確認與勘誤責任」）：**

$$\lambda = \frac{KL}{\pi r}\sqrt{\frac{F_y}{E}},\qquad \frac{F_{cr}}{F_y} = \frac{1}{\lambda^2},\quad \frac{F_{cr}}{F_y} = 1-\frac{\lambda^2}{4},\quad \frac{F_{cr}}{F_y} = 0.658^{\lambda^2},\quad \frac{F_{cr}}{F_y} = \frac{0.877}{\lambda^2}$$

*圖說：圖(b) RH400×400×13×21 斷面（$x$ 軸為強軸、水平；$y$ 軸為弱軸、垂直），翼板寬 400 mm 分為 113.5＋173＋113.5 三段，外側兩段標 $-0.5F_y$（壓）、中央段標 $+0.4F_y$（拉）；腹板側面亦標 $+0.4F_y$（拉）。圖(a) 為理想（無殘餘應力）曲線：$\lambda \le 1.0$ 時 $F_{cr}/F_y = 1.0$ 之水平段，$\lambda > 1.0$ 轉為 $F_{cr}/F_y = 1/\lambda^2$ 之 Euler 雙曲線，轉折點在 $(1.0,\ 1.0)$。圖(c) 為完全彈塑性（elastic–perfectly plastic）應力–應變圖，到 $\varepsilon_y$ 後應力恆為 $F_y$。*

## 核心考點

**核心觀念：完全彈塑性 ＋ 塊狀殘餘應力 ⇒ 有效慣性矩「階梯式」驟降 ⇒ 強度曲線出現一段「強度平台」。**

推導鏈：

```
殘餘壓應力 0.5Fy
  → 平均應力達 0.5Fy 時，外側 4 塊「同時」降伏（塊狀分布的特徵）
  → 完全彈塑性 ⇒ 降伏區 Et = 0 ⇒ 有效慣性矩 Ie = Ix − ΔI(外側4塊)
  → 非彈性挫屈 Fcr = π²E·Ie /[A(KL)²] ⇒ Fcr/Fy = (Ie/Ix)/λ²
  → 每個分支只在「與自身假設一致」的應力區間內成立
  → 兩分支都不成立的區間 ⇒ 強度被鎖在 0.5Fy（平台段）
```

**出題者測驗重點：**

1. 由殘餘壓應力 $0.5F_y$ 判出**比例限 $F_p = 0.5F_y$**，並算出對應的 $\lambda = \sqrt{2}$
2. 由「強軸」二字判斷降伏區在翼板**外側**（對 $I_x$ 貢獻大，$\propto$ 寬度 × 力臂²），使 $I_e/I_x$ 掉到約 0.49
3. **每個分支的有效區間**：這是本題真正的難點（見 §5.1），也是最容易寫錯的地方
4. 圖上要標函數式與轉折點座標（**三個**轉折點）

## 解題關鍵步驟

**作戰計畫：**
```
Step 1  比例限：F + 0.5Fy = Fy → Fp = 0.5Fy → 彈性分支下界 λ = √2
Step 2  有效慣性矩：Ie = Ix − 4·ΔI(外側塊) → Ie/Ix ≈ 0.485
Step 3  非彈性分支：Fcr/Fy = 0.485/λ²，僅在 Fcr ≥ 0.5Fy 成立 → λ ≤ 0.985
Step 4  壓潰上限：Fcr/Fy ≤ 1.0 → λ ≥ 0.697 才進入非彈性分支
Step 5  0.985 < λ < 1.414 兩分支皆不成立 → Fcr = 0.5Fy 平台段
Step 6  繪四段曲線 + 標三個轉折點座標
```

**陷阱分析：**

| 陷阱 | 說明 | 對策 |
|------|------|------|
| ❶ **誤畫成「不連續跳躍」** | 若把非彈性分支硬拉到 $\lambda=\sqrt2$，會得到 $0.485/2 = 0.243$，比同點的彈性值 0.5 還低，形成「$\lambda$ 變大、強度反而變大」的跳躍——**物理上不可能**（柱做長不會變強） | 各分支只在與自身假設相容的區間成立；中間以**平台段** $F_{cr} = 0.5F_y$ 銜接 |
| ❷ 非彈性段公式來源 | 需從 Euler 式代換 $I_e$：$F_{cr} = \pi^2EI_e/[A(KL)^2]$，除以 $F_y$ 後化為 $(I_e/I_x)/\lambda^2$ | $\lambda$ 的定義用**實際** $r = \sqrt{I_x/A}$，故比值出現在分子 |
| ❸ 強軸 vs 弱軸算法不同 | 強軸：$\Delta I \approx b_{out}t_f\bar y_f^2$（力臂主導，$\propto$ 寬度一次方）；弱軸：$\propto$ 寬度三次方，$I_e/I_y$ 會掉到約 0.08 | 本題只問強軸；弱軸僅供比較（§5.4） |
| ❹ 中央翼板與腹板會不會降伏 | 兩者殘餘應力為 $+0.4F_y$（拉），需外加 $1.4F_y > F_y$ 才降伏 → **全程保持彈性** | 有效斷面 = 中央翼板 ＋ 全腹板（＋圓弧填角） |
| ❺ 誤用 $1-\lambda^2/4$ 當答案 | 考卷列的 $1-\lambda^2/4$ 是 CRC 經驗拋物線（隱含**線性**殘餘應力分布），與本題**塊狀**分布不同 | 本題須自行推導；CRC 曲線僅作對照（§5.3） |

## 4. 步驟化詳細計算過程 (Step-by-Step Detailed Calculation)

> 📊 互動圖：[柱強度曲線（含殘餘應力）SS-2024-1-column-curve-viz.html](SS-2024-1-column-curve-viz.html)

### 步驟一：確定降伏啟始應力（比例限）

翼板外側 4 塊之殘餘應力為 $-0.5F_y$（壓）。外加平均壓應力 $F$ 時，該處總應力 $= F + 0.5F_y$，達 $F_y$ 即降伏：

$$F + 0.5F_y = F_y \quad \Rightarrow \quad \boxed{F_p = 0.5F_y}$$

**塊狀分布的關鍵特徵：** 外側 4 塊的殘餘應力**均勻**為 $-0.5F_y$，因此在 $F = 0.5F_y$ 這一瞬間**整塊同時降伏**（不像拋物線分布是由邊緣逐步向內推進）。

**中央翼板與腹板：** 殘餘應力 $+0.4F_y$（拉），降伏需 $F = F_y + 0.4F_y = 1.4F_y > F_y$，在軸壓下**永不降伏**，全程保持彈性。

---

### 步驟二：計算有效慣性矩 $I_e$（強軸）

| 參數 | 數值 |
|:---|:---|
| $b_{out}$ | 11.35 cm |
| $t_f$ | 2.1 cm |
| $A_{out} = b_{out}t_f$ | 23.84 cm² |
| $\bar y_f = (H - t_f)/2$ | $(40 - 2.1)/2 = 18.95$ cm |

單一外側塊對 $x$ 軸的慣性矩貢獻：

$$\Delta I_{one} = \frac{b_{out}t_f^3}{12} + A_{out}\bar y_f^{\,2} = \frac{(11.35)(2.1)^3}{12} + 23.84(18.95)^2 = 8.8 + 8{,}559 = 8{,}568 \ \text{cm}^4$$

4 塊（上下翼板 × 左右兩側）合計扣除：

$$\Delta I = 4 \times 8{,}568 = 34{,}272 \ \text{cm}^4$$

$$\boxed{I_e = I_x - \Delta I = 66{,}600 - 34{,}272 = 32{,}328 \approx 32{,}330 \ \text{cm}^4}$$

$$\boxed{\frac{I_e}{I_x} = \frac{32{,}330}{66{,}600} = 0.485}$$

> **策略註解：** 用**題目給的** $I_x = 66{,}600$ 扣除降伏塊，而非自行重算全斷面。理由：翼腹交會的圓弧填角位於中央（未降伏）區、全程有效，用給定值扣除才能把它留下來。
> *驗算：* 若完全忽略填角、純以三片矩形板計算，$I_{x,\text{geom}} = 65{,}362$、$I_{e,\text{geom}} = 31{,}090$，比值 $0.476$——與 0.485 相差 2%，不影響曲線形狀與結論。
