## 分歧明細（依嚴重度排序）

### 1. SS-2008-3　外三分之一跨均佈載重 — 載重範圍看錯
- **舊解：** 均佈 w 作用於**全跨**，跨中 Mu = 40.5w；BC 段 Cb 以 1.75 + 1.05 + 0.3 = 3.10 取 2.3 → Mn = Mp → **w = 2.50 t/m**
- **盲解：** 圖 2 的 w 只畫在 **AB、CD 兩段**（各 6 m），BC 段無載重 → M_B = M_C = 18w，**BC 段為均勻彎矩，Cb = 1.0**；Lb = 6 m > Lr = 5.80 m（Fr 取 0.7）→ 彈性 Mcr = 74.6 t·m 控制 → **w_n = 74.6/18 = 4.15 t/m**（φ 0.9 → 3.73）
- 舊解另有一處獨立錯誤：均勻彎矩段 M1/M2 = −1（單曲率），Cb 應為 1.0，不是 3.10
- **回考卷看：** 第 2 頁圖 2 上方載重箭頭範圍
- 不確定：題目未給 Fr；取 1.16 時 Lr = 6.56 m → 非彈性，w = 3.96 t/m

### 2. SS-2005-2　包覆型合成梁 — 混凝土強度單位錯 10 倍
- **舊解：** 0.85f'c 寫成 1.785 t/cm²（應為 0.1785）→ PNA c = 5.96 cm、鋼骨與上筋全部受拉 → **Mn = 170.3 t·m**
- **盲解：** 0.85 × 0.21 = 0.1785 t/cm² → PNA 距頂 **13.35 cm**（在上翼板下方），上筋與上翼板受壓 → **Mn = 135.5 t·m**、φMn = 121.9 t·m（扣除型鋼排開之混凝土 135.3）
- **回考卷看：** 第 1 頁第二題 f'c = 210 kgf/cm²

### 3. SS-2024-3　外伸梁 — 結構形式看錯
- **舊解：** 視為簡支梁、載重在跨中 C → **Mu = PL/4 = 21 t·m**；強軸 OK、弱軸 NG
- **盲解：** 圖中 A 鉸支、**C 為中間滾支**、**B 為外伸自由端受 P** → **Mu = 14 × 3 = 42 t·m**（C 點負彎矩）；Lb = 6 m（只有 A、B 有側向及扭轉支撐，C 無面外束制）、Cb = 1.316（巧合與舊解相同）；強軸 φMn = 65.6 ≥ 42 OK，弱軸 φMn = 17.1 < 42 NG
- 結論方向相同，但需求彎矩差一倍，強軸餘裕由 3.1 倍變成 1.56 倍
- **回考卷看：** 第 3 頁圖 (a)(b) 支承位置與載重箭頭位置

### 4. SS-2021-3　耐震梁斷面選擇 — 選擇理由錯、Lr 代錯迴轉半徑
- **舊解：** 選 BH500×500×16×36，理由「ry 最大、LTB 區間最佳、**最輕**」；Lr 以 rT 代入得 2615 cm；改善為每 400 cm 一側撐
- **盲解：** BH500×500×16×36 的 A = 428 cm²，**不是最輕**（BH700×300×12×25 只有 228）；強軸受彎宜選深梁：**BH700×300×12×25**，Zx = 6,330、Mp = 221.6 t·m、f = 1.116；Lb = 12 m > Lr = 898 → 彈性 LTB，Cb 1.75 → Mcr 151.9 < Mp → 需加側撐（耐震梁 ≤ 0.086ryE/Fy = 352 cm，例每 3 m）→ Mn = Mp，塑性極限 wu = 11.66Mp/L² = 17.9 t/m
- 考卷公式 Lr = ryX1/FL·√(…) 用的是 **ry**，舊解改用 rT 不符考卷
- 選擇屬判斷題，兩種選擇都可能得分，但「最輕」為事實錯誤，必須更正；建議題解並列兩種斷面的比較，說明選擇依據
- 另發現題表 BH700×300×9×19 的 A = 156 與尺寸算得 173.6 不符（題目本身的數字錯誤）
- **回考卷看：** 第 2 頁表一與圖三側撐位置
