## 1. 為什麼拆

2026-08 至 2026-11-01 的勘誤裡，改變答案的錯誤多數是**讀錯題**，不是算錯：靠桿讀成鉸接（SS-2013-2）、單柱讀成三根柱（SS-2013-4）、全深讀成腹板高（SS-2005-4）、上下不對稱讀成對稱（SS-2010-1）、重述時自行加上題目沒問的要求（SS-2025-4、SS-2003-1）。
原本的題目重述寫在解析 `.md` 的 §1，和解答綁在一起，題意從來沒有被**單獨**驗證過。拆開後：

- 題意只驗一次、標「已確認」後凍結；解答勘誤不必再回頭懷疑題意。
- 盲解稽核可以只給 `problem.md`＋考卷原圖，不讓既有解答帶著走。
- 錯誤可分層：讀錯題改 `problem.md`（下游全部重驗）；算錯只改解析。

## 2. 檔案規格（試做版）

| 項目 | 規定 |
|------|------|
| 路徑 | `raw/solutions/SS-YYYY-N/SS-YYYY-N-problem.md`（與解析同資料夾；解析檔名不變，避免影響既有腳本與連結） |
| 頭表 | 考卷檔名與頁次、題號、考年、配分、附圖、**判讀狀態**（待確認／已確認＋日期） |
| §1 考卷原文 | 逐字轉錄（引用區塊），符號照考卷寫法，只把數學包成 LaTeX；不改字、不補字、不加詮釋 |
| §2 考卷給的公式、附表與參數 | 題內公式、全卷參考公式區、附表全部照錄；標明哪些屬他題；「考卷沒給什麼」也寫（例：公式集出現 $M_p$ 但不定義） |
| §3 附圖 | 引用既有證據圖 `fig-*.png`（不修改）＋圖面文字照錄；證據圖未涵蓋的內容（如表格）以 §2 文字為準 |
| §4 判讀清單 | 依 exam-solve 階段一第 4 步：項目｜判讀｜圖上／題文依據｜把握（確定／不確定）；**題目用字的意思**另標「解讀」 |
| 不寫的東西 | 解法、推得的中間量（必要時只註「推得值」，如腹板淨高）、規範條文、答案 |
| 讀法 | 依 exam-solve：一律轉圖目視（本科考卷多為 Adobe-CNS1 CID 字型，poppler 無語言包時連轉圖都缺字，改用 PyMuPDF）；全頁 110 dpi 盲讀，尺寸線端點等關鍵處 220–400 dpi 局部放大；盲讀完成後才比對既有解析 |
| 確認後 | 判讀狀態改「已確認（日期）」；之後要改須回考卷原圖並記 log |

渲染：`scripts/render_problem_view.py` 偵測到 `-problem.md` 時，在 `study/problems-view/<id>.html` 的解析之前放一個「📄 題目正本」區塊（未確認時標「待確認」）。
