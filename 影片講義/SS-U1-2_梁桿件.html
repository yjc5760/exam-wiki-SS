0一句話

這個單元所有的公式，其實都在回答同一個問題：這根梁，有沒有資格把塑性彎矩容量 \(M_p\) 用完？抓住這個問句，三道關卡、三個區段，都會自己排好隊。

（黑板：\(M_p\) ＝ 塑性彎矩容量（全斷面降伏）；三道關卡｜三個區段｜取最不利）

1為什麼會側扭

先看梁受彎的時候發生什麼事。彎矩把梁分成上壓下拉：

部位受力行為
上翼板受壓就像一根壓桿，想往側面挫屈
下翼板受拉張力把它拉得筆直，不肯動

可是兩片翼板被腹板綁在一起。上面想跑、下面不跑，斷面只好一邊側移、一邊扭轉，這就是側扭挫屈，LTB。

重點LTB ＝ 側移 ＋ 扭轉。所以抵抗 LTB，一定同時要有側向彎曲勁度 \(EI_y\)，以及扭轉勁度 \(GJ\) 和翹曲勁度 \(EC_w\)。

2逐級扣減

解題架構是一條流水線。斷面先給本錢：\(M_p = F_yZ_x\)，全斷面降伏。接著過兩道關卡：

站判斷問的是
斷面本錢\(M_p = F_yZ_x\)全斷面降伏
關卡一 FLB\(\lambda\) vs \(\lambda_p,\lambda_r\)板件會不會先皺（局部挫屈）
關卡二 LTB\(L_b\) vs \(L_p,L_r\)側撐夠不夠密（側扭挫屈）
設計強度\(\phi_bM_n\)取最不利 × 折減

關卡是串聯的，只要一關沒過，強度就打折，最後取最不利者，再乘 \(\phi_b = 0.90\)。關卡只會把 \(M_n\) 往下壓，永遠不會超過 \(M_p\)：

$$M_n \le M_p$$

另外還有剪力和撓度兩條獨立檢核，跟彎矩無關，但一樣會落選：剪力 \(V_n = 0.6F_yA_wC_v\)；使用性撓度 \(\delta \le L/360\)（服務載重）。

3本錢 Zx

先把本錢算對。

彈性 \(S_x\)塑性 \(Z_x\)
對應狀態最外緣剛好降伏全斷面降伏
應力分布三角形上下兩塊矩形
中性軸形心（ENA）等面積軸（PNA）
公式\(S_x = I_x/c,\ M_y = F_yS_x\)\(Z_x = \sum A_i\bar y_i,\ M_p = F_yZ_x\)

所以 \(Z_x\) 的算法是：塑性中性軸上下兩側的面積，各自對它取一次矩再相加，完全用不到 \(I_x\)。

重點對稱斷面兩個中性軸重合（ENA ＝ PNA）；非對稱斷面一定要分開算。
檢查H 型鋼強軸的 \(Z_x/S_x\) 大約 1.12，算完先拿它驗算。

4關卡一　局部挫屈

關卡一，寬厚比：翼板量一半，腹板量淨高。

翼板從腹板往兩側懸出，外緣是自由端，是懸臂板；腹板上下都被翼板夾住，是兩端支承板，\(h\) 是淨高，不含翼板厚：

$$\color{#c8553d}{\lambda_f = \frac{b_f}{2t_f}}\qquad \color{#3d7fb0}{\lambda_w = \frac{h}{t_w}}$$

邊界條件不同，限值差很多。\(F_y = 2.5\) 的時候，翼板 \(\lambda_{pf} \approx 10.9\)，腹板 \(\lambda_{pw} \approx 107\)（一邊自由 → 最易皺 → 限值嚴；兩邊夾住 → 寬鬆）。

最常見的錯\(b_f\) 忘了除以二：寬厚比變兩倍，結實斷面全被誤判成非結實。
區條件強度
結實 Compact\(\lambda \le \lambda_p\)板不會先皺，可以進第二關爭取 \(M_p\)
非結實\(\lambda_p < \lambda \le \lambda_r\)從 \(M_p\) 線性折減到 \(M_r\)
細長 Slender\(\lambda > \lambda_r\)彈性局部挫屈
重點翼板 \(\lambda_f\) 和腹板 \(\lambda_w\) 要分別檢核。

5關卡二　側扭挫屈

關卡二是全單元最核心的一張圖。橫軸是無側撐長度 \(L_b\)，縱軸是 \(M_n\)，\(L_p\) 和 \(L_r\) 把它切成三區。

區段條件\(M_n\)
① 塑性區\(L_b \le L_p\)\(M_n = M_p\)，不需要乘 \(C_b\)
② 非彈性 LTB ★最常考\(L_p < L_b \le L_r\)從 \(M_p\) 線性內插到 \(M_r\)，再乘 \(C_b\)
③ 彈性 LTB\(L_b > L_r\)\(M_n = C_bM_{cr}\)，再和 \(M_p\) 取小：\(\min(C_bM_{cr},\,M_p)\)

\(M_r\) 是怎麼來的？答案是殘留應力 \(F_r\)。軋製冷卻不均，翼板尖端本來就帶著壓應力，熱軋型取 0.7，銲接組合取 1.16 tf/cm²。外加應力只要 \(F_y - F_r\)，尖端就開始降伏，所以

$$M_r = (F_y - F_r)\,S_x$$

但殘留應力是自相平衡的，合力和合彎矩都是零。等到全斷面降伏，它就自行抵銷。所以 \(F_r\) 只進 \(M_r\) 和 \(L_r\)，絕對不影響 \(M_p = F_yZ_x\)。

重點看到題目給 \(F_r\)，就丟進 \(M_r\) 和 \(L_r\)，\(M_p\) 那一行不用理它。

6實算一次

實際跑一次。熱軋 H400×200×8×13，\(F_y = 2.5\)，側撐間距 4 m。

翼板寬厚比 7.69、腹板 46.8，都在限值內，結實斷面：

$$\lambda_f = 7.69 < 10.9,\qquad \lambda_w = 46.8 < 107\quad\text{結實}$$ $$M_p = 2.5(1286) = 3215\ \text{tf}\cdot\text{cm},\qquad M_r = (2.5-0.7)(1148) = 2067\ \text{tf}\cdot\text{cm}$$

\(L_p = 2.31\) m、\(L_r = 6.81\) m，\(L_b = 4.0\) m 落在 ② 非彈性區。內插：

$$M_n = 3215 - 1148\cdot\frac{400-231}{681-231} = 2784\ \text{tf}\cdot\text{cm}$$

均布載重 \(C_b = 1.14\)，乘完 3174，小於 \(M_p\) 3215，不必截頂。再乘 0.9：

$$C_bM_n = 1.14(2784) = 3174 < M_p = 3215\quad\text{不必截頂}$$ $$\phi_bM_n = 0.9(3174) = 2857\ \text{tf}\cdot\text{cm} = 28.6\ \text{tf}\cdot\text{m}$$
觀察\(C_b\) 幾乎把非彈性的折減全部補了回來。

7Cb 紅利

\(C_b\) 是彎矩梯度的紅利：同一根梁、同一個 \(L_b\)，彎矩圖越不飽滿，能撐的就越多。

彎矩圖\(C_b\)說明
兩端等彎矩（均勻彎矩）1.00每個斷面都吃滿，最不利，是基準
簡支均布載重1.14小紅利
一端有彎矩、一端是零（線性）1.67紅利最大

公式用四分點取樣：把無側撐段切成四等分，讀 \(M_A\)、\(M_B\)、\(M_C\)：

$$C_b = \frac{12.5M_{max}}{2.5M_{max} + 3M_A + 4M_B + 3M_C} \le 3.0$$
重點全部取絕對值；不確定時取 1.0，永遠偏保守。

陷阱在上限。\(C_b\) 把整條曲線往上抬，但天花板 \(M_p\) 不會跟著抬，抬過頭的部分一律削平。\(C_b = 1.3\) 的時候，非彈性區左邊一大段都會超過 \(M_p\)。

陷阱乘完 \(C_b\) 一定要多寫一行，和 \(M_p\) 比（截頂 \(\le M_p\)）。

有多個側撐點時，要逐段各算各的：每一段用自己的 \(L_b\) 和 \(C_b\) 算 \(\phi_bM_n\)，再跟該段自己的 \(M_u\) 比。

段\(L_b\)\(C_b\)特徵
第 ① 段3.0 m≈ 1.4彎矩小、\(C_b\) 大
第 ② 段 ★控制2.4 m≈ 1.0彎矩最大、\(C_b\) 最小
第 ③ 段3.2 m≈ 1.52\(L_b\) 最長但彎矩小

\(L_b\) 最長的那段，常被 \(C_b\) 救回來；中段 \(L_b\) 短，但 \(C_b\) 接近 1，又碰上最大彎矩，往往才是控制段。

8獨立檢核

強度算完，還有兩條獨立檢核。

剪力：剪力幾乎全由腹板承擔。

$$V_n = 0.6\,F_yA_wC_v,\qquad 0.6 \leftarrow \frac{1}{\sqrt3} = 0.577\ \text{（純剪降伏）},\qquad A_w = d\times t_w,\qquad \phi_v = 0.90$$

剪力面積用全深 \(d\) 乘 \(t_w\)，不是淨高 \(h\)。

陷阱同一題裡，剪力用 \(d\)、寬厚比用 \(h\)，代錯就整題報銷。

撓度：撓度是使用性檢核，例如 \(\delta \le L/360\)，一定要用服務載重和彈性的 \(I_x\)，不能用 1.2D+1.6L。

陷阱用了因數化載重，撓度會高估四到六成，選出來的斷面就太大了。

9弱軸彎曲

弱軸彎曲為什麼沒有 LTB？挫屈一定往比較弱的方向去。繞弱軸彎的時候，受壓區要側移只能往強軸方向，挫不動，所以和 \(L_b\) 完全無關。但另有上限：

$$M_{ny} = \min\left(F_yZ_y,\ 1.5F_yS_y\right)$$
形狀因子 Z/S值
H 型鋼強軸1.12
H 型鋼弱軸1.55
規範上限1.50
重點H 型鋼弱軸形狀因子大約 1.55，超過 1.5，就由上限 \(1.5F_yS_y\) 控制。

10七步流程

  1. 算斷面性質：\(Z_x\)、\(S_x\)、\(I_x\)、\(r_y\)（非對稱分開算 ENA／PNA）
  2. 驗寬厚比：\(\lambda_f = b_f/2t_f\)、\(\lambda_w = h/t_w\) → 結實？
  3. 圈出側撐點，算每段的 \(L_b\) 和 \(C_b\)
  4. 算分界點：\(M_p\)、\(M_r\)、\(L_p\)、\(L_r\)
  5. 判定 \(L_b\) 落在哪一區，代對應公式
  6. × \(C_b\) → 截頂 \(\le M_p\) → × \(\phi_b = 0.90\)
  7. 收尾檢核：剪力 \(\phi_vV_n\) 與服務載重撓度 \(\delta\)

11總結

第一斷面給本錢 \(M_p = F_yZ_x\)；\(Z_x\) 不是 \(I_x/c\)
第二關卡一（板的尺度）：翼板量一半、腹板量淨高
第三關卡二（桿的尺度）：\(L_b\) 落在哪一區，乘完 \(C_b\) 要截頂
第四剪力（全深 \(d\)）和撓度（服務載重）另外檢核
整個單元的答案這根梁有沒有資格把 \(M_p\) 用完？
